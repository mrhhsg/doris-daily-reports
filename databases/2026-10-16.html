PR #22797｜主线 / main

新增析取连接重写优化器，将 INNER、LEFT、RIGHT、FULL OUTER、SEMI、ANTI 连接中 OR 连接的 2–16 个跨输入等值条件改写为比较连接链，避免块嵌套循环，并支持 IS NOT DISTINCT FROM。

重要性与适用范围：该优化改变运行时连接执行路径，适用于析取等值连接；仅支持 2–16 个等值分支，覆盖普通与 NULL 安全等值，FULL JOIN 独立检查两侧未匹配行以减少重复生成。

官方原文证据（保留基准及适用条件）：
Disjunctive equality joins currently use a blockwise nested-loop join even when each equality can use a comparison join. This adds an optimizer pass for INNER, LEFT, RIGHT, FULL OUTER, SEMI, and ANTI joins whose condition is an OR of 2–16 cross-input equalities, including IS NOT DISTINCT FROM.

For pair-producing joins, each equality becomes a comparison join. Later branches exclude pairs already accepted by earlier branches; UNION ALL preserves duplicate occurrences. Ordinary equality exclusions use lhs IS NULL OR rhs IS NULL OR lhs != rhs, allowing UNKNOWN through while letting statistics remove unnecessary NULL checks. NULL-safe equality uses lhs IS DISTINCT FROM rhs. These checks use the complete comparison operands, including nullable computed expressions. Outer joins append unmatched rows from anti-join chains. FULL JOIN checks unmatched rows independently on each side, so it does not regenerate the matched pairs to find unmatched RHS rows. SEMI uses a MARK-join chain and ANTI uses an anti-join chain.

PR #125402｜主线 / master

该 PR 让 Iceberg 的 remove_orphan_files 和 expire_snapshots 跳过已收集的 manifest，避免为每个快照重复读取同一清单，使读取量随不同 manifest 数而非快照数二次增长。
