# Apache Doris 合并日报｜2026-10-30（北京时间）

## 摘要

master 主线新增 MIN\_TOPK/MAX\_TOPK、ARRAY\_SORTED\_MERGE，并为启用溢写的 DISTINCT 集合运算改写执行路径；新增默认关闭的云端 PageIO 预读，优化 CSV 读取、集合构造与 CAST 向量化。修复认证插件兼容、Iceberg 认证及分区补偿、空值感知连接和搜索评分问题，默认禁用 localhost 认证绕过。外部扫描可随查询终止清理资源，但连接器插件需匹配新版 FE，部分性能收益及回退仍待验证。

release 回移方面，branch-4.1 涵盖 OIDC 登录、读取路径与搜索评分修复；branch-4.2 回移外部数据访问及 FileScannerV2 更新、导入鉴权、索引选择与评分、VCG 状态等修复，以及编码、CAST 和 DISTINCT 聚合 CTE 拆分优化。这些属于分支回移，不作为主线新增功能；部分变更细节及影响尚不充分。

测试覆盖新增函数、连接语义、索引选择和认证边界，并改进 MySQL 流式回归等待稳定性；部分完整构建、BE 单测和 SQL 回归仍待验证，ARM 优化尚缺重新测量。所提供资料未体现文档更新，合并不代表已上线。

## 合并概览

2026-10-30（北京时间）｜合并 PR：33。按实际 merged\_at 筛选，主线与 release 回移分别统计。

## master 主线（17 条）

### 功能（2 条）

[PR \#64125](https://github.com/apache/doris/pull/64125)

启用查询溢写或强制溢写时，将支持类型的 DISTINCT INTERSECT 改写为去重聚合加左半连接，DISTINCT EXCEPT/MINUS 改写为去重聚合加左反连接，以使用支持溢写的算子。采用空值安全相等保持 NULL 语义；未启用溢写、ALL 或不支持的输出类型保留原集合运算路径。

[PR \#69456](https://github.com/apache/doris/pull/69456)

新增 MIN\_TOPK/MAX\_TOPK 聚合函数，返回最小或最大的 k 个非空去重值及精确行数；新增 ARRAY\_SORTED\_MERGE，支持按自定义合并逻辑处理升序或降序数组。为增量 MIN/MAX 维护提供基础能力，增量视图维护集成由独立 PR 完成，并补充回归及单元测试。

### 性能（6 条）

[PR \#67292](https://github.com/apache/doris/pull/67292)

为云端查询新增默认关闭的 PageIO 预读路径，支持顶层标量列扫描与点查，按窗口合并邻近页读取，并对已消费范围异步补齐缓存块空洞后回写。旨在减少稀疏读取放大、增加顺序扫描并发读取机会；复杂列保持原路径，预读失败时回退原读取逻辑。

[PR \#69688](https://github.com/apache/doris/pull/69688)

为小端 AArch64 的 phmap 控制字节扫描引入 NEON 精确比较，减少误匹配候选，保留八字节分组、便携回退及既有转储加载布局。完善补丁重复应用检查、异常恢复和独立测试；当前组合补丁尚未重新进行 ARM 测量及完整 SQL 回归，具体影响待确认。

[PR \#69690](https://github.com/apache/doris/pull/69690)

优化 BE 单键值对 MAP 构造，跳过键去重；字符串 ARRAY\_DISTINCT 对无 NULL 批次集中复制，减少缓冲区扩容和逐项复制开销。含 NULL 或元素数超出 UInt32 选择器上限时保留逐项复制，维持首次出现顺序、重复键末值优先及 SQL NULL 语义。新增相关单元测试，完整 BE 单测仍待 CI 验证。

[PR \#69818](https://github.com/apache/doris/pull/69818)

优化 SegmentIterator 在 x86 上的行索引生成：选中行超过两行时采用八行查找表和定宽写入，稀疏掩码及其他架构沿用位迭代，保持行序和列物化行为。新增单测与独立基准；部分稀疏场景性能回退，完整 SQL 收益未测，标准 BE 单测尚未执行。

[PR \#69840](https://github.com/apache/doris/pull/69840)

将列创建工厂包装函数 COWHelper::create 标记为强制内联，消除部分 CAST 循环的向量化障碍。编译验证非空 INT 转 BIGINT 已生成 AVX2 向量指令，SQL 转换语义不变；空值路径仍有其他障碍，BOOLEAN 转换尚未全面验证，运行时收益待确认。

[PR \#69875](https://github.com/apache/doris/pull/69875)

优化 V2 CSV 读取：单字符分隔符直接比较，计数器批量更新，阶段计时改为采样，并按批次校验字符串列、预留空间，减少解析开销。遵循调用方批次行数上限，保留字节预算和原有值语义；共享计数与批次控制也适用于 Hive 文本读取。Sampled 阶段耗时不可直接与旧完整计时比较。

### 修复（8 条）

[PR \#67286](https://github.com/apache/doris/pull/67286)

修复升级 FE 后旧版无版本声明认证插件无法加载的问题，将确实缺失版本声明的认证插件按 API 1.0 处理并告警。空声明、格式错误或不兼容版本仍被拒绝，其他插件校验保持严格；FE 认证 API 主版本变更后将自动拒绝旧版插件。

[PR \#68833](https://github.com/apache/doris/pull/68833)

修复云模式虚拟计算组（VCG）同步失败状态收敛问题：每轮同步检查完整子组集合，避免健康子组误清除失败记录，并跟踪已有组新增的缺失子组；在全部引用恢复、组重命名或删除时清理相应时间戳，避免状态残留。

[PR \#69598](https://github.com/apache/doris/pull/69598)

修复 Iceberg 插件未按合并后的 Hadoop 配置选择 Kerberos 认证的问题，使标准 HDFS 存储认证属性生效；凭据不完整时保留原有认证路径，并保持 HMS 与存储身份隔离。同时修复认证包装层导致 REST 下发的临时存储凭据丢失，确保凭据可转发至 BE，文件操作仍保持认证。

[PR \#69678](https://github.com/apache/doris/pull/69678)

修复 Iceberg 物化视图分区补偿时，深拷贝文件扫描保留旧分区裁剪状态的问题。通过使复制扫描的裁剪状态失效，重新应用缺失分区谓词，避免补偿分支扫描全部旧分区，以及由此引发的嵌套 UNION、Memo 扩张和回退至 Iceberg 全量扫描。

[PR \#69740](https://github.com/apache/doris/pull/69740)

FE 默认禁用 localhost 身份认证绕过，不再默认允许本地主机连接跳过身份验证；配置方式及对现有连接的具体影响待确认。

[PR \#69762](https://github.com/apache/doris/pull/69762)

修复带附加连接条件的空值感知标记连接中，无匹配哨兵残留空值标志的问题。生成哨兵时将标志清零，保留真实候选标志，确保空相关子查询的 IN 返回 FALSE、NOT IN 返回 TRUE，不受前一探测行影响；新增哈希表单测和 SQL 回归测试。

[PR \#69815](https://github.com/apache/doris/pull/69815)

修复模式查询评分不一致问题：SEARCH 正则和通配符子句恢复为每个匹配行固定计分 1，与前缀查询及 Elasticsearch 默认行为一致；MATCH\_REGEXP 评分由 0 改为 1，并跳过不必要的统计收集，避免展开词项的 BM25 累加及分段统计差异影响评分。

[PR \#69835](https://github.com/apache/doris/pull/69835)

修复 FE 外部扫描在 LIMIT 完成、取消或超时后仍枚举文件并保留分片队列的问题，使扫描任务随查询终止并清理资源；新增首分片等待超时及生产者并行度配置，超时报错包含枚举进度。连接器和文件系统插件需匹配新版 FE；已披露的 OSS 性能回退原因尚未明确。
