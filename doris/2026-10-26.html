摘要

本日为完整自然日，共汇总 48 个 PR：master 主线 34 个，release 回移 branch-4.1 11 个、branch-4.2 3 个，未涉及其他分支。master 主线以性能和可用性改进为主，包括默认关闭 MOW 按版本数累积压缩、行存点查询复用 segment 避免二次扫描、Iceberg 元数据与分区视图缓存（报告暖查 LIMIT 10 由约 400 毫秒降至约 10 毫秒）、对象存储 glob 前缀下推；功能侧新增 GCS 的 GCP IAM 认证、分桶聚合桶数会话变量，传统文件导入可选用 FileScannerV2。

修复覆盖自动分桶最小桶数回退、USING 键列身份、文件链接压缩隐藏列、MOW 表 BM25 分数一致性、DROP INDEX 分区组合拒绝、HTTP TVF 的 SSRF 校验、外部表刷新状态清理、日志脱敏、HLL 反序列化校验、group commit Stream Load 鉴权，以及 Iceberg、Paimon 扫描和 LZ4HC 映射等问题。另有外部表 TopN 延迟物化 profile 统计口径、SHOW DATABASES 外部 catalog 授权前置、Kerberos 多 Catalog 共享运行时等修复。

release 回移共 14 个，均为缺陷修复回合，涉及嵌套集合操作列映射、物化视图 IF NOT EXISTS、tablet vacuum 回收孤立 rowset、FQDN 心跳重建、S3 流式元数据刷新、虚拟列深拷贝与 score() 绑定、对象存储客户端统一等，不视为新功能。测试方面有 TopN 用例分组、SNII 语料库默认执行及部分修复补充单元测试，未见专门文档条目；部分改动缺基准或 CI 验证，实际收益与上线状态待确认。

合并概览

2026-10-26（北京时间）｜合并 PR：48。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（34 条）

功能（4 条）

PR #68540

为 GCS 增加原生 GCP IAM 认证，支持 ADC、Compute Engine 服务账号和可选服务账号扮演，覆盖 FE、BE、Cloud 及资源与存储库；无 HMAC 时默认 ADC，匿名访问需显式配置，并拒绝冲突凭据。现有 HMAC 仍可用，但各进程需支持新凭据字段，完整验证尚待确认。

PR #69333

为 FileScannerV2 引入 LoadTableReader，使受支持的传统文件导入沿用现有 FE/Thrift 元组，在收尾钩子中执行源默认值、预过滤、目标转换、严格空值检查及部分更新位图；CSV/JSON 异常记录回滚并计数，JSON 管道读到 EOF，Avro/Arrow IPC 保持原路径，无 FE/Thrift 改动，完整构建与运行时验证待确认。

PR #69425

新增会话变量 bucketed_agg_num_buckets，用于分桶聚合自动或显式选择桶数：自动时单实例为1、否则256，显式仅允许1到256的2的幂；计划通过可选Thrift字段下传，缺省保持256。还调整桶路由与单桶路径优化，并增加Profile指标；SQL语义不变，运行时性能影响待确认。

PR #69614

在 FileScannerV2 新增 ES TableReader/FileReader，使 FORMAT_ES_HTTP 查询在开启 enable_file_scanner_v2 时走 v2，否则仍用 v1；复用现有 ES 查询构建、HTTP scroll、鉴权、SSL 和类型转换，支持投影、谓词本地化与残余过滤。

性能（5 条）

PR #67178

将 compaction_promotion_version_count 默认值从 1000 调整为 int64 最大值，默认关闭 MOW 累积压缩按版本数将输出 rowset 提升到 base 层的行为，本地和云模式均生效；按大小和删除版本提升逻辑不变，配置仍可调小作为回退手段。

PR #67649

行存点查询原先在定位主键后需再次加载并扫描 segment 读取行数据；本改动在键查找时返回匹配的 segment 并保留在每行读取上下文中，供行数据阶段直接复用，从而去掉第二次 segment loader 调用与扫描，原有查找接口及其他调用方的 IOContext 保持不变。未运行延迟或吞吐基准测试，具体收益待确认。

PR #69299

优化 Iceberg 扫描与 SQL 缓存元数据：按连接器元数据代际缓存不可变分区视图及裁剪索引，普通扫描默认用原生文件裁剪，SQL 缓存通过版本提供器校验当前、历史及分支/标签快照，并复用表句柄减少远程请求。PR 报告 12 万分区暖 LIMIT 10 由 389–463 毫秒降至 9.69 毫秒。

PR #69383

提取对象存储 glob 辅助逻辑为 ObjectStorageGlob，Azure 与 S3 兼容列举改用扩展前缀下推，减少无关扫描；有界备选转为排序且互不重叠的前缀，不安全或过度扩展回退保守前缀并仍应用完整匹配；数值范围保留零填充，游标统一按无符号 UTF-8 顺序；S3 目录桶拒绝基于 key 的分页。测试已扩充但未获 CI 验证，具体影响待确认。

PR #69600

为 SNII 词典扩展的 visit_prefix_terms 增加可选 accept_key，使 expand_terms 在解码词典条目前先做必需文本和模式匹配，跳过不匹配条目的正文；MATCH_REGEXP、通配符等无前缀模式词项扩展因此减少无效解码，结果与原有逻辑一致。

修复（23 条）

PR #69353

修复自动分桶回退路径未应用当前最小桶数的问题：共享计算器在历史大小缺失或为空时，对自动默认及历史桶数套用 autobucket_min_buckets 下限，使动态分区与自动范围分区遵循配置；固定桶数和已有分区不变，并补充单测与回归测试。

PR #69388

修复转发 USING 连接键的列身份不一致问题：SELECT、GROUP BY、HAVING、ORDER BY 中混用限定与非限定引用同一 USING 键可正常规划；并通过有序的消费者到生产者映射保持 CTE 输出列顺序，避免同一源列重复出现时列序错乱。

PR #69395

修复有序文件链接压缩对隐藏列的不安全问题：当被选中的行集包含单版本隐藏 VERSION/TSO 占位符时拒绝链接，回退普通物理合并，并按名称查找 VERSION 列以覆盖 light_schema_change=false 的合并读场景。

PR #69438

修复 merge-on-write 表 BM25 score 在不同副本及 compaction 前后不一致的问题：扫描时将删除位图和读取版本传入统计，按段排除删除位图标记行与删除标记行，使文档数、词频和 token 总数只计可见行，全隐藏表返回零文档；无删除位图表行为不变，合并读等场景仍待后续处理。

PR #69442

修复 ALTER TABLE 中 DROP INDEX ... PARTITION 与其他子句混用时其他子句被静默跳过或索引在错误分区删除的问题：现于处理前拒绝该组合并提示分开执行，单独的分区级删除行为不变，并新增单元测试验证。

PR #69455

为 HTTP TVF 的 FE 文件大小 HEAD 请求增加 SSRF 检查：在 HEAD 前启动配置的检查器，并在 finally 中停止；检查被拒则不发送 HEAD。该改动同时覆盖直连 HTTP/HTTPS 和 hf:// 展开的每个 URL，并保留请求头与文件状态。

PR #69501

修复外部表刷新后查找状态未失效的问题：显式 REFRESH TABLE 现在会清除连接器元数据、表名快照和对象/ID 查找，并在 follower FE 上重放相同决策；普通内容变更保持原有范围。普通查找确认远端表已删除时，在身份仍有效的前提下清理过期状态，避免旧缺失响应误删已刷新或重建的表，视图单独检查且连接器失败不视为表不存在。具体影响待确认。

PR #69506

修复 BE 诊断日志泄露 HTTP 查询信息的问题：HttpRequest::debug_string 不再输出完整请求 URI 及参数键值，改为输出解析后的路径和参数数量；查询解析失败告警也不再包含原始查询文本。请求解析及 URI、参数访问行为不变，改动仅限相关日志路径。

PR #69512

在反序列化 HLL 及可空 HLL 列时增加边界与一致性校验：传入实际缓冲区末尾，校验压缩可空空值映射的 StreamVByte 控制与数据长度，并在 Arrow 转换前核对行数；块反序列化失败时释放 exchange 队列记账并触发延迟完成回调，非法序列化值和行数不一致将被拒绝。

PR #69516

修复显式 group commit Stream Load 跳过事务开始路径导致鉴权缺失的问题；FE 规划阶段在 follower 转发或本地规划前增加凭据与目标表 LOAD 权限校验，非法凭据、无效 token 或无目标表 LOAD 权限的调用将被拒绝。

PR #69532

修复 BE 心跳日志与令牌不匹配错误中泄露集群令牌和认证令牌的问题：保留心跳事件及无效令牌错误信息，但移除凭据值，避免其传播到 FE 日志；新增单元测试覆盖初始化、重复心跳、认证令牌更新和令牌不匹配，并校验日志与错误响应不含凭据。

PR #69536

修复 Iceberg 表在等值删除键列被删除且 schema ID 被复用时查询失败的问题：解析缺失键列时先沿扫描快照父链查找，再检索完整 schema 列表，并补充单元测试覆盖复用 ID、时间旅行与类型提升等场景。

PR #69540

修复 BE Fragment 日志泄露凭据问题：VLOG(10) 不再输出完整执行参数、查询选项和外部查询计划，VLOG(1) 外部打开路径也不再打印完整计划，改为记录固定标识和实例数；执行与协议参数未变，具体影响待确认。

PR #69568

BE 的 CASE WHEN 结果分派缺少 TYPE_VARBINARY，含两个及以上 WHEN 且结果为 VARBINARY 时报错。PR 将其映射到 ColumnVarbinary，复用字符串的逐行复制路径，支持可空（无 ELSE 时未匹配行为 NULL）与非可空结果，FE 无需改动，并补充单测与回归测试。

PR #69571

修复 Paimon 二进制分区表在旧版分区命名下可能静默返回部分结果的问题：扫描规划时校验非空二进制分区文件及删除向量能否定位，无法定位则报错并指明表、分区和选项，同时补充相关单元测试。

PR #69574

修复 compression=LZ4HC 在 tablet 元数据转换中被遗漏并回退为 LZ4F 的问题；在 BE tablet 元数据转换和云 FE tablet 元数据构建中补充显式 LZ4HC 映射，并为两条路径增加回归测试。

PR #69578

修复 Paimon 删除向量文件缺失时被误判为数据文件缺失并跳过整个扫描范围的问题：DeletionVectorReader 现将缺失删除向量报为 INTERNAL_ERROR，使查询失败而非静默丢弃幸存行；缺失数据文件仍按原逻辑跳过。

PR #69579

将 branch-4.1 的物化计时修复移植到 master：MaterializationOperator 的 push 原先在框架计时器之外又开了一个计时器，导致每次 push 的 ExecTime 被重复累计，还把同步拉取列数据的 RPC 等待时间算入其中，影响面仅为 profile。现移除 push 内的计时器，改由框架统一采样；新增单元测试验证直接调用 push 不会改变 ExecTime，查询结果不受影响。

PR #69583

修正外部表 TopN 延迟物化第二阶段 profile 统计：InitReaderAvgTime 改为累加各 range 初始化时间，GetBlockAvgTime 使用真实块读取耗时，并新增 add_external_fetch_avg_time_profile 汇总，避免同一 RPC 内前一请求块均值影响后一块；仅影响 profile 与日志，不影响取回数据，已加单元测试。

PR #69607

将 BE 头文件依赖检查中 util/threadpool.h 的基线从 988 提升到 1200，使含 10% 余量的实际上限由 1087 升至 1320 个翻译单元，以解除构建阻塞并留出增长空间；同时新增 include 注入自测，验证超预算时仍会失败并输出诊断命令。运行期行为和其他预算规则不变，未声称降低编译成本。

PR #69608

修复同一 FE 进程内多个 Kerberos 外部 Catalog 共享 Hadoop 运行时时，后初始化插件覆盖 auth_to_local 映射并触发 NoMatchingRule 的问题；连接器与文件系统认证器统一在共享监视器下校验并初始化 UGI，追加去重兼容规则、失败回滚，不兼容机制明确拒绝。

PR #69612

修复 SHOW DATABASES 在检查调用者能否看到外部 catalog 之前就访问其元数据服务的问题：现在先复用现有 SHOW 谓词检查 catalog 可见性（含库、表、列授权并遵循授权控制器），无权限用户在远程元数据访问前即被拒绝，保留原有按库过滤和内部 catalog 行为，并新增未授权访问单元测试。

PR #69615

Iceberg Parquet 写入时收集行组起始偏移并写入数据文件元数据，在清单中发布 split offsets；文件元数据表扫描请求 split_offsets 时同时投影文件大小以通过校验，并保持 BE JNI 读取器列位置约定。旧片段、空文件、ORC 及删除文件不受影响，具体影响待确认。

测试（2 条）

PR #67402

将 search score TopN 谓词测试用例从并发 P0 组移入 nonConcurrent 组，避免与其他 P0 用例并发时出现间歇性失败，与分支修复保持一致，仅调整测试分组，不改变产品行为。

PR #68607

该 PR 将 SNII 兼容性语料库测试改为默认执行，内置八组索引与期望文件，由 CMake 提供目录路径，使 run-be-ut.sh 重置 DORIS_HOME 后仍能定位文件；外部语料或写入仍由 SNII_GOLDEN_DIR 指定。其余源码与 protobuf 改动仅简化注释并重命名一个测试，不改变断言与生产行为。

release 回移 / branch-4.1（11 条）

修复（11 条）

PR #69427

在 branch-4.1 分支合入 RBO 修复：合并嵌套集合操作时保留列映射，避免列对应关系丢失；该改动由 #69131 cherry-pick 而来，具体影响待确认。

PR #69439

该变更为 branch-4.1 拣选修复：CREATE MATERIALIZED VIEW IF NOT EXISTS 遇到已存在的同步物化视图时跳过，避免重复创建；具体影响待确认。

PR #69495

回合上游 #69325 到 branch-4.1：复用 tablet vacuum 在可配置宽限期后回收已完成但孤立的 rowset 预热记录，释放过大哈希桶，以尝试代次隔离延迟回调与索引注册，并在清理未用 rowset 缓存前释放 tablet 锁；同时适配 4.1 分支 segment 接口。

PR #69496

在 branch-4.1 回合上游修复（#69450），解决 FQDN 模式下 BE Pod IP 复用后 FE 仍复用旧心跳连接的问题：心跳目标改由 FE DNSCache 解析，缓存地址变化或后端移除时切换并清理端点池，心跳响应异常后作废旧连接，并在请求中保留配置的后端主机名与 ID，恢复依赖既有 DNSCache 刷新策略。

PR #69519

在 branch-4.1 回合修复：前端刷新 S3 流式数据源的文件元数据，确保读取时使用最新文件信息；具体影响待确认。

PR #69522

在 branch-4.1 回合并入修复，使物化视图改写时保留常量传播后的谓词，避免相关谓词在改写中丢失；具体影响待确认。

PR #69542
