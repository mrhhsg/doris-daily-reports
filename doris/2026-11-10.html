摘要

本日 master 主线新增原生只读 MongoDB Catalog，支持集合、视图及时序集合读取并保留 BSON 类型精度，但暂不支持谓词、投影下推及并行扫描规划。主线还修复云端行集通知资源清理与 HDFS 存储库 Kerberos 认证配置丢失问题；滚动升级须待所有 BE 修复后再启用 FE 通知，受影响的已有存储库升级后需执行 ALTER 补全配置。

release 回移方面，branch-4.1 纳入 Variant 非空槽位遍历优化，以及空值感知 Mark Join、DISTINCT 聚合计划、内存分配、WAL 回放等修复；branch-4.2 回移 Mark Join、WAL 回放和 Variant 精确读取相关修复。这些属于既有改动回移，部分性能收益与影响范围尚待确认。

测试覆盖包括 BE 单测、SQL 回归及 Variant 写入顺序断言；4.1 相关 Variant 本地测试13项通过，4.2 对应单测待 CI。Kerberos 真实读写及主线更新后的完整回归尚未验证；主线流水线排除项收敛至特定环境，但同名用例匹配仍降低覆盖率。摘要未提供独立文档更新，仅涉及注释与排除原因补充。

功能（1 条）

PR #70327

新增原生只读 MongoDB Catalog，支持普通集合、标准视图和时序集合的单游标读取，以及显式、校验器和文档模式的结构解析。原生 BSON 解码保留 int64 精度、ObjectId 字节和二进制子类型；SQL 运算仍由 Doris 执行，暂不支持谓词与投影下推及并行扫描规划。

修复（2 条）

PR #70218

修复云端行集通知完成后任务签名未释放、空行集标记未清理的问题，统一空与非空行集缓存生命周期。默认启用 FE/BE 通知，并关闭云端 MoW 导入初始化强制同步，可能扩大快照新鲜度窗口；移除流水线冗余配置。滚动升级时应待所有 BE 修复后再启用 FE 通知。

PR #70320

修复 FE 在通过 SQL 创建或修改 HDFS 存储库时丢失 Kerberos 认证模式的问题，将认证键值以 BE 识别的小写形式持久化，避免 BE 回退到简单认证而导致远程文件访问失败。受影响的已有存储库需在升级后执行 ALTER 补全配置；已补充单元测试，尚未验证真实 Kerberos HDFS 读写。

测试（1 条）

PR #70407

调整四个流水线回归配置，将临时排除项限定在 DORIS_CI_PRISTINE_FRAMEWORK=true 时启用，补充环境依赖及已观察失败用例的排除项和原因。默认配置、测试框架、断言及完整性检查不变；按名称匹配会额外排除三个同名用例，覆盖率有所降低，更新后的完整回归尚未验证。
