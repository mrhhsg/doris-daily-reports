摘要

本日覆盖20项PR。master主线聚焦分词与导入性能：standard/unicode及jieba在保持分词结果不变的前提下，摘要报告分别约有1.8倍、粗粒度3.2倍和细粒度2.3倍的速度提升；JSON读取减少拷贝与初始内存分配。Lance新增REST命名空间、下发凭证及OSS支持，减少静态凭证配置需求，暂不支持命名空间托管版本表。

主线还修复Profile滞留、VARIANT变量重置及物化视图元数据与首次刷新问题；统计缓存加载引入有界队列，缓解积压，满载时可能降级为未知统计信息，禁止该降级的会话可能失败。

release回移方面，branch-4.2集中修复云模式通知与退役状态、FDB日志死循环及OOM、空集导入任务滞留，并回移UUID、ANN、字符集查询及物化视图接口修复；branch-4.1回移单测信号处理与物化视图接口修复。云通知滚动升级须待接收端BE全部修复后再启用FE通知。部分改动补充单测、回归或适配测试，但Profile回归及UUID完整构建测试尚未执行；未提供文档更新信息，合入不代表已上线。

合并概览

2026-11-21（北京时间）｜合并 PR：20。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（9 条）

功能（1 条）

PR #70725

Lance 插件新增 REST 命名空间、命名空间下发凭证及 OSS 存储支持，可无需在 Doris 配置静态数据凭证读取表；补充认证与请求头校验、敏感信息脱敏及存储凭证合并处理。文件系统目录默认行为保持不变，命名空间托管版本表暂不支持并显式报错。

性能（3 条）

PR #70265

BE 端 standard 和 unicode 分词改用单一扁平的 UAX#29 密集表，保持分词结果和行为不变。正文报告分词速度约为主分支的 1.8 倍，并标记已进行单元测试和手动测试。

PR #70266

将 jieba 纳入 Doris 源码树，供中文解析器使用，并将基于哈希映射的字典树替换为扁平数组。在保持分词结果不变的同时，粗粒度与细粒度模式的分词速度分别提升至约 3.2 倍和 2.3 倍，字典内存占用降低。

PR #70780

优化 v2 JSON 读取器，将管道消息和整文件文档直接读入填充缓冲区，减少重复拷贝；取消每个读取器预分配并清零 8 MB 缓冲区，改为随文档大小增长。适用于例行导入、流式导入及整文件 JSON 导入，解析结果和错误处理不变；按行模式保留单次拷贝，仅受益于更小的初始分配。

修复（5 条）

PR #70305

修复仅使用本地运行时过滤器的查询最终 Profile 可能滞留至超时的问题。FE 对无远程过滤目标、无递归 CTE 且无不同工作节点共用 BRPC 端点的查询省略无用合并元数据，避免额外持有 QueryContext；其他路径不变。相关 FE 单测通过，SQL/Profile 回归尚未执行。

PR #70400

为 FE 列、分区列及直方图统计缓存加载设置共享有界队列，默认上限10万，可通过 stats_fetch_queue_size 配置并重启生效。队列满时新查询降级使用未知统计信息，自动刷新被拒保留旧值，显式刷新被拒使旧值失效；隔离缓存维护并增加拒绝计数。禁止未知列统计的会话可能失败。

PR #70763

将8个仅供测试的 VARIANT 会话变量由 default_variant_* 重命名为 debug_variant_*，升级时忽略持久化旧值，修复未开启调试点时重置全部会话或全局变量失败的问题。显式设置旧名称将报未知变量，并同步更新相关测试。

PR #70784

修复 FE 旧版元数据接口查询异步物化视图列信息时因索引 ID 选择错误触发空指针的问题，改用视图实际的基础索引，按定义顺序返回列名及别名，并新增回归测试验证旧路由返回结果。

PR #70785

修复延迟创建的 MOW 增量物化视图首次刷新因写入侧类型转换导致布局签名误报不匹配的问题。签名改用规范化表写入计划及绑定列名、类型，首次成功写入建立基线，无需预先全量刷新；DRY RUN 跳过签名校验，EXPLAIN REFRESH 不修改已存签名。

release 回移 / branch-4.1（2 条）

修复（2 条）

PR #70468

修复 branch-4.1 分支 BE 在单元测试中安装 CDC SIGCHLD 信号处理器的问题，调整为单元测试时不安装该处理器。正文未提供问题表现及验证结果，具体影响待确认。

PR #70828

修复 FE 旧版元数据 API 返回异步物化视图结构信息的问题，使接口包含相关 Schema；该修复已回移至 4.1 分支，具体影响待确认。

release 回移 / branch-4.2（9 条）

修复（8 条）

PR #70455

修复云模式 rowset 通知任务签名未释放和空 rowset 缓存残留，统一移除与过期处理。默认启用 FE/BE 通知，关闭 MoW 初始强制同步，移除冗余配置。跳过同步可能扩大本地快照新鲜度窗口；滚动升级需待接收端 BE 全部修复后再启用 FE 通知。

PR #70534

向 branch-4.2 回移 UUID 数组修复：在 FE 分析阶段拒绝不兼容的 UUID 与整数数组参数，默认哈希及数组集合、映射函数改用 UUID 全部 128 位，避免低 64 位相同导致大量碰撞。补充适配测试覆盖，本地未运行完整构建和测试。

PR #70671

修复云模式下节点退役状态更新问题，将状态更新调整为原子操作。本次改动回移至 branch-4.2 分支，正文未提供实现细节，具体影响待确认。

PR #70686

修复云模式下 FDB 冲突日志记录中的无限循环和内存溢出（OOM）问题，并通过拣选合入 branch-4.2 分支。正文未提供实现细节，具体影响待确认。

PR #70711

修复 branch-4.2 中 OLAP INSERT INTO ... SELECT 源被规划为空集时，已注册导入任务长期停留在 PENDING 的问题。提前返回时将任务标记为 FINISHED、行数记为 0，避免任务堆积导致堆内存泄漏及标签清理异常，并补充相关测试适配。

PR #70783

向 branch-4.2 回移 SHOW CHARACTER SET 和 SHOW CHARSET 的 WHERE、LIKE 过滤支持，修复 MySQL 客户端相关语句被拒绝的问题。LIKE 按当前 SQL 模式解析字符串并忽略大小写匹配，WHERE 沿用会话设置；本分支不支持将客户端取消操作传递给内部过滤查询。

PR #70792

向4.2分支回移两项ANN存储修复：当段无空值且区域映射上下界均等于谓词值时，裁剪非否定等值谓词，避免MOW ANN TopN查询不必要地退化为暴力搜索；普通及SNII历史索引构建逐段释放资源并封存重建索引文件，减少跨段资源累积和峰值内存。

PR #70829

修复 FE 旧版元数据 API 未返回异步物化视图结构信息的问题，使该接口能够返回相关 schema。此修复已移植至 branch-4.2 分支，其他具体影响待确认。

测试（1 条）

PR #70756

在 branch-4.2 分支中，为 FE 的 NestedGroup 会话默认值测试启用调试点；解决 VariantEscapeTableTest.java 的合并冲突时，保留 enable_debug_points 所需的 Config 导入。
