摘要

本日共16项PR，master主线13项、branch-4.2回移3项。主线新增FILE独立查询类型基础框架，支持内联二进制读取及元数据访问，但尚不开放表列、SQL构造函数和远程读取；Nereids扩展右连接OR展开，使符合条件的查询可用哈希连接替代嵌套循环，并改进高重复IN列表去重及UNNEST谓词依赖检查。自动审查入口同步统一，产品构建与发布路径不变。

主线重要修复涉及云模式Schema Change废弃tablet统计和中间文件清理、本地特定VARIANT表删除后合并崩溃、Group Commit提交失败误报成功，以及Iceberg快照过期的会话时区解析和删除计数，旨在降低磁盘占满、错误成功响应与快照误删风险；另修正changelog行数估算校准。

branch-4.2回移VARIANT值索引，要求启用enable_variant_v2，新增索引作用于新数据；另修复Iceberg ORC Decimal边界值及PostgreSQL JDBC空数组、全NULL数组类型映射。多项改动补充单元或回归测试，但本地删除回归、外部PostgreSQL回归尚未运行，Decimal修复缺少验证细节；未提供文档更新信息。上述合并不代表已上线。

合并概览

2026-11-26（北京时间）｜合并 PR：16。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（13 条）

功能（4 条）

PR #68853

新增 FILE 独立查询类型的前后端及传输、序列化框架，支持内联二进制读取、元数据访问、字段展开与 JSON 输出，为多模态和湖仓文件数据处理提供基础；暂不开放 FILE 表列、SQL 构造函数及远程对象读取，并限制比较、排序和类型转换。

PR #70471

Nereids 的 OR 展开新增支持未被 RBO 归一化的 RIGHT OUTER 和 RIGHT ANTI 连接，使符合条件的查询可使用哈希连接替代嵌套循环连接，保留输出列顺序及 SQL 结果语义。沿用 OR_EXPANSION 开关，并补充右连接、CASE 提取及空值等回归覆盖。

PR #70477

Nereids 将 SemiJoinCommute 更名为 ConvertRightJoinToLeftJoin，明确其将右外、右半及右反连接转换为对应左连接的职责，同步更新 RBO 注册引用和测试名。保留原规则标识及禁用配置兼容性，转换逻辑、执行顺序和性能不变。

PR #71038

统一自动审查入口为 /review，支持可选审查重点，授权新请求均通过 FC 执行；移除 Actions 审查执行器、调试命令、手动触发及后端切换配置，保留快照与权限校验。已运行任务可继续完成，产品构建和发布路径不变。

修复（9 条）

PR #67401

修复云模式下已取消或移除的 Schema Change 影子 tablet 导致最大 compaction 分数虚高的问题。通过同步任务存活状态，将废弃 tablet 排除出分数统计、调度候选和查询接口，保留进行中的新 tablet，并补充状态、未调度原因及僵尸数量诊断信息，使指标与接口统计范围一致，兼容滚动升级。

PR #69134

修复云模式下排序型 Schema Change 的中间 rowset 遗留在文件缓存路径的问题：每个输入 rowset 处理结束后，无论成功或失败均清理中间文件；BE 启动时清理历史进程遗留文件，避免误删当前进程文件。防止残留文件占满缓存磁盘并导致读取回退到远程存储，补充单元及回归测试。

PR #70286

修复本地模式删除行集沿用过期模式版本的问题，改为在请求提供版本时使用 FE 模式版本，避免含 VARIANT 列的 DUPLICATE KEY 表新增键列后、再次导入前执行删除，导致全量合并时各副本 BE 崩溃。新增回归用例，尚未本地运行；云模式不受影响。

PR #70502

修复 Iceberg expire_snapshots 在文件删除前递增计数的问题，改为仅在 FileIO.deleteFile 正常返回后计数，避免失败及重试导致删除数量虚增。保留六类文件统计、文件选择和重试行为，并补充删除失败、重试及并发场景测试。

PR #70612

修复 Iceberg expire_snapshots 将 ISO 格式 older_than 按 FE JVM 默认时区解析的问题，改用 SQL 会话时区，避免时区偏差导致历史快照误删或应删未删。毫秒时间戳输入、参数校验及保留规则不变，并补充时区与快照保留结果测试。

PR #70892

修复持续写入时滞后统计报告无法校准 changelog 行数估算的问题。FE 使用覆盖版本不回退的完整报告重置估算，为每个索引设置128个写入版本的增量预算，并保留版本边界以避免重复计数；同时修正 Cloud 刷新水位推进。估算可能短暂遗漏新写入行，后续完整报告会重新校准。

PR #70915

修复同步 Group Commit 导入在事务提交失败后仍返回成功的问题，覆盖因 WAL 空间不足转为同步模式的异步导入。在唤醒等待请求前记录共享队列错误，使客户端收到提交错误；保留首个队列错误，RPC 传输错误优先于响应错误，发布超时及 WAL 恢复判定保持不变，并补充错误传播回归用例。

PR #70917

修复 Nereids 对超过200项的 IN 列表直接跳过去重的问题。现对重复度较高的字面量前缀去重，保留首次出现顺序及单个 NULL，非字面量后缀保持不变；前200项出现第101个不同值时放弃改写。重复单值列表可进一步简化为等式，避免重复值被基数估算重复计数。

PR #70918

修复 Nereids 物理 Generate 表达式列表遗漏 lateral UNNEST 连接 ON 谓词的问题，避免表达式访问器漏检不可移动表达式；补充生成器参数和谓词列引用校验，确保谓词依赖的子节点列保留物化，并在引用不可用列时报告错误。

release 回移 / branch-4.2（3 条）

功能（1 条）

PR #70982

将 VARIANT 值索引回移至 4.2，支持根级 MATCH 跨列内叶节点使用 SNII 值索引；新增索引作用于新数据，删除索引会从表中移除索引。要求启用 enable_variant_v2，否则拒绝建索引及对已有值索引表的读写规划，并兼容旧键编码压实、跳过旧倒排格式的值索引写入。

修复（2 条）

PR #70290

修复 BE 向 Iceberg 写入 ORC 数据时有符号 Decimal 边界值的保留问题，并将改动回移至 branch-4.2。正文未提供实现细节或验证结果，具体影响待确认。

PR #71026

修复 4.2 分支 PostgreSQL JDBC 对全 NULL 或空数组列的类型映射：通过参数化查询读取系统目录中的声明维度，替代行数据采样，支持此类一维、二维数组列。保留原有过滤与类型映射，补充回归用例；FE 构建通过，外部 PostgreSQL 回归未运行。
