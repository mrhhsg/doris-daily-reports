摘要

主线新增 IVM MIN/MAX 增量维护、MongoDB 语句级共享快照及 Lance 只读连接器，分别减少完整重算、支持跨集合一致性读取并扩展数据接入。性能改动聚焦大规模 Compaction 行号映射压缩、稀疏 IN 剪枝、Fluss 扫描及列复制优化；多项改动尚无端到端基准，不能据此量化收益。

主线重要修复覆盖增量物化视图外连接刷新丢行、Paimon 删除向量读取、时区闰日计算、写入共享列安全及空源导入任务泄漏，并加固镜像。MongoDB 快照及 Paimon 协议调整需注意 FE/BE 配套，Lance 自定义内存配置需迁移。测试补充单元、回归及 ASAN 覆盖，治理异步统计竞态并公开 CI 配置，部分验证仍待完成；文档更新贡献指南与 PR 模板，不改变运行时行为。

release 回移方面，branch-4.1 修复表变更回放时的查询缓存失效处理，以及超大删除位图导致的云模式写入失败；branch-4.2 修复加列后跨计算组点查误返默认值及相关崩溃风险。这些均为修复回移，不代表新功能或已经上线。

合并概览

2026-11-18（北京时间）｜合并 PR：37。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（34 条）

功能（7 条）

PR #69890

为 IVM 新增 MIN/MAX 增量维护，通过容量可配置的分组 top-K 状态合并变更日志，避免每次完整重算；可信范围耗尽时按刷新模式报错或回退完整刷新，修改容量后需完整重建。同时修复 Nereids 公共子表达式消除及投影下推中 lambda 参数作用域问题。

PR #70343

为 Iceberg REST Catalog 增加基于标准 SDK 和已配置 KMS 的加密元数据惰性只读支持，补充单元与回归测试。加密读取仍默认关闭，加密 SQL 执行仍被拦截，不支持加密写入；明文读取保持原路径，部署需匹配插件 API 33.0。

PR #70443

重构对象存储访问，引入 BE 与 Recycler 共用的配置解析和客户端创建层，按提供商拆分配置、认证及 SDK 构建职责，并分离限流逻辑。保留 BE 按桶缓存客户端、Recycler 不使用缓存及各自限流策略，便于统一扩展认证方式和接入原生 SDK。

PR #70563

将存储页预读策略从段迭代器下移至列迭代器，各列独立规划和提交范围，共享查询预算；统一点查的存储层行号读取接口，移除重复行存读取。保留现有配置和缓存行为，但取消跨列请求合并，请求数量和提交顺序可能变化；尚未进行集群及远端对象存储性能验证。

PR #70654

MongoDB 原生扫描新增语句级共享快照，显式 snapshot 策略可在同一源集群的集合及 Catalog 间固定时间点，为 JOIN、UNION 提供一致性读取；不兼容策略或源状态异常时报错，不降级读取。同时修复 UUID 元数据保留和连接池键问题，默认读取策略不变，需 FE/BE 版本匹配。

PR #70681

新增 Lance 连接器插件，支持本地及使用静态凭据的 S3 文件系统目录、基础只读查询和主链版本及时间回溯，补齐 master 升级后的目录读取能力。Arrow 内存配置迁至 lance.conf，自定义值需手动迁移；暂不支持 REST 目录、写入及下推。

PR #70695

新增标签事件触发的 CI 审阅人分配流程：Codex 识别相关模块，Python 从配置候选池随机抽取至多两人，完成指派、提醒及标签切换；无候选时转交兜底人员。不改动 Doris 运行时组件，线上工作流及实际指派尚待验证。

性能（5 条）

PR #70216

优化 Fluss 扫描准备、Arrow 导入及联合读取：缓存会话属性、元数据和分区列表，复用版本化尾部键，批量处理空值及连续字符串，优化 UTC 时间转换；完善缓存生命周期、TTL 与表结构身份校验，修复未对齐偏移读取。降低重复处理开销，端到端查询收益尚未验证。

PR #70350

优化 Compaction 行号映射，按4096个源行分块构建压缩存储，符合条件且预估稠密映射严格超过500 MiB时默认启用，降低大规模映射内存占用。适配 MoW 删除位图转换和 SNII 索引合并，需稠密矩阵的路径保持不变，并新增存储用量监控及测试。

PR #70521

Nereids 扩展空关系消除规则，裁剪左侧为空的 LEFT ANTI JOIN 和右侧为空的 RIGHT ANTI JOIN，简化增量物化视图刷新中的无输出修复分支，减少冗余扫描与联合节点。同时遍历物化 CTE 生产者及嵌套依赖，保留必要断言、标量基数检查和不可移动表达式；未评测刷新耗时。

PR #70559

优化存储层稀疏 IN 谓词的段与页 Zone Map 剪枝：边界检查后利用完整 IN 集合排除不含候选值的区间，可能减少读取。复用现有阈值，超阈值及稠密域仍仅检查边界，否定谓词和含 NaN 集合保持保守处理，行级判断不变；补充边界与回退测试，尚无延迟基准结果。

PR #70606

减少空值安全相等运算 <=>、Hive 分区过滤及 Iceberg ORC 二进制归一化中的冗余列复制，复用只读空值映射和未变更子列，过滤前不再克隆完整输入。后续写入仍按写时复制机制分离；未运行性能基准，具体性能收益待确认。

修复（18 条）

PR #69290

修复云端检查器在多存储库实例中跳过反向泄漏检查的问题，按实际配置区分并去重存储位置，识别错库存放的段文件，避免嵌套路径及扫描期间新提交行集被误报。统一泄漏计数，单库存储遍历失败不再阻断其他库检查，检查开销随存储库数量增加。

PR #70073

对齐 branch-4.1 的 Paimon BLOB Thrift 定义，修复 BLOB 上限被误解码为分析溢写上限的问题，将溢写字段迁至 240，并补齐 BLOB 文件及锚点元数据，保留 Parquet 与向量字段编号。替换使用旧编号的 master 构建时需配套部署 FE/BE；本次不含 BLOB 物化及 FILE 执行支持。

PR #70346

修复 FE 中未限定数据库的函数名计算哈希时因数据库字段为空触发空指针异常的问题，使包含 date_trunc 等函数的物化视图分区元数据可正常输出改写失败诊断，并覆盖集合与表达式哈希路径；物化视图改写行为不变，新增单元及回归测试。

PR #70401

修复 Paimon 原生扫描无法读取 bitmap64 删除向量的问题：按条目头识别格式并校验长度、物理范围及校验和，使用对应解码器并缓存验证后的位图。支持同一索引混用 32 位与 64 位删除向量，避免文件末尾条目触发范围检查失败。

PR #70434

修复 Nereids 连接重排遇到连续过滤节点时的类型转换异常，在规则入口和递归提取时合并连续过滤，保留完整的可重排连接簇及易变谓词边界和连接限制。特定提示下的左连接复现查询可正确返回一行空值结果；可重排连接的顺序及谓词位置可能变化，相关单测已通过。

PR #70485

修复 TIMESTAMPTZ 按 UTC 日期进行年份加减，导致本地闰日结果错误的问题。FE 常量求值和 BE 列计算统一按会话时区的本地日期计算，再转换回 UTC；目标年份非闰年时将闰日调整为 2 月 28 日，并保留时间及微秒。

PR #70499

FE 移除聚合状态类型的强制转换标记，改在生产端重写后校验实际类型，并覆盖快速 VALUES 规划和导入表达式转换。不兼容的 combine 状态转换统一报错并显示源、目标类型；兼容状态及生产端输入拓宽仍受支持，不改变元数据、通信或存储格式。

PR #70522

修复 information_schema.table_options 遗漏零分区 OLAP 表的问题：为此类表补充一行表级元数据，PARTITION_NUM 为 0，保留已有表按分区逐行输出的行为，使客户端可读取其键模型信息。新增回归与 FE 单元测试，覆盖零分区及多分区场景。

PR #70523

修复异步物化视图 ENGINE 为 NULL 的问题，改为返回 MaterializedView，便于客户端识别。信息模式表、SHOW TABLE STATUS、REST 元数据及扫描计划 JSON 同步更新，TABLE_TYPE 保持 BASE TABLE，并补充回归与单元测试。

PR #70539

修复 SHOW CREATE MATERIALIZED VIEW 输出异步物化视图名称未加反引号的问题，确保名称含保留字、特殊字符或受支持的 Unicode 字符时，生成的建视图语句可重新执行。补充单元及回归测试；所有视图名均增加反引号，按首行文本精确匹配的脚本需适配。

PR #70562

将 Tablet 写入列校验从块转换器中提取为独立模块，以不可变遍历和新建复杂类型容器维护写时复制安全，修复共享列被修改、嵌套字符串替换后视图失效导致的错误结果或写入失败，并统一空值传播与原始行过滤。只读叶子缓冲区继续复用，不改变存储及通信格式；24项 ASAN 单测通过。

PR #70630

修复增量物化视图外连接刷新时，补空行删除与重插使用相同序列号导致行丢失的问题。复用带符号序列编码，确保重插优先，覆盖 LEFT、RIGHT 和 FULL JOIN；不增加扫描或连接，DRY RUN 结果结构不变，并补充相关测试。

PR #70649

修复 OLAP INSERT INTO ... SELECT 的来源被规划为空集时，已注册导入任务长期停留在 PENDING、导致主 FE 内存泄漏的问题。空源提前返回时将任务记录为 FINISHED、行数为 0，客户端响应不变；补充单元与回归测试，待 CI 验证。

PR #70662

加固组件、一体化及 Compose 镜像：更新系统包与 JVM，移除多余工具、Arthas 和示例 MySQL 私钥，校验下载文件并修正基础镜像引用。SSL 部署需自备证书库，Compose 构建需以仓库根目录为上下文；无需 SQL 或元数据迁移。

PR #70676

修复 Flight SQL 查询失败后，取消操作先于结果模式获取时丢失原始错误的问题。移除结果缓冲区时保留终态供后续查询，并定时清理，同时立即释放未读数据；补充取消顺序、状态回收及实际错误传递测试。

PR #70691

修复 BE 中 RuntimeState 访问的生命周期保护，使其受任务上下文生命周期约束。涉及异步结果写入回调和流水线任务诊断，而 RuntimeState 的生命周期由 fragment 管理；正文未说明实现细节，具体影响待确认。

PR #70712

修复评审人分配工作流权限，仅为最终分配任务授予 PR 写权限；成功或失败时均保留脱敏的模块决策、候选池及执行诊断，产物保存七天。路由、随机抽样和人工回退行为不变，不影响 Doris 运行时；托管环境评论创建与产物上传仍待验证。

PR #70720

修复 CI 审阅者分配依赖模型自行读取输入、可能返回空模块的问题。改由 Python 构建完整输入并通过标准输入传递；存在合格路径候选时拒绝空分类且不修改 PR。新增本地重放、离线检查、只读手动验证及诊断记录，保留人工回退与检查点支持。

测试（3 条）

PR #70546

在桶洗牌集合运算回归测试中，为三个初始表的两列均注入 row_count=3，避免异步统计更新导致 INTERSECT 输入顺序或 UNION 锚点变化，引发偶发执行计划形状不匹配。保留现有查询、断言及预期结果，不改变产品行为。

PR #70577

公开 CI 构建与测试配置，恢复经审计的回归用例覆盖，并记录保留排除项及外部组件省略项的原因和恢复条件。现有并发、超时及失败报告语义保持不变。离线检查已通过，托管脚本接入需单独推进，完整构建、回归及线上部署验证仍待完成。

PR #70652

调整 count_rollup_empty_input 回归测试，在收集统计信息前等待基表与物化视图行数分别就绪为3行和2行，避免异步行数上报与统计收集竞态影响计划选择，保留原有计划和结果断言。云模式实际回归尚待 CI 验证，具体影响待确认。

PR #70422
