# Apache Doris 合并日报｜2026-11-19（北京时间）

## 摘要

master 主线新增兼容 MySQL 的双密码机制，支持凭据在线轮换，须全部 FE 升级后使用；分词器 SIMD 化、外部 Parquet/ORC 扫描分片及增量物化视图外连接刷新得到优化，ANN 索引构建降低峰值内存。外部扫描升级需先更新 BE 并重建相关插件；Azure 新认证与 OSS 依赖尚不代表消费链路已接入。

主线重点修复云模式日志凭据泄露、Iceberg 加密元数据跨语句授权隔离、审计表升级及查询正确性问题，并改善 Variant 内存压力后的恢复能力。release 回移中，branch-4.2 涵盖 DATE 运行时过滤器、文件缓存恢复、备份解析和令牌脱敏等修复，并回移 Variant 键名转义能力，默认关闭且有全节点升级要求；branch-4.1 修复运行时生命周期保护及空集导入任务滞留，不作为主线新功能描述。

多项改动补充单元、SQL 回归、重启及 RPC 测试，CDC 测试夹具亦修复 ASAN 隐患；部分多 FE、Cloud 和真实 Azure 场景仍待验证。摘要未提供独立文档改动信息，部分回移的具体影响仍待确认；上述改动不等同于已上线。

## 合并概览

## master 主线（24 条）

### 功能（5 条）

[PR \#66115](https://github.com/apache/doris/pull/66115)

新增兼容 MySQL 的双密码支持，允许修改密码时保留旧密码并单独废弃，实现凭据在线轮换；相关操作受 GRANT 权限控制，并增加双密码状态展示和旧密码认证计数。须全部 FE 升级后再使用，降级会丢失保留的旧密码。

[PR \#69981](https://github.com/apache/doris/pull/69981)

云模式 Meta Service RPC 默认启用严格实例校验，调整 FE 请求处理，并将首个 FE 注册合并为单次 RPC。继续支持 cluster\_id 部署，自注册无需额外配置；混合版本部署可临时关闭严格校验，FE 升级期间的虚拟计算组更新保留临时兼容。

[PR \#70497](https://github.com/apache/doris/pull/70497)

第三方默认构建新增 Alibaba Cloud OSS C++ SDK V2 0.2.0，复用 Doris 的 curl 和 OpenSSL 安装头文件及静态库，为后续 BE 和 Recycler 原生 OSS 客户端集成准备依赖，本次不含运行时接入。已通过 macOS 本地构建与冒烟测试，完整第三方构建及 Linux 构建尚未验证。

[PR \#70657](https://github.com/apache/doris/pull/70657)

共享对象存储层新增 Azure SAS 和 Microsoft Entra ID OAuth2 客户端凭据认证，提供统一配置接口、凭据校验及令牌管理，保留现有 SharedKey 行为。FE 配置及 Iceberg 等消费链路尚未接入，预签名 URL 仍仅支持 SharedKey；真实 Azure 集成尚未验证。

[PR \#70661](https://github.com/apache/doris/pull/70661)

重构 BE 运行时过滤器合并器，移除所有权提示及直接接管分支，改为复制首个输入，并在 IN 转 Bloom 时先复制 Bloom 输入。过滤结果与分发路由不变，不涉及 SQL、RPC 协议或持久化格式变化。原独占路径增加锁内深拷贝，生产性能和峰值内存的具体影响待确认。

### 性能（3 条）

[PR \#70264](https://github.com/apache/doris/pull/70264)

BE 的 english 和 basic 分词器改用 SIMD 向量化字节分类器，在保持分词结果不变的前提下优化处理速度。PR 报告两者速度分别约为 master 的 3.8 倍和 7.4 倍，并已进行单元测试及手动测试。

[PR \#70561](https://github.com/apache/doris/pull/70561)

优化增量物化视图外连接刷新中的空值扩展行修复：满足唯一性等条件时，利用带符号增量替代修复前后快照检查，并在 LEFT、RIGHT、FULL 等值连接间共享键修复事件；浮点键等不适用场景保留原快照修复路径，保障结果正确性。

[PR \#70664](https://github.com/apache/doris/pull/70664)

优化原生 Parquet/ORC 外部扫描：FE 默认按 512 MiB 粗分片，BE 按行组或条带细化并向 64 MiB 合并，新增会话变量控制目标大小；共享 ORC 元数据以减少重复初始化，保留查询结果及删除语义。升级需先更新 BE，并重新构建 API 35.0 插件。

### 修复（15 条）
