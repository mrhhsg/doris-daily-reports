摘要

master 主线推进 MongoDB Catalog 保守谓词下推与列裁剪，优化 JSON 入列流程以减少重复解析，并完善多架构镜像构建。Iceberg 加密读取补齐索引认证和独立密钥处理，但加密 SQL 入口仍未开放；JSON 优化未提供性能基准。

主线修复重点覆盖夏令时与时间精度、Flight 查询取消清理、离线 BE 恢复后事务不可见、云节点退役并发导入及数据库恢复可靠性，同时加强目录敏感信息脱敏和报文大小检查。第三方连接器需适配插件 API 32.0，Paimon、Lance 构建需同步升级工具链并重建。

release 回移分别面向 branch-4.1、branch-4.2：两分支均纳入页脚缓存并发安全修复和 Variant 调试断言；4.1 另修复轻量 Schema Change 后点查询，4.2 涵盖 Variant 空值过滤、SHOW 转发、ANN 线程预算及空间函数优化。测试覆盖时间语义、缓存生命周期、锁竞争等，JSON 转换通过179项单测，但部分云诊断测试尚未运行，部分集成验证仍缺失；文档同步更新镜像帮助及开发、审查流程。

合并概览

2026-11-17（北京时间）｜合并 PR：35。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（25 条）

功能（6 条）

PR #70263

重构 BE 分析组件，将分词器、词元过滤器、字符过滤器及其工厂统一迁移至不依赖 CLucene 的流接口。词元、索引文件及行为保持不变，包含回归测试和单元测试。

PR #70314

Iceberg 原生读取器新增加密 Parquet 列索引、偏移索引及 Bloom 过滤器的认证与读取，支持安全页面裁剪；修正跳页后的物理页序号及明文缓存头兼容问题。模块损坏或认证失败会终止读取，缺失可选模块仍保守读取；加密 Iceberg SQL 读取入口尚未开放。

PR #70321

支持 Iceberg Parquet 数据文件、位置删除和等值删除文件分别传递并使用独立密钥与 AAD，覆盖原生 position_deletes 读取。加密删除对象绕过共享缓存并按分片重新认证，防止缓存复用绕过鉴权；拒绝加密 ORC/Puffin，阻止元数据 COUNT 绕过删除鉴权。加密 SQL 准入仍关闭，明文行为不变。

PR #70490

Doris 4.1 一体化镜像默认同时构建 amd64 和 arm64 的 base、full 版本，保留显式单平台选项；拒绝使用单架构二进制目录进行多平台构建，本地输出、发布包及测试须匹配单平台。冒烟测试兼容两种 Paimon 目录名，并同步更新帮助与文档。

PR #70598

将原生 Paimon 读取依赖 paimon-rust 从 0.5.0-rc1 升级至正式版 0.5.0，不再使用本地补丁；Paimon 与 Lance 构建统一要求 Rust 1.95.0 或更新版本，并使用相同工具链，Paimon 构建改用 Doris 的 OpenSSL 前缀。需同步重建两库或更新编译镜像。

PR #70604

完善原生 MongoDB Catalog 的 M1 类型覆盖验证，接入保守谓词、LIKE 候选下推及源端列裁剪，新增会话开关。谓词下推需显式启用类型不匹配转空值策略，所有 SQL 残余过滤仍保留；默认严格策略、严格转换及视图保持本地过滤，列裁剪可独立启用。

性能（1 条）

PR #70470

将 simdjson 到列的转换下沉至类型 SerDe，复杂类型递归调用子类型 SerDe，JSONB 对象和数组直接编码，避免转为 JSON 文本后再次解析。保留标量转换与错误传播语义，并修复嵌套 Array/Map 异常后的空集合偏移问题。最终版本通过 179 项单元测试，未提供性能基准。

修复（16 条）

PR #69996

修复 Arrow Flight SQL 结果流提前关闭或取消时仅清理局部 BE 的问题。FE 保存独立于会话且有容量限制的查询路由，BE 通过新增取消接口通知全部相关 BE 终止查询；同时处理远程读取中止及 GetFlightInfo 失败，避免其他 BE 持续执行并保留未读结果。

PR #70003

修复 TIMESTAMPTZ 按天加减跨夏令时切换时本地时间偏移的问题，BE 计算与 FE 常量折叠统一按会话本地日历处理，保留小数秒等语义；限制可变时区下的单调性声明和比较式移项，避免错误改写。按小时加减仍保持实际经过时间语义。

PR #70181

修复 BE 长时间离线恢复后，发布任务被清理导致已提交事务持续不可见的问题。临时离线时保留任务重试能力；永久移除 BE 或彻底删除数据库时回收相关任务，并阻止并发新增任务绕过清理，同时保留重复分区更新请求的原有派发行为。

PR #70204

修复夏令时缺口内本地时间转换被截断及小数秒丢失的问题，改为按实际缺口长度前移并保留小数秒，统一 FE 与 BE 行为；修正日历取整边界选择和跨缺口分区裁剪，并统一 Iceberg 覆盖写入与过滤的时间转换及精度，避免误删或遗漏目标分区数据。

PR #70224

修复云模式下 BE 开始及完成退役时，节点删除再添加导致注册信息短暂缺失、并发导入报 empty instance_id 的问题。改为单事务更新状态和修改时间，提交后统一刷新缓存；兼容未存储集群 ID 的命名集群，批量请求存在节点缺失或不匹配时整体失败，并补充确定性回归测试。

PR #70338

修复连接器目录敏感属性及 ALTER CATALOG 审计文本明文泄露问题，通过连接器安全声明统一脱敏目录展示和日志，保留引擎原有规则；安全声明加载失败时跳过对应提供者，避免阻断 FE 启动。插件 API 升至 32.0，基于 31.x 的第三方连接器需重新构建。

PR #70345

修复 Python 函数的 Arrow 时间类型转换：DATETIME 保留日历字段，TIMESTAMPTZ 遵循会话时区，TIME 支持浮点微秒返回及精度舍入，向量化 TIMESTAMP_NS 保留合法最小值并与 NULL 区分。含该最小值的 Series 使用对象类型，无法直接使用 .dt。

PR #70369

将 ARRAY 字面量由文本改为不可修改的元素列表，保留嵌套结构及空值。JDBC、Elasticsearch 的相关过滤改由 Doris 执行，避免查询失败或结果错误；同时限制涉及复杂类型转换的谓词下推及 Hive、Hudi 分区裁剪，防止错误过滤。

PR #70417

修复云模式下开启 FDB 冲突日志时，分页诊断重复读取同一页导致死循环及 Meta Service 内存耗尽的问题。三类冲突诊断统一使用完整范围迭代器推进分页并返回读取错误，保留原始提交错误。补充分页、键内零字节和超时测试，尚未运行。

PR #70420

修复 FE 接收 MySQL 逻辑包时未执行 max_allowed_packet 限制的问题，统一明文与 TLS 接收检查，在读取负载或扩容前校验累计大小。默认上限仍为 16 MiB，超限返回错误 1153 并关闭连接；同时修正 TLS 入站关闭处理，保留已缓冲的明文。

PR #70453

修复认证插件提供的会话角色在元数据鉴权中丢失，导致可访问的库、表、列未显示的问题。通过共享 RPC 身份传递角色快照，统一查询与元数据的角色解析，并覆盖 TVF、Flight 元数据及 FE 转发等路径；完整传递需升级 FE 和 BE，原生 BE 执行及真实插件集成尚未验证。

PR #70491

修复 macOS 原生 Cloud 构建卡住、依赖选择及编译链接问题，适配多版本 FoundationDB 客户端、线程命名和字节序处理，正确区分生产与测试目标；调整启动脚本，支持从运行时 JAVA_HOME 加载 JVM。macOS 构建与启动验证通过，Linux 构建及真实 FDB 集成尚未验证。

PR #70581

修复 FE 中 RECOVER DATABASE 获取目录锁超时导致回收站元数据丢失、后续无法恢复的问题。改为先获取目录锁，再在锁保护下校验目标名称并恢复元数据，确保锁超时后数据库仍保留在回收站，支持重试恢复；新增锁竞争回归测试。

PR #70610

更新第三方构建配置中 Arrow ADBC 源码归档的 MD5 校验值，修复上游归档变化导致的新下载校验失败，解除编译及 BEUT CI 阻塞。保留原版本、下载地址和校验机制；已完成归档内容比对，构建与测试验证留待 CI。

PR #70622

修复云端与本地 Tablet Schema 的 protobuf 双向转换中，VARIANT 转义策略字段缺失时被显式设为 false 的问题。复制和移动实现均保留字段是否设置的状态，显式值及默认值不变，并补充缺失字段与往返转换测试。

PR #70663

修复 GCC 15 默认 C 方言不再接受旧式函数声明和定义，导致 TPC-DS、TPC-H 工具编译失败的问题。构建脚本显式指定 GNU89，并保留上游构建参数；已使用 GCC 15.2.0 验证编译及数据生成功能。

文档（2 条）

PR #70648

更新 CODEOWNERS 的八条规则，将 mymeiyi 的代码审查归属移交给 liaoxin01，涉及 FE HA、日志、主节点、持久化及云事务代码。保留路径和其他负责人，并对云事务规则去重；仅改变审查路由，不影响运行时行为或存储格式。

PR #70672

更新 AGENTS.md，明确开发取证与 PR 描述工作流在当前工作树中的技能文件入口，要求缺失时仅初始化 doris-skills 子模块后再加载。该改动规范代理在检出目录和工作树中的技能加载流程，不改变运行时行为或发布流程。
