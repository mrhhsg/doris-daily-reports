摘要

本日日报覆盖11项PR，其中master主线10项。主线将Hive冷目录枚举改为流式生成扫描分片，减少等待完整列表的阻塞，并限制列表暂存、完善缓存发布与取消处理；文本分析统一至TextAnalyzer接口，现有词元、索引文件及行为不变。ANN构建新增单任务线程配置，使并行度更可预期，仍受总预算约束，可能影响构建延迟与并发度，需重启BE生效。

主线修复SEARCH数值列及Variant数值子列高命中比例下的报错；优化Variant元数据注册的异常安全、内存占用与封存效率，但唯一键注册略增开销。Variant V2增加仅调试构建启用的乱序断言。测试覆盖文本分析、Variant合并保序及SEARCH等，并修复统计快照测试内存耗尽和模拟FE启动端口竞争；第三方测试适配非root运行，Linux环境要求rootless Docker。另纠正目录审查归属规则，无运行时影响；未见文档改动。

release回移仅涉及branch-4.1的Variant模式变更回归测试修复，稳定双写用例预期；因该分支缺少SNII测试套件，移除对应测试文件，不引入新套件或新功能。

合并概览

2026-11-13（北京时间）｜合并 PR：11。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（10 条）

功能（1 条）

PR #70262

重构 BE 文本分析调用，将 SNII 写入器、V1/V2 写入器、查询端及 normalize、tokenize 统一切换至 TextAnalyzer 接口。分析器仍通过 CLucene 适配器运行，词元、索引文件及行为保持不变，并包含回归测试和单元测试。

性能（1 条）

PR #70078

FE 将 Hive 冷目录枚举改为流式生成扫描分片，无需等待完整列表；新增单目录及共享文件列表暂存上限，超限仍继续枚举，并独立缓存完整目录字节总量供后续统计估算。仅在枚举、关闭成功且未取消时发布缓存，避免失效缓存被迟到结果覆盖，并完善取消及失败处理。

修复（6 条）

PR #70416

为 Variant V2 稀疏行新增仅调试构建启用的字节序断言，覆盖行游标绑定、精确路径提取及垂直合并的源行和目标行，尽早暴露写入或合并产生的乱序问题。补充乱序触发断言及物化子列合并保序测试；发布构建不包含检查，不改变查询和合并行为。

PR #70454

新增 BE 配置 ann_index_build_threads_per_task，为 ANN 训练和向量插入固定预留线程，替代按剩余预算折半分配；保留 omp_threads_limit 总预算约束，额度不足时等待。此变更使单次调用并行度可预期，可能改变构建延迟与并发度，配置需重启 BE 生效。

PR #70487

重构 Variant 元数据键注册，使用嵌套 DorisVector 替代双端队列，先复制并预留容量，再发布映射并无抛出地移入键数据，消除异常回滚耦合及清理路径的分配风险。编码、键排序和行撤销语义不变；元数据内存占用降低，封存加快，但唯一键注册略有开销增加。

PR #70488

修复 SEARCH 查询数值列或 variant 数值子列时，命中比例超过倒排索引跳过阈值导致报错的问题。通过设置 skip_try 强制数值叶子节点使用倒排索引，避免回退到不支持的逐行执行；MATCH 和普通谓词行为不变，并新增高命中比例回归测试。

PR #70526

修复模拟 FE 启动时端口竞争导致测试 JVM 退出的问题：提前绑定临时 RPC 监听套接字并交由 Thrift 接管，避免端口选定后被抢占；端口预检仅覆盖所选日志类型和已启用服务，避免禁用服务的端口占用阻断启动。新增回归测试并通过相关验证。

PR #70541

移除 .github/CODEOWNERS 中误加的 be/src/common 目录归属规则，该目录的变更不再通过此规则自动请求原指定人员审查。不涉及构建或运行时改动，已检查差异并通过格式检查。

测试（2 条）

PR #70457

第三方测试环境支持非 root 用户通过 rootless Docker 启动，移除宿主机提权操作，并适配文件所有权、网络、初始化及健康检查；Linux 环境现要求使用 rootless Docker 守护进程。

PR #70525

修复 FE 表统计快照一致性测试偶发堆内存耗尽：改用仅存根的 Mockito 模拟对象，避免保留调用记录，并将读写限制为各 5000 轮。通过交替发布行数相同的快照检测字段混读，将读取线程异常传递给 JUnit，不改变生产行为。
