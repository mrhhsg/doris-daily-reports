# Apache Doris 合并日报｜2026-11-21（北京时间）

## 摘要

本日覆盖20项PR。master主线聚焦分词与导入性能：standard/unicode及jieba在保持分词结果不变的前提下，摘要报告分别约有1.8倍、粗粒度3.2倍和细粒度2.3倍的速度提升；JSON读取减少拷贝与初始内存分配。Lance新增REST命名空间、下发凭证及OSS支持，减少静态凭证配置需求，暂不支持命名空间托管版本表。

主线还修复Profile滞留、VARIANT变量重置及物化视图元数据与首次刷新问题；统计缓存加载引入有界队列，缓解积压，满载时可能降级为未知统计信息，禁止该降级的会话可能失败。

release回移方面，branch-4.2集中修复云模式通知与退役状态、FDB日志死循环及OOM、空集导入任务滞留，并回移UUID、ANN、字符集查询及物化视图接口修复；branch-4.1回移单测信号处理与物化视图接口修复。云通知滚动升级须待接收端BE全部修复后再启用FE通知。部分改动补充单测、回归或适配测试，但Profile回归及UUID完整构建测试尚未执行；未提供文档更新信息，合入不代表已上线。

## 合并概览

2026-11-21（北京时间）｜合并 PR：20。按实际 merged\_at 筛选，主线与 release 回移分别统计。

## master 主线（9 条）

### 功能（1 条）

[PR \#70725](https://github.com/apache/doris/pull/70725)

Lance 插件新增 REST 命名空间、命名空间下发凭证及 OSS 存储支持，可无需在 Doris 配置静态数据凭证读取表；补充认证与请求头校验、敏感信息脱敏及存储凭证合并处理。文件系统目录默认行为保持不变，命名空间托管版本表暂不支持并显式报错。

### 性能（3 条）

[PR \#70265](https://github.com/apache/doris/pull/70265)

BE 端 standard 和 unicode 分词改用单一扁平的 UAX\#29 密集表，保持分词结果和行为不变。正文报告分词速度约为主分支的 1.8 倍，并标记已进行单元测试和手动测试。

[PR \#70266](https://github.com/apache/doris/pull/70266)

将 jieba 纳入 Doris 源码树，供中文解析器使用，并将基于哈希映射的字典树替换为扁平数组。在保持分词结果不变的同时，粗粒度与细粒度模式的分词速度分别提升至约 3.2 倍和 2.3 倍，字典内存占用降低。

[PR \#70780](https://github.com/apache/doris/pull/70780)

优化 v2 JSON 读取器，将管道消息和整文件文档直接读入填充缓冲区，减少重复拷贝；取消每个读取器预分配并清零 8 MB 缓冲区，改为随文档大小增长。适用于例行导入、流式导入及整文件 JSON 导入，解析结果和错误处理不变；按行模式保留单次拷贝，仅受益于更小的初始分配。

### 修复（5 条）

[PR \#70305](https://github.com/apache/doris/pull/70305)

修复仅使用本地运行时过滤器的查询最终 Profile 可能滞留至超时的问题。FE 对无远程过滤目标、无递归 CTE 且无不同工作节点共用 BRPC 端点的查询省略无用合并元数据，避免额外持有 QueryContext；其他路径不变。相关 FE 单测通过，SQL/Profile 回归尚未执行。

[PR \#70400](https://github.com/apache/doris/pull/70400)

为 FE 列、分区列及直方图统计缓存加载设置共享有界队列，默认上限10万，可通过 stats\_fetch\_queue\_size 配置并重启生效。队列满时新查询降级使用未知统计信息，自动刷新被拒保留旧值，显式刷新被拒使旧值失效；隔离缓存维护并增加拒绝计数。禁止未知列统计的会话可能失败。

[PR \#70763](https://github.com/apache/doris/pull/70763)

将8个仅供测试的 VARIANT 会话变量由 default\_variant\_\* 重命名为 debug\_variant\_\*，升级时忽略持久化旧值，修复未开启调试点时重置全部会话或全局变量失败的问题。显式设置旧名称将报未知变量，并同步更新相关测试。

[PR \#70784](https://github.com/apache/doris/pull/70784)

修复 FE 旧版元数据接口查询异步物化视图列信息时因索引 ID 选择错误触发空指针的问题，改用视图实际的基础索引，按定义顺序返回列名及别名，并新增回归测试验证旧路由返回结果。

[PR \#70785](https://github.com/apache/doris/pull/70785)

修复延迟创建的 MOW 增量物化视图首次刷新因写入侧类型转换导致布局签名误报不匹配的问题。签名改用规范化表写入计划及绑定列名、类型，首次成功写入建立基线，无需预先全量刷新；DRY RUN 跳过签名校验，EXPLAIN REFRESH 不修改已存签名。
