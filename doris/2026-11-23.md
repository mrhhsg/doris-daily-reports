# Apache Doris 合并日报｜2026-11-23（北京时间）

## 摘要

本日覆盖49项PR，其中master主线31项。主线新增历史优化器统计、MySQL VECTOR同步和内部RPC双向TLS，并优化Lance下推与缓存、CDC快照内存、短字符串哈希连接、JSONB转换及Iceberg规划，旨在减少读取开销、改善查询性能。TLS默认关闭且不支持混合版本滚动升级；Lance同URI数据集删除重建后需刷新目录。

主线修复BM25评分、共享列改写引发的查询错误、ORC正负零过滤漏行、物化视图刷新与回退、参数转换溢出、日志凭据泄露及Iceberg分区和文件重写问题。测试覆盖单元、回归及集成场景，并推进70个BE单测文件的临时目录隔离；部分测试通过，但Changelog仍有四项云端测试失败，Lance相关失败也阻碍全量通过。摘要未提供明确的文档更新信息。

release回移包括branch-4.1的3项、branch-4.2的14项及branch-deltalake的1项，涉及查询正确性、崩溃防护、凭据脱敏、Iceberg视图、对象存储适配和Delta Lake只读支持，不作为主线新增功能。部分回移未构建或测试；未提供other分支改动，合并不代表已上线。

### 功能（7 条）

[PR \#69322](https://github.com/apache/doris/pull/69322)

为 Nereids 新增历史优化器统计，使用结构化计划指纹匹配历史执行数据，并校验表统计与数据状态，避免复用过期或不匹配的统计。支持手动管理固定统计、持久化及 EXPLAIN 展示；当前指纹对表别名敏感，重命名后无法复用原条目。

[PR \#69896](https://github.com/apache/doris/pull/69896)

在存算一体和存算分离模式下，成功提交可即时补充 Changelog 物理记录行数估计，周期统计继续校准保留行数；新增云端统计聚合、版本去重及恢复副本统计拉取。无需新配置，现有 SQL 和数据可见性不变；计数仍为估计值，四项云端行内容测试失败尚未解决。

[PR \#69948](https://github.com/apache/doris/pull/69948)

流式作业新增 MySQL VECTOR 列同步支持，涵盖普通列及 VIRTUAL、STORED 生成列，映射为 Doris 浮点数组，支持快照、增量读取、自动建表和运行时加列。新增生成列不回填目标表历史行；补充 MySQL 9.7.4 冒烟及 VECTOR 集成测试，不代表完整兼容性认证。

[PR \#70271](https://github.com/apache/doris/pull/70271)

重构后端 SNII 的 ANN 数据读写，直接实现存储接口并移除 CLucene 目录适配层，磁盘字节与读取次数不变。启用 inverted\_index\_snii\_read\_no\_write\_file\_cache 时，SNII 文件中的 ANN 读取不再填充文件缓存。

[PR \#70693](https://github.com/apache/doris/pull/70693)

为 OSS 内置私有 gRPC、BRPC 和阻塞式 Thrift RPC 增加双向 TLS，支持流量加密和可信对端证书认证，认证失败不回退明文。默认仍关闭，启用需协调节点配置；内部连接与外部服务策略隔离，本次不支持混合版本 FE/BE 滚动升级。

[PR \#70793](https://github.com/apache/doris/pull/70793)

Iceberg 插件新增 worker\_thread\_pool\_size 配置，可统一设置 FE 上所有 Iceberg Catalog 共享线程池的大小，用于清单规划和写入，需重启 FE 生效。显式配置优先于 SDK 设置，未配置时保留原有行为；非法值或已初始化线程池大小冲突会导致连接器初始化失败。

[PR \#70827](https://github.com/apache/doris/pull/70827)

Lance 连接器新增精确匹配的谓词下推、无残留过滤时的 LIMIT 下推，以及无过滤 COUNT(\*) 的清单行数读取，支持按标量索引分段规划扫描，减少不必要的数据读取。无法精确转换的条件仍由 Doris 执行，并新增扫描分片分组调试变量。

### 性能（6 条）

[PR \#70255](https://github.com/apache/doris/pull/70255)

[PR \#70404](https://github.com/apache/doris/pull/70404)

[PR \#70410](https://github.com/apache/doris/pull/70410)

将 Iceberg 有界 Manifest 加载与解析缓存解耦，未启用缓存的受支持扫描也可复用按完成顺序预取，减少 SDK 轮询等待；精简查询元数据保留，保持共享缓存完整，并修复分区投影及删除关联等问题。单个、超大或数量未知的 Manifest 仍使用 SDK 流式规划，最终版本端到端性能收益待验证。

[PR \#70748](https://github.com/apache/doris/pull/70748)

优化哈希连接的单个短字符串等值键：扫描构建侧键后，按需打包为4、8或16字节整数，复用数值哈希与桶链，减少字符串读取开销。超长或尾随零字节的构建键保留原路径，不可匹配的探测键转入独立空桶，保持NULL处理及JOIN结果不变。

[PR \#70795](https://github.com/apache/doris/pull/70795)

优化 BE 扫描条件排序：将残余条件的首次成本排序移至扫描器初始化前，延迟运行时过滤器仅在追加新表达式后重新排序，避免无新增表达式时反复在共享锁内排序。禁用过滤器仍推进已应用计数，并新增扫描排序测试；收益取决于空检查次数。

[PR \#70830](https://github.com/apache/doris/pull/70830)

Lance 目录通过共享 Session 和默认60秒的表访问缓存跨查询复用元数据，减少重复描述及存储请求；查询 Profile 新增各扫描表的 FE 元数据耗时、调用及失败次数。支持刷新失效，同 URI 删除重建数据集后需执行 REFRESH CATALOG。
