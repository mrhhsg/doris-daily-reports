# Apache Doris 合并日报｜2026-10-21（北京时间）

## 摘要

本完整自然日覆盖35个已校验PR，其中主线21个、4.2回移13个、4.1回移1个。主线上新 index\_disk\_usage 表函数，可查看倒排与ANN索引磁盘占用；行级binlog更名为changelog并拆分配置；VARIANT根列改为按批流式写入并限制段缓冲；compaction以临时rowid列替代独立缓冲区。修复涉及嵌套物化视图匹配、JSON表值函数键大小写、routine load jsonpaths、常量传播exprId、ADMIN REBALANCE DISK超时、同步物化视图SQL模式兼容、DATETIMEV2与TIMESTAMP\_NS比较、Iceberg MODIFY COLUMN及云模式预热状态回收等。测试补充Iceberg必需列、云单测和多项回归；文档改动未在摘要中体现。

回移不视为新功能：4.2回合存储层GCP IAM支持、delete bitmap聚合跳过、struct内map惰性物化、SEARCH/BM25评分与谓词二值化、VARIANT流式写入、SHOW CREATE TABLE嵌套注释、array\_sort比较器约束及事务协调器按backend ID匹配等；4.1回合lance-c依赖更新。回移多含单元与回归测试，完整构建或运行时验证仍待确认，实际影响以对应分支发布为准。其他分支本次无条目。

### 功能（4 条）

[PR \#67977](https://github.com/apache/doris/pull/67977)

新增 index\_disk\_usage 表函数，可按 tablet、rowset 或 segment 级别查看倒排索引和 ANN 索引的磁盘占用，并细分字典、posting、position 和统计字节；支持分区与索引过滤及 position\_detail，并限制单次请求的 tablet 数量。具体性能影响待确认。

[PR \#69195](https://github.com/apache/doris/pull/69195)

将 record\_rowids 及独立行位置缓冲区替换为临时 compaction rowid 列，该列在 compaction 期间保持源行位置与数据行对齐，并在写出输出段前移除。具体影响待确认。

[PR \#69235](https://github.com/apache/doris/pull/69235)

将第三方依赖 librdkafka 从 2.11.0 升级到 2.16.0，作为后续探索 Kafka share-group 接入的前置条件。此次不启用 Routine Load 的 share consumer，也未新增摄入模式或配置。已完成脚本语法检查、下载校验与补丁验证；完整 Doris 编译、SASL/SSL 链接及 broker 场景验证尚未覆盖，具体影响待确认。

[PR \#69311](https://github.com/apache/doris/pull/69311)

将行级 binlog 重命名为 changelog，并从 CCR binlog 拆出独立配置：表函数改为 changelog(...)，隐藏列改用 \_\_DORIS\_CHANGELOG\_\* 前缀，相关配置、指标和 IDL 字段同步重命名；旧 ROW 元数据增加报错护栏，避免崩溃或误读。

### 性能（1 条）

[PR \#69221](https://github.com/apache/doris/pull/69221)

Doris 将 VARIANT 根列写入器改为按批流式写入，不再缓存整个输出 segment；对仍整段缓存的 shredder 和子列写入器，按输入段 raw\_data\_bytes 与新增配置限制每段行数，避免超过 4 GiB 字符串列上限触发 E-3113。新增流式写入单测并验证校验和不变，非垂直 compaction 等场景未覆盖，具体影响待确认。

### 修复（13 条）

[PR \#63639](https://github.com/apache/doris/pull/63639)

修复嵌套物化视图候选匹配中，上层 MV 重复下层已保证的过滤条件而导致匹配失败的问题。改为利用下层 MV 可靠保证的谓词证明上层定义中的冗余过滤，使嵌套改写可匹配；查询谓词仍保留用于补偿，缓存定义不变，无法可靠确定保证时不启用。

[PR \#67408](https://github.com/apache/doris/pull/67408)

文件表值函数在构造推断出的文件 schema 时，若路径分区列名与已有文件列名冲突（大小写不敏感），现在会拒绝该配置，使无效配置在分析阶段报错；此前重复列会导致列引用歧义，并可能让 SELECT \* 触发内部后端错误。

[PR \#67411](https://github.com/apache/doris/pull/67411)

修复 JSON 表值函数在模式推断时将字段名转为小写的问题，现保留推断键的大小写，大小写混合或大写键不再被静默读为 NULL；重复检测仍不区分大小写，其他文件格式仍保持小写。

[PR \#67510](https://github.com/apache/doris/pull/67510)

修复多表 routine load 在动态目标表规划时未恢复 jsonpaths 与 num\_as\_string 的问题，避免嵌套 JSON 记录因 JSON 路径列表为空被当作无效行过滤，并补充相关单元测试。

[PR \#69111](https://github.com/apache/doris/pull/69111)

常量传播在聚合之上物化常量时复用被替换输出的 exprId，使同一 exprId 存在两个定义，可空性与类型可能不同，引发 AdjustNullable 误报。修复仅在常量确实遮蔽下层列时分配新 exprId，并刷新上层引用与 sink，CTE 生产者与消费者按重映射同步；非遮蔽场景保留原 exprId 以免影响物化视图匹配。

[PR \#69139](https://github.com/apache/doris/pull/69139)

修复 ADMIN REBALANCE DISK 的优先级超时处理：原先把秒级超时直接加到毫秒时间戳，使 24 小时缩短为 86.4 秒；过期判断也反向，会删除未过期后端而保留已过期后端。现改为毫秒换算并仅删除已过期优先级，同时补充超时转换和优先级过滤的单元测试。

[PR \#69212](https://github.com/apache/doris/pull/69212)

修复 Nereids 同步物化视图重写：当查询会话与物化视图创建会话仅在 STRICT\_TRANS\_TABLES 或 STRICT\_ALL\_TABLES SQL 模式位上不同时，原会话变量精确比较会判为不兼容，导致 SUM 等表达式被包装、聚合匹配失败。新增同步物化视图专用兼容检查，仅忽略这两个严格表模式位，其他 SQL 模式及其他影响结果的会话变量仍严格比较，旧视图无持久化会话变量时行为不变。

[PR \#69268](https://github.com/apache/doris/pull/69268)

新增 DataType.zeroValue()，为 IVM 增量刷新中缺失的隐藏槽位合成类型零值，替代按类型分支处理；修复基表含 DATETIME 序列列且 MV 查询含 join 时规划失败的问题，使该类场景可正常刷新。

[PR \#69271](https://github.com/apache/doris/pull/69271)

修复 DATETIMEV2 列与亚微秒 TIMESTAMP\_NS 字面量比较后类型不一致、OLAP 扫描谓词归一化失败的问题。将各类日期时间类型统一提升为 TIMESTAMP\_NS，覆盖比较、IN、公共结果类型和时间函数，保留收窄转换并移除混合类型回退。超出 Int64 纳秒范围会报错，时间列转换可能减少存储谓词下推。

[PR \#69285](https://github.com/apache/doris/pull/69285)

修复 Iceberg 表 MODIFY COLUMN 以 VARBINARY 重述 BINARY 或 FIXED 列（含 STRUCT 字段、ARRAY 元素、MAP 值）时报 Unsupported type for Iceberg 的问题：连接器在类型构建失败时回查当前列类型，若与请求的 VARBINARY 读法一致则保留原 Iceberg 类型，仅应用可空性、注释和位置变更，类型不一致仍报错；新增回归与单元测试。

[PR \#69325](https://github.com/apache/doris/pull/69325)

修复云模式下预热状态泄漏：复用 tablet vacuum 任务回收不在可见与过期行集中的已完成预热记录，默认宽限一小时，由 warm\_up\_rowset\_state\_gc\_grace\_period\_seconds 控制；为已接受的尝试分配 generation，避免延迟回调更新替换记录；回收后释放过大哈希桶，并调整锁顺序，使缓存清理不阻塞查询读取与预热回调。

[PR \#69332](https://github.com/apache/doris/pull/69332)

将 lance-c 固定版本更新到最新上游 main 提交并同步归档校验和，引入索引名与不同 schema 列匹配时冷会话向量预热的修复及行地址预过滤 API，并调整现有 Foyer 补丁中的 C++ 测试上下文；本地验证校验和、补丁和依赖解析，完整构建与运行时回归待确认。

[PR \#69377](https://github.com/apache/doris/pull/69377)

修复 CI 审查脚本 submit\_review.py 无法识别已有审查评论中以加粗形式标注的 P1 等优先级标题的问题，使历史评论在被重新确认计数时先规范化加粗优先级标记；新发现的问题仍保留严格格式，P0/P1 仍要求修改且不重复发布行内评论，P2/P3 仍不可作为阻塞项。
