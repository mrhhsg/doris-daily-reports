摘要

master 主线新增原生 Arrow IPC 导入与 HLL 降采样，优化云模式 MATCH、Parquet TopN、CAST、短语检索及 Catalog 资源回收，减少重复扫描、解码和等待开销。HLL 降采样可缩减存储，但不可逆且降低精度，使用前须升级全部 BE。

主线修复清表再导入后的统计缺失、增量查询分区误裁剪、SEARCH 解析与前缀评分、文件缓存生命周期等问题；IVM 日志过期后，允许回退的刷新可转为全量重建，严格增量模式仍报错。测试覆盖连接器空覆盖写入、查询规划和缓存等场景，并改善稳定性；部分测试未运行或状态未确认，未见明确文档更新。

release 回移中，branch-4.1 包括 Paimon BLOB 读取支持、CTE 列顺序及前缀评分修复；branch-4.2 包括列间 Zone Map 裁剪、表达式结果校验，以及分区谓词、复杂类型裁剪、Iceberg 扫描和默认值列延迟读取修复，并调整回归测试。这些是分支回移，不作为主线新功能；部分细节与验证仍待确认，合并不代表已上线。

合并概览

2026-10-28（北京时间）｜合并 PR：38。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（27 条）

功能（2 条）

PR #69257

新增 datasketches_hll_downsample 标量函数，支持降低序列化 DataSketches HLL 的 lgK 并转换表示类型，可重写历史分区以缩减稠密草图存储，无需从原始数据重建。降采样不可逆且降低估算精度；使用前需升级全部 BE 节点。

PR #69668

FileScanner V2 新增原生 Arrow IPC 导入，支持增量解码、拼接流及压缩数据；Arrow Stream Load 和 CSV、TEXT、JSON 模式推断统一使用 V2 读取器。保留现有导入接口、表达式与校验语义，并完善嵌套空值、时间戳、VARIANT 及聚合状态的类型转换处理。

性能（7 条）

PR #67915

仅在云模式下，将 MATCH 查询的扫描任务按 segment 划分，复用 ANN TopN 的每段一个扫描器机制，避免同一 segment 被多个扫描器共享时重复遍历倒排列表。不含 MATCH 或 ANN TopN 的查询保持不变。

PR #68256

云端回收在单行集、批量行集及 tablet 路径中先判断是否需清理删除位图，非 MoW 行集跳过元数据查询；5000 个此类行集可避免 5000 次范围读取。同步完善回收基准的数据准备、缓存预热及读取计数，新增单测覆盖跳过逻辑并保留 MoW 路径，测试通过状态未确认。

PR #69639

重构 CAST 执行路径，在表达式准备阶段绑定列执行器，避免构造临时 Block 并经通用函数框架执行；通过 CastOptions 保存转换设置，执行时传入 RuntimeState。标量、复杂类型及 Variant 转换统一迁移，保留 FunctionCast 兼容适配器，行为不变。

PR #69646

优化 Parquet V2 的 TopN 扫描：依据首排序列的页脚统计优先读取有利行组，为 VTopNPred 增加 ZoneMap 判断，并在行组边界重查最新运行时界限，减少无效解码与读取。保留排序、空值及删除语义；被排除行组中的表达式和转换可能不再执行，相应异常也可能不再出现。

PR #69648

优化 SNII 小批量读取：本地索引近期小块读取平均耗时低于20微秒时，默认将不超过4个分段且总量不超过256 KiB的批次交由调用线程读取，减少线程池提交与等待开销，加速本地短语查询。远程、大批次及慢速读取仍使用线程池，支持配置关闭。

PR #69649

SNII 新增动态配置 snii_prx_zstd_min_saving_percent，默认仅在 zstd 比 PFOR 节省至少30%空间时选用 zstd，减少短语查询解压开销，代价是索引略增。仅影响后续写入或合并重写的段，设为0可恢复原选择策略。

PR #69665

FE 将外部 Catalog 退役资源关闭移至异步回收，元数据更新和缓存失效仍同步执行，减少慢关闭对串行日志回放的阻塞；隔离不同上下文的连接器缓存，修复删除、重命名时授权控制器发布竞态，并避免等待初始化时持有全局管理锁。日志格式不变，新增清理监控和并发单测。

修复（15 条）

PR #69028

修复清空表后重新导入时统计记录缺失、规划器将行数估为1的问题：导入事务可见时重建记录并累计行数，主从前端均可恢复。限制增量行数仅用于保持基表行数的索引，并按分析时间判断未分析状态。删除统计或变更表结构后，重建记录暂只包含后续导入行数。

PR #69460

修复 SEARCH DSL 三类解析问题：AND、OR、NOT 运算符支持大小写不敏感，并可作为字段值；ANY、ALL 中引号内的括号不再导致内容截断；EXACT、ANY、ALL 内容构建词项前去除 DSL 转义，避免匹配失败。新增 FE 单元测试及回归用例验证。

PR #69492

修复云模式下回收器在克隆和回滚场景中的共享存储检查逻辑，涉及这两类场景下的存储回收判断；正文未说明检查条件及行为变化，具体影响待确认。

PR #69494

修复 RANGE、LIST 分区表增量查询显式指定有效 changelog tablet 时因分区误裁剪而返回空结果的问题。通过表的 getPartitionIndex 接口解析索引，与扫描范围生成逻辑保持一致，并保留基础 tablet 兼容回退；补充相关单元测试。

PR #69594

修复 Nereids 中显式指定数据库执行 SHOW QUERY STATS 时的空指针异常，将数据库统计类型赋值移至数据库级处理分支，确保隐式和显式数据库查询均正确初始化结果元数据，并新增回归测试验证两种形式的结果结构。

PR #69630

修复 ASOF JOIN 匹配条件错误使用连接输出可空性的问题，保留子节点输入表达式的可空性，普通连接行为不变。新增覆盖四类 ASOF 连接及普通左外连接的前端单元测试，但未在本地运行，修复后尚未进行构建和运行时验证。

PR #69662

修复 FE 在隐藏删除标记过滤节点中丢失有效运行时过滤源信息的问题，保留有效的链式运行时过滤，避免误裁剪导致事实表额外扫描。隐藏谓词本身仍不视为有效过滤源，并补充规划器单元测试及 EXPLAIN 回归覆盖；真实 BE 过滤效果和生产性能未验证。

PR #69684

修复 Hive 连接器仅为 HMS 上的 Iceberg 表读取表注释的问题，统一读取各类表已有的 HMS 注释，使普通 Hive 表注释在表信息视图和 SHOW TABLE STATUS 中显示。缺少注释或表不可读时仍返回空字符串，沿用现有元数据缓存与刷新路径，不新增元数据 RPC。

PR #69693

修复启用 packed file 时小文件写入忽略 write_file_cache 选项的问题，使设置 disable_file_cache=true 的导入不再填充文件缓存，与直接写入行为一致；调用方未传入选项时保留原上下文配置，并移除仅供测试使用的缓冲区容量访问接口。

PR #69694

修复云模式下 Tablet 加密检查误报：解析文件系统前先跳过无数据段的空 Rowset，避免填补版本空洞时检查失败；同时正确返回检查错误，不再误报为部分数据未加密，并新增单元测试覆盖。

PR #69698

修复 MATCH_PHRASE_PREFIX 评分遗漏前缀展开词的问题，使用 tablet 级统计计算 IDF，避免分段方式影响评分；统一 V2、V3、SNII 的单词元前缀评分为 1，防止 score() > 0 过滤掉匹配行，并补充单元及回归测试。

PR #69703

修复 Iceberg 的 expire_snapshots 在并发元数据提交后，将位置删除文件和等值删除文件误计为数据文件的问题。构建文件类型映射前先刷新表，使分类与快照过期操作使用同一版本元数据，纠正删除文件计数，并补充两类删除文件的回归覆盖。

PR #69705

将 CachedRemoteFileReader 持有的文件块改为弱引用并移除占用标记，修复多读者场景下缓存块无法清理回收、查询读取中文件被误删的问题。读取期间临时持有强引用，缓存失效后重新获取，并替换同偏移的过期条目；同步修正四项云端文件缓存回归测试。

PR #69737

修复代码审查工作流未识别 refresh_token_invalidated、导致失效凭据被反复选用的问题，补充终止事件及错误输出识别，并将原因传递至隔离标记和失败通知。保留按令牌哈希隔离机制，避免旧请求误隔离替换后的令牌；通用401错误不触发永久隔离，并补充离线测试。

PR #69772

修复 IVM 物化视图流偏移因 changelog.ttl_seconds 过期后持续刷新失败的问题，将增量读取及前置分区重建中的此类异常归为 CHANGELOG_BROKEN。允许回退的刷新改用 COMPLETE 重建并重置流基线；严格 INCREMENTAL 仍失败，但明确报告原因。

测试（3 条）

PR #69291

补充 Paimon、Iceberg 连接器的单元及回归测试，覆盖规划器判定数据源为空的 INSERT OVERWRITE，验证仍执行事务并清空整表或指定静态分区，同时确认普通空 INSERT 无需事务，防止空覆盖被静默跳过；本次不改变运行逻辑。

PR #69701

隔离外部文件缓存三个非并发回归测试套件的状态，临时调整缓存、查询限制及磁盘阈值，轮询各缓存路径的模式标志，并确保断言失败时也恢复后端配置。通过嵌套阈值更新避免后台监控观察到无效顺序，提升资源压力场景下的测试稳定性，不改变产品行为及预期输出。

PR #69721

固定 Paimon Rust 读取器回归测试的 IN 运行时过滤器容量，并关闭基于选择率的过滤器裁剪，避免会话变量模糊测试导致过滤器被禁用而误报失败。保留超大过滤器边界测试及原有断言，测试结束后恢复继承配置，不改变生产行为。
