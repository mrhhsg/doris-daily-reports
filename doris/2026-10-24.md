# Apache Doris 合并日报｜2026-10-24（北京时间）

## 摘要

本日日报覆盖完整自然日，共19个已校验PR：master主线1个，release/branch-4.2回移18个，无other分支改动。master侧仅见一项性能优化，针对轻量DROP INDEX预检查改为单次快照扫描索引变更历史，减少持表写锁期间开销，并统一冲突匹配与报错提示。

release回移以修复和稳定性为主，不视作新功能：包括prepared statement协议兼容与资源清理、FQDN下BE地址变化后的心跳连接重建、云模式删除rowset重放与schema change可见性修复、S3流式元数据刷新、物化视图IF NOT EXISTS判断及改写谓词保留、flatten对NULL子数组处理，以及Nereids中score()/MATCH相关绑定、谓词推断和虚拟列深拷贝问题。另有回移将内部/外部扫描默认调度器切换及安全日志脱敏，后者减少凭据和敏感RPC信息落日志。

测试方面，多项回移附带回归或单元测试，覆盖prepared statement、FQDN心跳、日志脱敏、Nereids查询正确性及双写schema change稳定性；本次输入未见文档类PR。上述改动需经合入后验证，尚不能视为已发布或已上线。

## master 主线（1 条）

### 性能（1 条）

[PR \#69441](https://github.com/apache/doris/pull/69441)

该 PR 优化轻量 DROP INDEX 预检查：对索引变更任务历史只取一次快照并单次扫描，匹配表内任一分区的冲突任务，替代原先逐分区复制扫描全部历史的任务，降低持表写锁时的开销；同时把匹配条件抽取为共用方法，并将拒绝时的报错改为提示存在未完成的索引变更任务。

### 修复（15 条）

[PR \#69463](https://github.com/apache/doris/pull/69463)

回迁 prepared statement 协议修复到 branch-4.2：长数据上传不再返回响应并延迟错误到执行阶段，执行后清理数据；非 master FE 转发完整参数类型和值以支持缓存语句复用；空结果游标返回空游标并以 LAST\_ROW\_SENT 完成 FETCH；响应完成或转发结束后释放命令缓冲区。含回归和单元测试。

[PR \#69484](https://github.com/apache/doris/pull/69484)

在 branch-4.2 回合云模式修复：防止陈旧的删除 rowset 重放重新创建临时元数据，避免已清理的临时元数据被重放操作恢复；具体影响待确认。

[PR \#69497](https://github.com/apache/doris/pull/69497)

回填云端 schema change 场景修复：压缩在 TABLET\_RUNNING 前预填充聚合删除位图缓存，可能导致切换到 RUNNING 后仍暴露被覆盖行。改为在持有 tablet 头读锁且状态为 RUNNING 时才执行两种压缩后预填充，并适配 4.2 的分段 ID 与 BitmapKey API 调整参数化单测。具体影响待确认。

[PR \#69518](https://github.com/apache/doris/pull/69518)

在 FQDN 模式下，BE Pod IP 变更后，FE 可能继续复用指向旧进程的心跳连接。此改动通过 DNSCache 解析目标地址，并按解析出的 IP 区分心跳连接，同时保留原始主机名和后端 ID；地址变化时清理旧端点的空闲连接，移除后端时清理相关连接，失败时废弃连接后重试，从而避免心跳持续失败。

[PR \#69520](https://github.com/apache/doris/pull/69520)

在 branch-4.2 上回合合入 Nereids 相关改动，使 UTC\_DATE 与 UTC\_TIME 能在 FE 侧进行常量折叠，属于查询优化器表达式折叠的缺陷修复；具体影响待确认。

[PR \#69521](https://github.com/apache/doris/pull/69521)

[PR \#69531](https://github.com/apache/doris/pull/69531)
