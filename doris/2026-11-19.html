摘要

master 主线新增兼容 MySQL 的双密码机制，支持凭据在线轮换，须全部 FE 升级后使用；分词器 SIMD 化、外部 Parquet/ORC 扫描分片及增量物化视图外连接刷新得到优化，ANN 索引构建降低峰值内存。外部扫描升级需先更新 BE 并重建相关插件；Azure 新认证与 OSS 依赖尚不代表消费链路已接入。

主线重点修复云模式日志凭据泄露、Iceberg 加密元数据跨语句授权隔离、审计表升级及查询正确性问题，并改善 Variant 内存压力后的恢复能力。release 回移中，branch-4.2 涵盖 DATE 运行时过滤器、文件缓存恢复、备份解析和令牌脱敏等修复，并回移 Variant 键名转义能力，默认关闭且有全节点升级要求；branch-4.1 修复运行时生命周期保护及空集导入任务滞留，不作为主线新功能描述。

多项改动补充单元、SQL 回归、重启及 RPC 测试，CDC 测试夹具亦修复 ASAN 隐患；部分多 FE、Cloud 和真实 Azure 场景仍待验证。摘要未提供独立文档改动信息，部分回移的具体影响仍待确认；上述改动不等同于已上线。

合并概览

2026-11-19（北京时间）｜合并 PR：35。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（24 条）

功能（5 条）

PR #66115

新增兼容 MySQL 的双密码支持，允许修改密码时保留旧密码并单独废弃，实现凭据在线轮换；相关操作受 GRANT 权限控制，并增加双密码状态展示和旧密码认证计数。须全部 FE 升级后再使用，降级会丢失保留的旧密码。

PR #69981

云模式 Meta Service RPC 默认启用严格实例校验，调整 FE 请求处理，并将首个 FE 注册合并为单次 RPC。继续支持 cluster_id 部署，自注册无需额外配置；混合版本部署可临时关闭严格校验，FE 升级期间的虚拟计算组更新保留临时兼容。

PR #70497

第三方默认构建新增 Alibaba Cloud OSS C++ SDK V2 0.2.0，复用 Doris 的 curl 和 OpenSSL 安装头文件及静态库，为后续 BE 和 Recycler 原生 OSS 客户端集成准备依赖，本次不含运行时接入。已通过 macOS 本地构建与冒烟测试，完整第三方构建及 Linux 构建尚未验证。

PR #70657

共享对象存储层新增 Azure SAS 和 Microsoft Entra ID OAuth2 客户端凭据认证，提供统一配置接口、凭据校验及令牌管理，保留现有 SharedKey 行为。FE 配置及 Iceberg 等消费链路尚未接入，预签名 URL 仍仅支持 SharedKey；真实 Azure 集成尚未验证。

PR #70661

重构 BE 运行时过滤器合并器，移除所有权提示及直接接管分支，改为复制首个输入，并在 IN 转 Bloom 时先复制 Bloom 输入。过滤结果与分发路由不变，不涉及 SQL、RPC 协议或持久化格式变化。原独占路径增加锁内深拷贝，生产性能和峰值内存的具体影响待确认。

性能（3 条）

PR #70264

BE 的 english 和 basic 分词器改用 SIMD 向量化字节分类器，在保持分词结果不变的前提下优化处理速度。PR 报告两者速度分别约为 master 的 3.8 倍和 7.4 倍，并已进行单元测试及手动测试。

PR #70561

优化增量物化视图外连接刷新中的空值扩展行修复：满足唯一性等条件时，利用带符号增量替代修复前后快照检查，并在 LEFT、RIGHT、FULL 等值连接间共享键修复事件；浮点键等不适用场景保留原快照修复路径，保障结果正确性。

PR #70664

优化原生 Parquet/ORC 外部扫描：FE 默认按 512 MiB 粗分片，BE 按行组或条带细化并向 64 MiB 合并，新增会话变量控制目标大小；共享 ORC 元数据以减少重复初始化，保留查询结果及删除语义。升级需先更新 BE，并重新构建 API 35.0 插件。

修复（15 条）

PR #69784

修复 RBO 常量传播中 ExprId 复用导致空值属性冲突的问题：当子节点仍输出原列且常量的可空性不同时，分配新 ExprId 并更新上层引用，避免后续改写在 fe_debug 下触发检查并中止查询；其余情况保留列标识，兼顾物化视图匹配。

PR #70006

修复云模式 Meta Service 和 Recycler 日志及错误信息泄露敏感凭证的问题：隐藏 HTTP 管理 token，对 cloud_unique_id 的节点密钥及 AK/SK 脱敏，403 响应不再回显传入 token；补充单元测试验证敏感信息不会明文写入日志。

PR #70332

修复 Nereids 查询 Profile 持有优化器状态及修改共享统计信息的问题：浅拷贝物理计划并独立保存统计信息，列统计附录仅保留已知且有效的列，按全限定表名和列去重。不改变查询执行与估算结果，保留计划标识、运行时过滤器顺序及实际行数展示。

PR #70348

修复非主 FE 转发 SET、UNSET 命令失败后仍执行本地回调的问题：主节点返回 ERR 时跳过回调，避免报错后仍修改连接节点变量，并保留原始错误响应。新增失败与成功路径单元测试，成功命令行为不变；尚未进行修复后的多 FE 端到端验证。

PR #70393

修复云模式下 audit_log 升级因缺少会话上下文而持续失败、无法补齐审计列的问题。列顺序符合要求时采用轻量变更原位补列，避免整表重写；需重排时在具备权限和计算组的会话中执行，并补充单元及重启回归测试。

PR #70560

将表流在 SHOW FULL TABLES 和 information_schema.tables 中的类型由 VIEW 改为 BASE TABLE，保留 Stream 引擎标识，避免元数据客户端误识别为视图；桶检查改为仅筛选 Doris 引擎表。补充类型映射及回归测试，已发布版本不受影响。

PR #70591

修复历史多分段行集构建 ANN 索引时已完成资源和序列化缓冲区持续累积的问题，逐段释放构建资源并封存索引文件，降低峰值内存占用。覆盖常规及 SNII 构建路径，传递写入和关闭失败，保持整个行集成功后才发布的边界不变。

PR #70631

修复段级常量等值谓词未被识别为恒真的问题，避免 MOW ANN Top-N 查询不必要地回退到暴力扫描；为 UNIQUE_KEYS 快照包装表保留原表 MOW 属性，防止跳读过滤列时错误返回空结果，保持 DUP_KEYS 变更日志包装表非 MOW 语义。补充单元及回归测试，Cloud 模式验证仍待完成。

PR #70675

修复 Iceberg 加密元数据跨语句复用时绕过各自密钥授权的问题，将加密表资源及含文件密钥的清单限定在语句租约内，仅允许可共享的明文结果进入公共缓存。同一语句内合并活跃清单读取并保障取消安全；不同语句冷加载可能独立执行 I/O，加密 SQL 读取准入仍保持关闭。

PR #70706

修复 SHOW CHARACTER SET 和 SHOW CHARSET 拒绝 WHERE、LIKE 子句的问题，支持按输出列过滤字符集信息。LIKE 按当前 SQL 模式解析字符串并忽略大小写匹配；内部过滤沿用会话设置和预编译参数，跳过结果缓存及自动 SELECT 行数限制，并补充单元与回归测试。

PR #70723

修复 Variant 外部元数据加载遇到内存超限后，复用读取器持续返回旧错误的问题。加载失败时重置一次性执行状态，允许后续调用重试并跳过已合并路径，使 Compaction 在内存压力缓解后恢复元数据读取；相关单元及回归测试通过。

PR #70728

修复 Flight SQL GetSqlInfo 返回硬编码版本的问题，改为报告含短提交哈希的 FE 构建版本及已加载 Flight SQL 库的实际版本；库版本缺失或为空时返回 unknown，并保留信息代码以支持显式请求。新增三项 RPC 测试，覆盖完整、筛选请求及版本缺失场景。

PR #70731

将旧分支保护迁移为八个分支CI与评审规则集及一个共享安全规则集，并清除旧保护，解决同步失败导致过时TeamCity检查持续阻塞的问题。保留103项检查及既有评审要求，共享安全规则不允许绕过。迁移非原子操作，需协调Infra；完整校验及服务端同步尚未执行，具体影响待确认。

PR #70736

修复 GCC 15.1.0 在启用 unity 构建及警告视为错误时，行 ID 转换存储类型链接属性不一致导致的编译失败。将三种存储布局及共享目标类型移出匿名命名空间，赋予外部链接属性，定义仍保留在实现文件中，不改变运行时行为。

PR #70751

回退此前将分支保护迁移至 GitHub rulesets 的构建相关改动。正文未说明回退原因、涉及的规则范围及回退后的保护配置，具体影响待确认。

测试（1 条）

PR #70734

修正 BE CDC 单测夹具保存环境变量的方式，将 DORIS_HOME、LOG_DIR 和 JAVA_HOME 原值复制为可选字符串，并在各恢复点使用快照，保留未设置与空值的区别，避免环境变更后读取失效指针导致 ASAN 报错；生产 CDC 逻辑、断言和超时不变。

release 回移 / branch-4.1（2 条）

修复（2 条）

PR #70701

修复 BE 中 RuntimeState 访问的生命周期保护问题，使相关访问受任务上下文生命周期约束。该改动已回移至 branch-4.1，具体影响待确认。

PR #70710

修复 branch-4.1 中源数据被规划为空集的 INSERT INTO ... SELECT 提前返回后，导入任务长期停留在 PENDING 的问题。现将已注册任务标记为 FINISHED、行数为 0，避免内存泄漏及积压任务触发清理器删除全部已完成导入任务。

release 回移 / branch-4.2（9 条）

功能（1 条）

PR #70643

为 Variant 新增键名转义存储，保留含点号和百分号的字面键。开关默认关闭，启用后新表默认采用转义编码，需启用 V2 并完成全节点升级，既有表不转换。同时修复 V1 空值插入导致的释放后使用问题，更新兼容性测试；降级重写可能丢失键语义。

修复（8 条）

PR #70333

将 DATE 最小值/最大值运行时过滤器接收路径的类型修复回移至 branch-4.2，按 DATE 类型解码边界，避免误用 DATETIME 类型导致 DATE 扫描谓词构建时类型不匹配；其他类型行为不变，并补充 DATE/DATETIME 单元测试及 DATEV1 SQL 回归测试。

PR #70617

修复 Nereids 在字符串字面量算术运算中未遵循类型转换模式的问题，并将修复移植至 4.2 分支。正文未说明具体行为差异，具体影响待确认。

PR #70620

将 Nereids 添加谓词时合并已有过滤条件的修复移植至 Doris 4.2 分支，涉及优化器的过滤条件处理；未说明具体触发场景和查询结果差异，具体影响待确认。

PR #70642

将 BE 中 Segment::_footer_pb 数据竞争问题的修复回移至 branch-4.2 分支。正文未说明触发条件、修复方式及影响范围，具体影响待确认。

PR #70644

修复云模式下超大删除位图的元数据事务处理，将超大删除位图拆分到多个元数据事务中处理。该修复已移植至 branch-4.2 分支，具体影响待确认。

PR #70677

修复 BE 启动期间后台元数据尚未加载完成时，文件缓存同步恢复可能遗漏已有缓存或仅恢复单个块的问题。改为按 tablet 和文件哈希前缀查询元数据并恢复全部块，增加文件哈希不存在的断言，保持调用触发条件、键编码及现有 tablet 范围查询不变。

PR #70682

修复 BACKUP SNAPSHOT 指定有效 timeout 时，因 BackupCommand 修改解析器返回的不可变属性映射而在 Nereids 分析阶段失败的问题。改为先复制属性，再从可变副本中解析并移除属性；新增单元测试，验证 BACKUP SQL 的超时转换及内容解析。

PR #70692

移除 BE 心跳 INFO 日志及令牌不匹配错误响应中的集群令牌和认证令牌值，保留心跳事件消息与无效令牌错误，避免凭据泄露并传播至 FE 日志。新增单元测试，覆盖初始化、重复心跳、连续认证令牌更新及令牌不匹配场景，验证日志和错误响应不含凭据。
