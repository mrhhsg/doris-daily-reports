摘要

本完整自然日共汇总38个PR：master主线27个，release回移11个（branch-4.1 3个、branch-4.2 8个），未涉及其他分支。

master主线以查询与存储读取优化为主，包括MATCH查询复用ANN扫描路径、Rowset回收跳过非MoW delete bitmap读取、Parquet V2 TopN按ZoneMap裁剪行组、SNII小批次内联执行、CAST执行器重构及位置索引zstd选用阈值；功能侧新增DataSketches HLL降采样函数和Arrow IPC原生读取，并将Arrow Stream Load及多种格式的schema推断切到V2。重要修复覆盖SEARCH DSL解析、SHOW QUERY STATS空指针、ASOF连接空值推导、Hive表注释读取、加密表空rowset误报、Iceberg快照过期文件分类及运行时过滤器剪枝等，部分性能收益仍待确认。

release回移不视为新功能：branch-4.1回移涉及Paimon BLOB读取、CTE列顺序保持和MATCH_PHRASE_PREFIX打分异常修复；branch-4.2回移覆盖列间ZoneMap裁剪、表达式返回列校验、短路点查询分区谓词保留、Iceberg扫描schema字段对齐、合并块复杂类型及带默认值列惰性读取等修复。测试方面，多项改动补充了单元或回归用例，另有若干测试稳定性修复；摘要中未见明确的文档更新说明。

合并概览

2026-10-28（北京时间）｜合并 PR：38。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（27 条）

功能（2 条）

PR #69257

新增标量函数 datasketches_hll_downsample，可将序列化的 DataSketches HLL sketch 转为不超过目标 lgK 且可指定 HLL_4/HLL_6/HLL_8 表示的 sketch，支持 STRING、VARCHAR、VARBINARY 输入，空值原样返回，无需转换时返回原始字节；可用于重写历史分区以降低存储，但降低 lgK 不可逆且会损失精度。

PR #69668

为 FileScannerV2 增加原生 Arrow IPC 读取，并将 Arrow Stream Load 及 CSV、TEXT、JSON 的 schema 推断切换到 V2 读取器和共享入口；Stream Load 计划显式启用 enable_file_scanner_v2，同时保留原有加载表达式、过滤、默认值及 schema 诊断等行为。

性能（7 条）

PR #67915

云模式下，含 MATCH 的查询复用 ann topn 的按 segment 划分扫描器路径，使每个 segment 只构建一个 scanner，避免倒排索引先在整个 segment 上执行再与扫描器行范围求交、导致共享 segment 的 posting list 被遍历两次。不含 MATCH 或 ann topn 的查询不变，具体性能收益待确认。

PR #68256

云模式回收 rowset 时，单条、批量和 tablet 回收路径先判断是否需要清理 delete bitmap，非 MoW rowset 跳过其存储元数据读取，避免不必要的空范围读；同步更新 recycler benchmark 并新增单测覆盖非 MoW 跳过与 MoW 保留路径。具体性能影响待确认。

PR #69639

该 PR 在表达式准备阶段为 CAST 绑定列执行器，用 CastOptions 保存转换配置并在执行时传入 RuntimeState，将标量、复杂类型和 Variant 转换迁移到新接口，同时保留 FunctionCast 兼容适配器。属于 CAST 执行重构，行为不变，可减少临时 Block 和通用函数框架开销；具体性能影响待确认，回归测试未运行。

PR #69646

该 PR 为 Parquet V2 TopN 扫描增加 VTopNPred 的 ZoneMap 判断，按前导排序键的页脚最小/最大值优先读取更可能命中的行组，并在每个行组边界复查最新运行时上界以跳过无关行组；最终 TopN 结果与排序语义不变，但被排除行组中的表达式或转换可能不再执行。

PR #69648

将 SNII 小批次读取改为在调用线程内联执行：仅当索引位于本地文件系统、批次段数不超过配置默认 4、数据量不超过 256 KiB 且近期小读平均低于 20 微秒时生效；大批次、远程和慢读仍提交线程池。减少线程池提交与等待开销，从而加速本地短语查询。

PR #69649

新增可变配置 snii_prx_zstd_min_saving_percent，位置窗口仅在 zstd 相对 PFOR 至少节省指定百分比时才选用 zstd，默认30；可减少短语查询解压开销、提升查询速度，但新写段索引约增大2%，设为0恢复原行为。

PR #69665

将 ALTER、DROP、重命名外部 catalog 时旧连接器等资源的关闭从 journal replay 同步路径改为由 FE resource reclaimer 异步执行，元数据应用和缓存失效仍同步；并处理 drop/rename 并发、资源租约与清理指标，新增回放并发单测。可减少慢关闭阻塞后续 journal 条目，具体性能影响待确认。

修复（15 条）

PR #69028

加载事务可见时由加载自身重建表统计记录并累加所报行数，避免 TRUNCATE 后记录缺失使规划器把行数估为 1；并将 delta 仅累加到每基行保留一行的索引，未分析判断改用分析时间戳。具体性能影响待确认。

PR #69460

修复 SEARCH DSL 三处解析问题：AND/OR/NOT 改为大小写不敏感；引号内的括号不再提前截断 ANY/ALL 子句；EXACT/ANY/ALL 内容先反转义再构建词项。新增 FE 单测与回归测试，覆盖关键字值、小写 or、引号括号和转义精确词等场景。

PR #69492

该 PR 修复云模式下共享存储回收器在 clone 与 rollback 场景中的检查逻辑，避免相关场景下回收判断异常；正文未说明具体实现与影响范围，具体影响待确认。

PR #69494

修复在 RANGE 或 LIST 分区表上通过 TABLET 指定 changelog 索引有效 tablet 时，增量查询因分区裁剪枚举物理基索引而非 changelog 包装索引导致误删分区、返回空结果的问题；改为通过 getPartitionIndex 解析索引，与扫描范围生成及基表 tablet 兼容回退保持一致，并补充单元测试。

PR #69594

修复 SHOW QUERY STATS FOR 指定数据库时抛空指针异常的问题：将 ShowQueryStatsType.DATABASE 赋值移入数据库级统计分支，确保显式和隐式数据库查询都能正确初始化元数据；新增回归测试覆盖两种形式及无效库名报错。

PR #69630

修复 ASOF 连接匹配条件的空值可空性推导：最终 AdjustNullable 改用子输入可空性而非连接输出可空性，避免外层 ASOF 连接把 NOT NULL 输入表达式误标为可空；普通连接行为不变。已补充四种 ASOF 连接及 LEFT OUTER JOIN 对照的 FE 单测，但未在本地运行或做运行时验证，具体影响待确认。

PR #69662

修复FE中隐藏删除标记Filter导致运行时过滤器链被剪枝的问题：三表连接中仅含隐藏列的Filter此前会丢弃子节点有效源信息，使内连接可能基于无选择性统计剪掉RF0，增加事实表扫描；现复用propagateEffectiveSrc保留子节点REF/NATIVE类型，新增规划器单测与EXPLAIN回归覆盖。

PR #69684

修复 Hive 连接器表注释读取：此前仅 Iceberg-on-HMS 表从 HMS parameters 的 comment 取值，普通 Hive 表返回空。现所有表格式均读取该参数，无注释或表不可读时仍为空；information_schema.tables.TABLE_COMMENT 和 SHOW TABLE STATUS 可显示 HMS 表注释。新增单元测试，具体影响待确认。

PR #69693

修复打包小文件写入未遵循 write_file_cache 选项的问题：传入文件写入选项时始终复制到 packed append 上下文，使 disable_file_cache=true 的导入不再填充文件缓存；选项为空时保留原值，并移除仅测试用访问器。具体性能影响待确认。

PR #69694

修复 cloud 模式下 check_tablet_encryption 对含空 rowset 的加密 tablet 误报未加密：is_tablet_encrypted 先跳过无 segment 的 rowset 再解析 fs，避免空 resource id 解析失败；错误改以 ResultError 返回，不再被 Status 隐式转为 false。

PR #69698

修复 MATCH_PHRASE_PREFIX 的 score 计算：将前缀扩展词项的 tablet 统计 idf 计入短语得分，消除不同倒排索引存储格式间差异；单 token 前缀在各格式统一得 1 分，并补充单元与回归测试。该改动会改变相关评分结果，具体性能影响待确认。

PR #69703

修复 Iceberg expire_snapshots 在表元数据并发提交后，可能将位置删除和等值删除文件误计为数据文件的问题：构建文件类型映射前先刷新表元数据，使分类与过期处理基于同一元数据版本，并补充相应回归测试。

PR #69705

将 CachedRemoteFileReader 的 _cache_file_readers 改为保存 weak_ptr，移除 _owned_by_cached_reader 标志，使仅被读取器知晓的块不再计入使用中，releasable() 简化为 use_count == 1；读取时锁定弱引用避免块被删除，并替换同偏移的过期项。另修正四个云文件缓存测试用例。

PR #69737

修复 Code Review Runner 对永久刷新令牌失败的识别与隔离：除 refresh_token_reused 外也识别 refresh_token_invalidated，并将原因传入隔离标记和失败通知；按单个令牌哈希隔离，替换令牌后恢复资格，后续审查跳过被隔离凭证。仅工作流和离线测试改动，通用 401 仍不隔离。

PR #69772

修复 IVM 物化视图内部流偏移过期后每次刷新失败的问题：将过期错误归类为 CHANGELOG_BROKEN，允许回退的刷新改用 COMPLETE 重建并重置流基线，严格 INCREMENTAL 刷新则以该原因失败，同时覆盖增量前的分区重建失败路径。

测试（3 条）

PR #69291

该 PR 仅新增和移植测试，覆盖规划器判定源表为空的 INSERT OVERWRITE：验证空 INSERT 不开启事务，整表或静态分区覆写仍需事务并清空目标，补充 Paimon 与 Iceberg 连接器事务及回归用例。无行为变更，具体影响待确认。

PR #69701

修复外部文件缓存回归测试不稳定：为三个非并发套件建立隔离基线，关闭上层读缓存与继承的查询限制，临时抑制提前驱逐，改用磁盘阈值并轮询模式标志后再测量，通过临时配置助手恢复全部后端设置（含断言失败）；特性测试以零阈值和百分之一阈值进入相应模式，避免监控观察到无效的进入/退出顺序。

PR #69721

修复 Paimon Rust 读取器空值相等回归测试：在断言前设置足够的 IN 过滤器容量并关闭基于选择率的剪枝，避免会话变量模糊测试把 runtime_filter_max_in_num 设为 0 导致过滤器被禁用；超限容量测试保留 70000，继承设置由 finally 恢复，生产行为不变。

release 回移 / branch-4.1（3 条）

功能（1 条）

PR #69658

新增 Paimon BLOB 类型读取支持，查询返回含 inline 数据或描述符的 JSON；支持 blob-as-descriptor=true 仅返回描述符，并可用 fl_get_binary 获取二进制内容；新增 paimon_blob_max_size 限制内联大小，超限报错，附带回归测试。

修复（2 条）

PR #69676

该 PR 在 branch-4.1 上从 #69388 拣选修复，针对 FE 中重复 slot 场景保留 CTE 列顺序，避免列顺序错乱；具体影响范围与触发条件待确认。

PR #69699

修复 MATCH_PHRASE_PREFIX 查询在 score() 打分时报 UnionTermIterator 不支持打分的问题：联合迭代器的 norm 改为读取当前文档所在子迭代器的 norm，避免前缀展开词更稀有导致抛错；带 score() 的查询不再失败，打分逻辑未改。

release 回移 / branch-4.2（8 条）

功能（1 条）

PR #69659

该 PR 将主线的列与列表达式 ZoneMap 裁剪回移到 branch-4.2，使 a != b、a < b 等比较可利用两列区间裁剪 Native Segment 和 Parquet V2 Row Group。保留分支原有 BloomFilterProbe 接口及 NULL、NaN、字符串边界等保护，并排除隐藏版本列占位符；VARIANT 回归暂缓。具体性能影响待确认。

修复（5 条）

PR #69661

将 #62614 回合到 branch-4.2：在 VExpr::execute_column 中校验表达式返回列的大小和物理类型是否与声明结果一致，不一致时返回错误；子类实现迁移到 execute_column_impl 并使用只读选择器，同时适配 4.2 API，允许可空声明类型返回合法非空结果。具体影响待确认。

PR #69689

将针对短路点查询的修复回合到 branch-4.2：在短路点查询场景中保留分区谓词，避免分区过滤条件被丢弃。具体影响待确认。

PR #69696

该 PR 将 #65396 中合并块相关修复回合到 branch-4.2：构造 merge block 时按列唯一 ID 采用 FE 剪枝后的类型，未剪枝列继续保留物理类型，以修复复杂类型在合并块中被错误丢失的问题；具体影响待确认。

PR #69709

该 PR 回合修复 Iceberg 扫描 schema 的字段标识对齐问题：在 4.2 旧版 IcebergScanNode/IcebergUtils 路径中，按 Iceberg 字段 id 从查询固定的 scan schema 解析 identity 分区键和值，使 path_partition_keys、schema 信息与范围分区元数据保持一致。master 专属的 fe-connector 字典/小写化改动不适用于该路径。

PR #69713

将 master 分支的修复回合到 branch-4.2，解决 BE 对带默认值列的惰性读取问题，并包含回归测试。PR 正文未说明具体根因与影响范围，具体影响待确认。

测试（2 条）

PR #69687

修复回归测试 test_pushdown_explain 中 COUNT 下推断言的不稳定问题：由于 lo_shipmode 非空，该表达式恒为 0，简单聚合转常量规则会在异步行数缓存命中时将计划改写为常量，导致断言偶发失败；该补丁在计数断言前禁用此规则，与 master 对齐，仅稳定测试，未改变查询结果或规划器行为。

PR #69692

修复 branch-4.2 上 Parquet TopN 测试辅助代码：让其布尔谓词的可空性由输入推导，与生产构造逻辑一致，并补充整数、字符串输入在有无可空性及发布边界前后的覆盖。仅改测试夹具与用例，行为不变。
