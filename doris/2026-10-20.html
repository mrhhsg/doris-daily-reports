摘要

本自然日 44 个 PR 中，master 主线 25 个，重点在查询裁剪、可观测性与物化视图：zone map 支持同表列间比较裁剪；AI 函数新增按 fragment 汇总的 profile；_query_plan 可转发到 Master；增量刷新 MIN/MAX 物化视图新增 COUNT_AT_MIN 与 COUNT_AT_MAX；ANALYZE 接受 WITH SAMPLE 与 WITH HOT VALUE；Parquet profile 计数器改为按扫描实例初始化，覆盖 Hive、Iceberg、Hudi、Paimon、Fluss，降低小文件扫描的重复初始化与锁竞争，读取解码行为不变。

主线修复涉及 Iceberg 可空性展示、JSON 嵌套写入丢成员、Paimon 时间戳与 Kerberos、SEARCH BM25、云模式删除位图与事务协调，以及 MySQL 协议预处理语句的长数据上传、跨 FE 转发与空游标问题。

release 回移 19 个（branch-4.1 三个、branch-4.2 十六个）均为既有改动回合，不视为新功能，涉及 S3 无 scheme endpoint 默认 HTTPS、Iceberg/Paimon 纳秒时间戳与嵌套类型、SEARCH 评分与 SNII 压缩、JSON_SEARCH 转义、Variant 统计与解析配置、map 键校验、SegmentCache 计数、低基数 length() 修复，以及事务过期后删除位图重读、空与级联 CTE 计划裁剪，具体影响待确认；本日未包含 other 其他分支改动。

测试方面多项改动补充了单元或回归用例，但部分回移未完整运行测试、集群回归未执行；摘要未体现专门文档更新。合并不等同于已上线，实际效果需以构建、发布与验证为准。

合并概览

2026-10-20（北京时间）｜合并 PR：44。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（25 条）

功能（7 条）

PR #67774

扩展表达式 zone map 裁剪，支持同表两列比较（如 a != b、a < b），新增独立的 can_evaluate_slot_slot 能力判断，原生 segment 与 v2 Parquet reader 可按段裁剪；同时修复 v1 Parquet reader 浮点 NaN 标记未设置导致的错误裁剪，并对 v1 单列路径增加文件与表类型一致性检查。

PR #69046

为标量 AI 函数、文本/多模态 EMBED 和 AI_AGG 收集按 fragment 共享的统计，查询 profile 新增 AISummary 段，聚合各 backend、fragment 与执行尝试的最新上报并保留 fragment 明细，重复上报不重复计数；Token 用量包含重试和错误响应中提供方上报的值，覆盖计数区分未上报与显式零值。

PR #69144

该 PR 从上游 parallel-hashmap 回合 ARM 检测修复，在 Clang 的 AArch64 平台启用 phmap 内置 128 位整数支持，避免继续走回退的 64 位哈希混合路径，从而改善 ARM 上哈希集合查找相关路径；具体影响待确认。

PR #69182

为 _query_plan HTTP API 增加可选参数 forward=true，使非 Master FE 可通过现有转发机制把查询计划请求转发到 Master；省略或为 false 时保持本地规划，GET 与 POST 入口均支持，转发时内部改用 POST 以保留 SQL 请求体，并补充了转发相关单元测试。

PR #69225

ANALYZE TABLE 和 ANALYZE DATABASE 现在接受 WITH SAMPLE 与 WITH HOT VALUE 组合，不再报错；该标志仅对全量分析选择热值模板，样本分析是否收集热值仍由执行时各列所选估计器决定，线性估计器列不会因此收集，具体影响待确认。

PR #69242

BE 在 TabletSchema 从 PB 加载时改为按列名派生三个 binlog 隐藏列的位置，删除 thrift 与 protobuf 中承载这些位置的字段及对应 reserved 标记，并更新相关单测；现有读写路径行为不变，回滚到旧版本的影响待确认。

PR #69286

为增量刷新 MIN/MAX 物化视图新增 COUNT_AT_MIN/COUNT_AT_MAX 聚合函数，并用隐藏状态列记录极值行数；应用时在极值仍有存活行时保留旧极值，仅删除最后一个极值行才回退全量刷新，同时补充单元测试与回归测试。

性能（1 条）

PR #69300

将外部扫描的 Parquet profile 计数器改为每个扫描实例初始化一次，并通过表读取器包装层把不可变句柄传给 Parquet 读取器，同时合并 Variant 计数器的共享持有；覆盖 Hive、Iceberg、Hudi、Paimon 和 Fluss，减少大量小文件扫描时的重复初始化与锁竞争，读取和解码行为不变。

修复（16 条）

PR #66666

将 FE、BE 与 Cloud 的版本指标值改为 major、minor、patch、hotfix 四个固定宽度百分位分量编码，每段占两位十进制，使数值大小与版本顺序一致，并拒绝超出 0 到 99 的分量；指标名和标签不变，补充单元与跨进程回归测试。

PR #68084

修复云模式下延迟的 compaction 聚合可能覆盖较新删除位图、导致已删除行可见的问题：在每个 MS 事务中校验 compaction 输出范围，在写入或清理前拦截过期请求，并保留非 OK 错误检查，补充单元测试和双 BE Docker 复现环境。具体影响待确认。

PR #68100

修复云模式下事务过期后分页读取删除位图的重试逻辑：仅重启未完成的位图读取，保留已完成结果与字节计数，并在切换到另一位图时重置每个位图的三次重试预算，避免并发聚合导致截断或混合数据。

PR #68161

修复 Paimon 时间戳精度收窄场景：历史高精度值在最终物化时按当前精度截断而非四舍五入，避免跨秒舍入或提前丢行；Format V2 与 JNI 参与修复，受影响 p7-p9 ORC 选用 JNI，V1 实现不变。

PR #68307

修复 SHOW CREATE TABLE 输出 STRUCT 类型时丢失嵌套字段注释的问题，使 struct 内部字段的 COMMENT 能正确保留并展示，便于查看建表语句时获取完整字段说明。

PR #68640

修复 Iceberg 连接器元数据展示问题：ConnectorColumn 新增记录源端声明的可空性，DESC、SHOW CREATE TABLE、SHOW COLUMNS 和 information_schema.columns 现可正确显示 NOT NULL 约束，而读写模式仍保持可空以兼容旧数据文件缺列。

PR #68756

修复云模式下事务协调器改为按稳定的 backend ID 匹配，避免 BE 重启、重调度或 FQDN 地址变化后遗留 PREPARE 事务，导致 schema change 和 rollup 持续等待；ID 未知时回退地址匹配，并新增相关单元测试。

PR #69051

修复 BE 关键字 SEARCH 索引无法正确计算 BM25 评分的问题：保留关键字原值（含大小写和空白），为缺失词频或 norm 的 posting 提供默认值，并统一过滤器的短语资格判断，避免 MATCH 过滤请求未收集统计；同时修正 SNII 合取评分。SEARCH 配合 score() 现可覆盖 TopN 与 WAND 执行。

PR #69128

自动分区创建改为在批量创建前统计仅缺失的分区名，超限请求直接拒绝且不创建任何分区；发布前在表写锁下再次检查数量，防止并发请求超出上限。已发布且在限内分区不回滚，既有超限表不处理，序列化格式不变。

PR #69188

修复 Iceberg 表在标识分区字段被重命名后静态分区写入的问题：将 PARTITION (col = val) 中的列名按源列解析并物化，拒绝使用重命名的分区字段名并提示改用源列，非标识变换仍保持拒绝；同时在进入 BE sink 前把静态分区键改写为分区字段名，行为与 Spark 对齐。

PR #69231

将 gperftools 从 2.10 升级到 2.18.1，修复 macOS ARM64 大型 BE 因分支超出 ±128MiB 范围导致的链接失败，并同步更新 thirdparty/vars.sh；构建时设置 TCMALLOC_DONT_PREFER_LIBUNWIND=1，在 Linux ARM64 保持帧指针回溯，避免分析器死锁。

PR #69247

修复 Paimon 在 Kerberos 环境下延迟元数据读取的认证问题：对快照缓存、分区缓存键加载及完整时间旅行解析执行认证，复用元数据读取包装器，并从有效 Hadoop 配置（含规范化存储属性）选择存储认证器；HMS 与存储身份保持分离，保留缓存和空表快照语义，同时更新 CHAR 填充回归断言。

PR #69256

将 ALTER_REFRESH_INFO 和 ALTER_STATUS 的元数据修改与 journal 提交放在同一 MV 写锁内，锁释放后等待记录写入；getIvmInfo 改为无锁读取，并用 volatile 发布替换引用，isIvm 和 getNextSequencePrefix 不再等待 MV 写锁，同时修正 MTMVTask 注释。

PR #69288

修复 JSON_SET/JSON_INSERT 在嵌套对象中插入缺失成员时，丢失该对象后续兄弟成员的问题。原因是写入时多写了一对对象起止标记，提前关闭当前对象，导致后续写入静默失败。改动移除多余的这两个调用，直接向已打开对象追加键值；新增单元测试和回归测试，覆盖四种函数名及对照场景。

PR #69297

该PR修复功能测试编译失败：FunctionStateScope 改为 enum class 后，function_h3_test.cpp 中8处 open/close 调用仍用旧写法，现改为带作用域的 FRAGMENT_LOCAL/THREAD_LOCAL，测试逻辑不变，恢复 BE UT 构建。

PR #69314

修复 MySQL 协议预处理语句的长数据上传、跨 FE 转发与空游标问题：参数分片上传不再返回错误包，错误延迟到 EXECUTE；转发的 EXECUTE 携带缓存的参数类型、NULL 位图和完整参数值，避免经非主 FE 复用时报无值异常；空结果游标返回有效空游标，并以 LAST_ROW_SENT 完成 FETCH；响应结束后释放执行缓冲区。

测试（1 条）

PR #69248

在 search 文档 ID 回归测试的 fixture 中显式关闭 Variant 文档模式，避免会话默认启用 default_variant_enable_doc_mode 时表与 parse_to_variant 值模式不一致导致 INSERT 类型转换失败，使 V2 与 SNII 校验不再依赖会话默认值；仅改测试，无生产行为变化。

PR #69272

PR #69275

PR #69307

在 branch-4.2 上回合合入云模式修复：当事务过期后，如果删除位图读取尚未完成，将重新发起该读取，避免读取中断。具体影响待确认。

PR #69308
