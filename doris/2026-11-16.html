摘要

master 主线新增 VARIANT 点号键转义、Iceberg V3 unknown 列只读支持及 MongoDB 会话级读取策略；优化节点间异步缓存读取、外表慢缓存自适应绕过和空间函数，改善外表扫描及复杂多边形查询。点号键转义须全量升级 FE、BE 后启用，Iceberg 支持仍有配套与验证限制。

主线重点修复缓存并发崩溃风险、Catalog SSRF 检查遗漏、补充字符引发的凭据脱敏问题，以及空值过滤、夏令时分区裁剪、HAVING 与 LIMIT 组合导致的结果错误。连接器 UDF 改为本地执行，旧插件需重构建；已有损坏物化视图需重建。

release 回移方面，branch-4.1 承接空值语义、ANN 线程预算、空间函数优化及 Kuromoji 等改动；branch-4.2 承接 Kuromoji、Variant 安全修复和无根 Docker 环境适配；branch-4.1.2-recycler 调整打包文件筛选与切片回收。多项改动补充单元、回归测试，MongoDB 配套文档；部分测试未运行、真实无根环境未验证，若干回移影响仍待确认，合并不代表已上线。

合并概览

2026-11-16（北京时间）｜合并 PR：38。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（26 条）

功能（3 条）

PR #69995

新增建表时设置且不可修改的表属性 variant_escape_dots_in_keys，默认关闭；启用后无损区分 VARIANT 中含点的字面键与嵌套路径，避免路径混淆和重复条目错误。支持 CTAS 和异步物化视图继承，保留旧表行为；须全量升级 FE、BE 后启用，且不兼容 NestedGroup。

PR #70112

新增 Iceberg V3 unknown 列只读支持，含嵌套列，查询时按 NULL 处理并保留逻辑类型展示，使相关列可查询且支持 SELECT *。含 unknown 列的表禁止数据修改，仍不支持创建此类列。需配套 BE 改动；新增测试尚未执行，混合版本执行未验证。

PR #70493

为原生 MongoDB 查询新增读取偏好和读取关注级别会话变量，支持 SET 与语句级 SET_VAR 覆盖，并将生效策略固定到扫描描述符。默认 inherit，沿用 URI 或目录配置，不修改共享目录及元数据读取策略；补充参数校验、回归测试和文档。

性能（3 条）

PR #69071

异步文件缓存写入路径支持从其他 BE 读取缺失块，不再因启用节点间缓存读取而回退为同步写入；通过 IOBuf 避免中间数据复制。S3 竞速线程池默认由32增至64线程，修正节点间读取字节统计并新增监控指标。收益取决于源节点与缓存磁盘速度，慢盘下可能减少缓存保留量。

PR #69779

外表扫描按缓存路径和请求大小采样本地与远端延迟，可自适应绕过较慢的磁盘缓存，并限制探测频率与并发。远端失败或短读时回退本地，保持缓存与LRU行为；默认启用，不适用于HDFS，并补充Profile指标及回归测试。

PR #70302

优化 st_contains 等空间关系函数：每个扫描线程缓存常量形状的解码结果，避免逐行重复解码与校验；缓存多边形顶点经纬度，并通过边界框预筛减少边缘判断开销。主要改善含多顶点常量多边形的查询，结果保持不变，新增跨数据块缓存及边界容差测试。

修复（19 条）

PR #67720

移除 Segment 中存在并发读写竞争的页脚弱引用，统一通过 StoragePageCache 访问页脚，修复可能导致 BE 崩溃的风险及绕过 LRU 统计的问题；元数据大小统计不再读取页脚，避免无实际查询时刷新缓存热度，并补充并发淘汰单元测试。

PR #70335

修复 FE 的 TIMESTAMPTZ 常量查询显示：按会话时区校验年份范围 0–9999，与 BE 保持一致，保留历史时区偏移秒数，并拒绝时区转换后为负年份的默认值。将 FE 执行资格判断与结果格式化分离，避免云端 EXPLAIN 因显示越界失败，合法 UTC 边界值仍可写入并以 UTC 读取。

PR #70351

修复连接器列类型转换时丢失 TIMEV2 小数秒精度的问题，从 precision 字段读取声明精度，使 Hudi 的 time-millis、time-micros 列分别保留 time(3)、time(6)。未指定精度时仍保持为 0，并新增单元测试覆盖。

PR #70364

修复外部 Catalog 的 SSRF 安全检查遗漏：未显式指定端口的 HTTP、HTTPS 端点分别按默认端口 80、443 探测，避免内网地址绕过检查。覆盖 CREATE 和两条 ALTER 路径，保留显式端口优先及其他协议原有行为，并补充解析与 ALTER 拒绝内网端点的测试。

PR #70365

修复 Variant 类型转换后的 IS NULL 与 <=> NULL 过滤被错误下推、导致转换结果为空的行被丢弃的问题。此类空值判断保留在扫描表达式中，按转换结果过滤；其他下推不受影响，并新增回归测试覆盖相关空值判断。

PR #70366

修复 Nereids 在 SQL 含 emoji 等补充字符时，因码点与字符串偏移不一致导致的日志凭据脱敏泄漏、视图及物化视图定义重写错误、提示失效和 EXPLAIN PLAN 截取异常。统一转换偏移或直接读取令牌文本，并补充测试；已有损坏定义的物化视图需重建。

PR #70372

为连接器函数调用新增内置函数标识，阻止 JDBC 和 Elasticsearch 将 UDF 过滤条件误下推，改由 Doris 本地执行，避免远端函数不存在报错或同名函数导致结果错误。插件 API 主版本升至 31，旧版插件需重新构建，并补充回归及单元测试。

PR #70380

修复从 FE 转发 CTAS 时 TIMESTAMPTZ 用户变量类型和小数秒精度丢失的问题，解码时保留声明类型及精度，确保匹配行、列类型、UTC 值和时间差与直连主 FE 一致，并补充类型、字面量往返测试及 CTAS 回归测试。

PR #70409

修复 Nereids 添加谓词时反复嵌套过滤节点、导致优化不收敛及 FE 堆内存持续增长的问题。共享过滤构造方法合并相邻逻辑过滤节点的谓词，条件已齐备时复用原节点，并保留非空标记及原始 SQL 谓词来源，使受影响的条件 SUM 等查询正常完成重写。

PR #70428

修复 BE KVCache 返回裸指针导致缓存移除或销毁后调用方悬空引用的问题，改用共享所有权，并在所有缓存锁外创建对象。同键并发加载可独立推进，复用首个成功发布的值，但可能产生重复 I/O 和分配。新增生命周期与并发测试，因构建环境缺失尚未编译运行。

PR #70456

修复共享外部表发现逻辑吞掉连接器异常的问题，冷查表时保留认证、传输错误及重试行为，不再误报表不存在；成功查询但未找到表时仍保持原行为。补充 MongoDB M0 跨批次读取、凭据纠正、故障恢复和游标清理验收测试及说明，异常修复适用于共享发现路径上的 Connector SPI Catalog。

PR #70469

修复 FE 将 DATETIMEV2 转为 TIMESTAMPTZ 时，跨夏令时跳时区间被误判为单调转换，导致分区误裁剪和查询漏行的问题。复用本地时间跳时检查，保留涉及该区间的分区，同时保留固定偏移快速路径及区间外的裁剪行为，并新增回归测试。

PR #70478

修复云端 Merge-on-Write 单个删除位图超出 FDB 事务上限时写入失败的问题，允许超大加锁位图的分片跨元数据事务写入，并在最后的数据事务中校验已提交前缀，避免并发清理导致位图残缺却返回成功。保留原有发布边界及无锁覆盖的原子性，不改变协议和持久化格式。

PR #70494

移除云管理中未使用的 Recycler recycle_instance RPC，以及 MetaService alter_iam 的 RPC、HTTP 路由和相关实现。保留实例回收的认证 HTTP 流程、既有 IAM 数据读取兼容性及实例级 RAM 用户更新；升级后被移除端点不再可用。

PR #70501

修复 CREATE TABLE LIKE 复制 VARIANT 列时受会话默认值影响的问题。隐藏 default_variant_* 变量，仅开启调试点时允许设置并使用其值；正常模式下缺省属性采用内置值，升级前的全局设置不再生效，用户需在列定义中指定属性。同时修正嵌套组类型的属性输出。

PR #70512

修复 BE 最终去重流式聚合在 GROUP BY 查询同时包含 HAVING 和 LIMIT 时可能丢失有效分组的问题。将最终 LIMIT 应用到 HAVING 过滤之后，仅统计通过过滤的分组，并保留本地预聚合的输出计数逻辑；新增单元测试及 SQL 回归测试均通过。

PR #70518

修复 Nereids 字符串字面量算术运算未遵循 enable_strict_cast 的问题，移除重复的 BigDecimal 校验并沿用 CAST 规则。非法数字字符串在非严格模式下返回 NULL，严格模式下报转换错误；接受带首尾空格的有效 DOUBLE 文本，并补充单元及回归测试。

PR #70545

统一 FE 审计统计的参与后端跟踪，移除外部写入专用状态和重复协调器引用。FILES 插入通过共享语句执行状态登记协调器，复用审计与取消交接流程；参与者选择、报告等待及超时回退规则保持不变，不涉及协议或存储格式变更。

PR #70605

修复开放草稿 PR 无法通过授权评论触发 TeamCity 构建或写入跳过状态的问题，移除共享校验中的非草稿限制，保留开放状态、头提交及目标分支一致性检查。补充真实校验逻辑的入队与跳过路径测试，授权规则和文件过滤逻辑不变。

测试（1 条）

PR #70639

修正 FE 中 NestedGroup 会话默认值测试：启用调试点，使解析器应用测试专用默认值，正确验证含转义点号键的 VARIANT 表拒绝 NestedGroup 列；在 finally 中恢复原配置和会话值，避免影响后续测试。相关 115 项测试全部通过，不改变产品行为。

PR #70628
