## master 主线（32 条）

### 功能（7 条）

[PR \#68746](https://github.com/apache/doris/pull/68746)

为 SELECT INTO OUTFILE 和 TVF 输出文件新增可选参数 file\_name\_padding，用 0 填充文件名序号，取值范围 0 到 10；默认 0 保持现有行为，启用后可使文件名字典序与 ORDER BY 结果顺序一致，便于对象存储列举文件。

[PR \#68791](https://github.com/apache/doris/pull/68791)

新增可选会话变量 external\_scan\_consistent\_hash\_spread\_num，默认 1 保持原调度；设 0 时在查询计算组内所有合格 BE 间自动分散外部扫描分片，设大于 1 时启用文件缓存或一致性哈希时限制哈希候选数。分散模式按查询本地权重选最少候选并随机打破平局，禁用全局重分布，可能增加缓存副本。

[PR \#68825](https://github.com/apache/doris/pull/68825)

将 branch-4.1 的 Paimon Rust reader 前向移植到 master：BE 通过 Arrow C Data Interface 读取 FE 规划的 Paimon split，由默认关闭的 enable\_paimon\_rust\_reader 会话变量控制；不支持的扫描模式、表结构、凭证、投影、谓词或运行时过滤器会保守回退到原有 JNI reader。

[PR \#68921](https://github.com/apache/doris/pull/68921)

Iceberg 分区表写入改为按转换后的分区值哈希分发，每个分区由单个 writer 写入；be\_exec\_version 达到 18 才启用，否则回退随机分发。每 writer 的分区上限只统计其分到的分区，多 writer 时一次 INSERT 可跨超过 128 个分区，二进制等无法路由的情况仍随机写。

[PR \#68934](https://github.com/apache/doris/pull/68934)

新增 Iceberg timestamp\_ns 与 Paimon timestamp(9) 到 Doris TIMESTAMP\_NS 的双向映射，保留九位小数，覆盖读取、插入、CTAS、嵌套类型、分区、谓词下推和重写过滤。Iceberg 纳秒模式需格式版本3和 V2 读取器，Paimon 高精度读使用 JNI。

[PR \#69031](https://github.com/apache/doris/pull/69031)

将 Iceberg Java SDK 从 1.11.0 升级到 1.12.0，同步升级 Avro 与 caffeine，适配 DeleteFileIndex，为 ManifestFiles.read 传入 table.specs()。AWS 客户端改用 URLConnection 默认，滚升期间系统表暂不可用。

[PR \#69090](https://github.com/apache/doris/pull/69090)

为仓库新增 branch-4.2 分支保护规则，配置与已有的 branch-4.1 保持一致，用于约束该发布分支的推送与合并等操作，属于构建及仓库配置层面的调整，不改动引擎代码逻辑，具体影响待确认。

### 修复（20 条）

[PR \#67962](https://github.com/apache/doris/pull/67962)

修复 ColumnStruct 哈希入口忽略外层 ColumnNullable 的 null\_map 问题，使 NULL 结构体不再哈希隐藏字段负载，非 NULL 行哈希不变。影响：可空 STRUCT 键的 GROUP BY/DISTINCT 不再因隐藏负载不同而拆分相等 NULL 键；滚动升级及持久化 agg\_state 的哈希值变化可能导致路由或计数差异，具体影响待确认。

[PR \#68106](https://github.com/apache/doris/pull/68106)

将 get\_packed\_slice\_location() 提升为 FileWriter 虚方法并取代 is\_in\_packed\_file()，避免加密等包装写入器被向下转型引发未定义行为；CloudRowsetWriter 等改经 FileWriter 调用，空路径表示未打包。

[PR \#68348](https://github.com/apache/doris/pull/68348)

修复文件缓存清理时仍被引用的块仅被标记删除、无后台回收而长期滞留的问题：新增删除中块集合与回收巡检，由后台 GC 每轮按 QPS 限制回收，并补充计数指标；同时修正 remove() 处理下载中块时的迭代器悬空，调整 LRU 待更新清理时机与日志，并补充单元测试。

[PR \#68358](https://github.com/apache/doris/pull/68358)

修复启用扩展正则时Boost.Regex分支中regexp\_extract\_all及数组版本的零宽匹配推进逻辑：原先从旧搜索起点加一继续，导致同一位置的捕获被重复提取；现改为从匹配位置后一字节继续，匹配位于输入末尾时停止。非零宽匹配行为不变。

[PR \#68503](https://github.com/apache/doris/pull/68503)

修复 NTILE 桶参数校验：原检查在常量折叠前要求参数已是字面量，导致 1 + 1 等常量表达式被拒。现改为先折叠再校验，接受折叠为正整数的常量表达式，并新增重写后检查要求正整数常量；折叠结果为 0、负数、NULL、非恒定列及 LARGEINT 桶仍报错。

[PR \#68612](https://github.com/apache/doris/pull/68612)

修复 array\_sort 的 comparator 校验：lambda 参数必须返回 -1、0 或 1，分别表示小于、等于、大于；此前传入返回 BOOLEAN 的 lambda 会在 debug/ASAN BE 触发 cast 错误并中止，现在会给出明确错误。

[PR \#68639](https://github.com/apache/doris/pull/68639)

修复字符串转换为嵌套 MAP 时重复键未去重的问题：当 MAP 位于 ARRAY、STRUCT 或作为 MAP 的值时，原先会保留重复键两项，导致 size 计入两项且 element\_at 返回首项；现在与顶层 MAP 一致，重复键只保留最后一个值。

[PR \#68930](https://github.com/apache/doris/pull/68930)

修复条件缓存开启时，扫描谓词含不支持的 BITMAP、HLL、quantile state、VARBINARY、定长对象列或嵌套字面量，在生成摘要时失败的问题；现递归检查实际列及子列，返回摘要哨兵值 0，使相关扫描绕过条件缓存。普通标量、容器字面量及以可哈希字符串序列化的 AGG\_STATE 保持原行为。

[PR \#68962](https://github.com/apache/doris/pull/68962)

修复 Iceberg 读取无 field id 的 Parquet 文件（add\_files 或迁移文件）时整行全为 NULL 的问题：当 split 文件完全无字段 id 且表无可用的 name mapping 时，改用 v2 扫描语义并为顶层字段按序打上 1 到 N 的序号 id，使现有 BY\_FIELD\_ID 路径可解析；嵌套子字段仍为 NULL，ORC 不受影响。

[PR \#68964](https://github.com/apache/doris/pull/68964)

修复 Stream Load 在规划锁外读元数据导致的空引用失败：响应数据库 ID、表 ID 与基础 schema 版本改为在已有 generatePlan 读锁内填充，仅对首个计划表生效；HTTP load\_sql 改用 OlapTableSink 中已捕获的元数据，去掉额外元数据锁获取及超时中止分支。

[PR \#68978](https://github.com/apache/doris/pull/68978)

此 PR 修复 Decimal CEIL/FLOOR 在舍入因子与结果乘数超出原生 Decimal 范围时对非零定向舍入结果静默返回零的问题：正 CEIL 与负 FLOOR 现改为报告算术溢出，并提示将输入转换为精度足够的 Decimal；零结果与返回类型不变，测试覆盖 Decimal32/64 的向量和常量输入。

[PR \#68985](https://github.com/apache/doris/pull/68985)
