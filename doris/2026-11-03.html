摘要

本日日报覆盖65项PR。master主线新增Trino连接器对MongoDB ObjectId、JSON的支持，使用时需匹配FE、BE插件；优化Hive分区下推、云端物化视图元数据检查、稀疏VARIANT组装及schemata扫描，减少规划、元数据分配与缓存扰动。

主线修复外部读取、编码、索引评分、窗口聚合及云端死锁问题，并收紧远程JDBC驱动加载权限，降低错误结果、数据损坏和阻塞风险。Iceberg统计与Variant V2写入修复不自动修复历史数据，相关场景仍需重算统计或重写数据。

release回移均在branch-4.2，涵盖SNII解码与批处理优化、倒排索引、锁顺序、UPDATE元数据保护，以及表达式、日期精度、聚合和物化视图正确性修复，并补齐鉴权、更新安全依赖；这些是既有改动回移，不作为主线新功能。未提供other其他分支改动资料。

测试覆盖时间戳、Parquet、死锁、RPC错误，并增强ORC延迟物化结果校验；部分本地测试、完整回归及Hive集成验证尚未完成。资料未说明文档更新覆盖，部分收益与兼容性仍待验证，合并不代表已上线。

合并概览

2026-11-03（北京时间）｜合并 PR：65。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（26 条）

功能（1 条）

PR #69969

Trino 连接器新增 MongoDB ObjectId 与 JSON 类型支持：ObjectId 含嵌套字段映射为 VARBINARY(12)，并暴露默认 _id 列；JSON 映射为 Doris 原生 JSON，修正嵌套序列化并保留 SQL NULL 与 JSON null 的区别。使用时需在 FE、BE 安装匹配的 Trino 插件。

性能（3 条）

PR #67725

将符合条件的 Hive 分区等值和 IN 谓词下推至 HMS，避免提前加载全部分区；不支持的情况保守回退。保留后端残余谓词，完善物化视图分区覆盖及模式、快照一致性，并调整 INSERT 预加载与重试逻辑；选择性 EXPLAIN 的完整分区总数未知时显示问号。

PR #69717

优化 BE 共享头文件依赖，通过拆分声明、使用前向声明及将部分定义移至源文件，减少 protobuf、Thrift 等传递依赖。16 个重型头文件的依赖对减少 18.39%，降低编译依赖与重建范围，保持对象布局和行为不变；查询运行时性能的具体影响待确认。

PR #69914

优化 VariantAssembler，按列构建每行非空物化槽候选列表，组装时仅遍历候选槽；候选占比至少一半时回退全槽扫描。保持可见性与优先级规则不变，降低宽稀疏数据的组装开销，整列 VARIANT 扫描和稀疏数据压缩未见明显变化，并新增基准与单元测试。

修复（21 条）

PR #67899

修复 Flight SQL 表类型枚举读取失败及多类型过滤不准确的问题，支持大小写不敏感匹配及 TABLE、SYSTEM TABLE 别名，并保留授权范围。云模式从节点仅在请求 UPDATE_TIME 时刷新分区版本，避免普通表元数据查询受相关 RPC 失败影响。

PR #69617

FE 在创建、修改 CDC 作业或构造 cdc_stream 时，对 HTTP/HTTPS JDBC 驱动地址强制要求全局 ADMIN 权限，并在源初始化或驱动加载前校验。FROM-TO 与 TVF 路径共用权限检查，本地驱动权限要求及 S3 流式行为保持不变。

PR #69672

修复 Elasticsearch 扫描中源值与索引值不一致导致的过滤错误，完善数值、布尔、日期及数组解码和映射兼容性。按最终读取模式保留本地过滤，通过别名扫描保留过滤及路由语义；源值回退可能增加候选行读取，依赖新解码逻辑的计划需更新 BE。

PR #69697

修复 Arrow 时间戳读入 DATETIMEV2 和 TIMESTAMPTZ 时越界年份截断为错误日期的问题，新增 0000 至 9999 年范围及日期有效性校验。越界时间戳和无效日期 0000-02-29 现在报 DataQualityError，避免静默写入错误值，并补充范围及嵌套读取单元测试。

PR #69787

修复物化视图匹配仅识别字面量常量的问题，改为接受常量别名和常量函数等表达式，使查询中的常量输出无需在视图中存在对应列，避免因此错误拒绝候选视图。count(1) 等对字面量的聚合函数仍按原有逻辑处理。

PR #69790

修复未分词倒排索引上 MATCH、MATCH_ALL、MATCH_PHRASE 的 score() 恒为 0 的问题，现按完整字段值计算 BM25，与 SEARCH 一致，使关键词条件参与组合查询排序。关键词 MATCH_PHRASE_PREFIX 评分改为 1，等值和 IN 仍仅作过滤。

PR #69805

修复 FE 对预处理语句字符串参数的解码，避免 JDBC setBytes 和 ODBC 二进制绑定中的非 UTF-8 字节被替换。非法 UTF-8 载荷保留为二进制字面量，经 BE 转换回原字符串类别，维持函数与比较类型；有效 UTF-8 和 BLOB 行为不变，并修正重绑定及转发时的字面量哈希一致性。

PR #69836

修复 FE 外部视图在语句快照绑定阶段错误解析表句柄的问题，跳过已知视图的表元数据请求，同时保留底层表的正常快照固定逻辑。对视图不支持的 @branch、@tag 等扫描参数显式报错，避免静默忽略选择器；已添加相关单元测试，但未在本地运行。

PR #69888

修复 Iceberg ORC 写入时十进制边界符号和小数位数错误：按列声明恢复小数位数，并以最小大端编码保留原始有符号位，避免负数及含小数尾零的值被谓词错误裁剪。修复仅适用于新收集的边界，已有错误统计需重新计算或重写数据文件。

PR #69889

修复 JNI 字符串转换导致的 Unicode 损坏或截断，新增经校验的标准 UTF-8 与 UTF-16 双向转换，保留补充字符和内嵌空字符，非法编码显式报错。覆盖参数及统计映射、Paimon 元数据与溢写路径等，并支持无 Doris 线程上下文的转换，原有修改版 UTF-8 API 契约保持不变。

PR #69950

修复云模式下 tablet 加密检查与元数据写操作之间的死锁：提前读取 schema，并在不持有元数据锁时检查 rowset 快照，避免远程文件读取期间持锁，防止检查请求、合并及同步持续阻塞；新增单元测试验证检查时未持锁。

PR #69964

修复 quantile_union 在有界 ROWS 窗口由非空变为空或仅含 NULL 时沿用前一帧分位数的问题。每帧重置首输入标志和样本状态，使 quantile_percent 返回 NaN；逻辑重置保留样本向量容量供复用，clear() 仍释放存储。

PR #69966

修复云端物化视图分区补偿逐分区检查非空状态导致重复串行元数据请求的问题：对有效映射分区去重，以每批最多5000个调用批量接口，并跨关联表复用结果，降低规划开销、限制请求大小；保持查询语义、分区补偿、缓存处理及异常传播行为不变。

PR #69967

修复原生 Parquet 读取器拒绝合法 BOOLEAN 字典页的问题，支持读取两种字典编码的布尔列，将位打包字典展开为连续单字节值，并在分配前校验数据范围、保留字典索引检查。新增测试覆盖分页、过滤、跳过及编码切换；完整 SQL 回归执行仍待 CI。

PR #69970

将 FE 的 BDB JE 依赖升级至 18.3.18-doris-SNAPSHOT，对齐所有活跃目标分支要求的 Doris 快照版本。本次仅更新依赖版本，未执行本地构建或测试，具体影响待确认。

PR #69979

将自适应随机分桶导入中跳过非本地 tablet 的预期过滤日志从 WARNING 调整为默认关闭的 VLOG_DEBUG，避免大量分区及并行写入时日志刷屏，减少磁盘 I/O 和诊断历史挤占。保留诊断字段、tablet 选择逻辑及异常情况告警，不改变数据路径逻辑。

PR #69989

修复云端 Stream Load 引用已从 FE 元数据移除的 BE 时返回通用内部错误的问题，改为在生成执行计划前返回包含缺失 BE ID 的 ANALYSIS_ERROR，由既有 CDC 失败处理和自动重调度流程恢复，调度及位点行为不变。新增 RPC 测试覆盖错误状态、无执行计划及上下文清理。

PR #69990

将代码审查运行器及金丝雀运行时从 Codex 0.162.1 升级至 0.166.0，同步更新包版本与校验值；使显式策略容量错误沿用现有有界恢复机制，保留目标完成、同会话恢复和提交校验，其他错误仍不可重试。合并后运行时验证尚待完成。

PR #69999

修复通过 HMS Catalog 读取 Iceberg 表时，快照固定模式下丢失继承能力的问题。统一表结构委托逻辑并保留快照，恢复 Top-N 延迟物化、嵌套列裁剪及 UPDATE、MERGE 条件中 DEFAULT(column) 的正确语义。仅涉及主分支，不影响普通 Hive 表和 Hudi 表。

PR #70001

修复 Variant V2 稀疏键写入顺序与读取查找顺序不一致，导致 a-b 与嵌套 a.c 等字段投影错误返回 NULL 的问题。所有模式下均按完整路径字节排序，保留原有统计选择规则；仅影响新写入数据，读取逻辑不变，不增加读取开销，历史数据不会自动修复。

PR #70010

修复 information_schema.schemata 扫描时不必要的数据库对象加载：新增可选请求字段，使扫描仅获取数据库名称、不返回无用 ID，减少大型外部目录的对象缓存扰动和临时元数据分配。保留权限、模式过滤及 SQL 结果语义，兼容旧版 FE、BE 和需要 ID 的调用方。

PR #70059

将 ORC 延迟物化回归测试从 Profile 精确计数断言改为与关闭相关优化的扫描进行完整行结果对比，避免空扫描器导致计数缺失而误报。覆盖两项开关的四种组合及六类谓词，检查期间禁用缓存并确保恢复会话设置。不改生产代码，尚未完成 Hive 集成验证。
