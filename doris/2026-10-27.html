摘要

master 主线兼顾功能增强与稳定性：BE 非流式窗口函数新增受开关控制的溢写路径，Iceberg REST 外表增加 tbl$labels 系统表，外部 Hive/Iceberg 扫描引入有界公平调度与元数据预取，并新增连接器安全 SPI、禁用 LOCAL TVF；同时修复 SNII 内存记账、LIST 分区短路查询、FE 转发会话变量丢失、Variant 解析崩溃、ALTER TABLE 路径误判、ORC TopN seek、云模式事务提交竞态、分区统计 numNulls 重复缩放，以及 Parquet FLOAT16 转换在旧版 libstdc++ 下的编译问题。文档修正开发环境 Dockerfile 路径，多项改动补充单测与回归测试，主要影响查询正确性、编译与升级兼容性及外表访问行为。

branch-4.1 与 branch-4.2 的改动均属回移，不视为新功能，以修复和默认行为调整为主：MemTable 内存统计改用 allocate_shared 与 DorisVector 跟踪、自动分桶在统计缺失时应用最小桶数、事务提交重试遇已提交时改为惰性发布并重读可见状态、导入与 HTTP 查询诊断日志脱敏、有序 GROUP_CONCAT 降序空值排序修正；另含禁用 LOCAL TVF、Iceberg 删列校验、ASOF JOIN 可空性、Iceberg REST 嵌套命名空间并发删除、外表元数据缓存刷新、FILE 类型支持与 MOW 版本数默认关闭等。

本次未提供 other 其他分支改动。部分回移未说明具体性能收益与兼容性影响，相关能力实际生效仍取决于对应分支的合并与发布，尚待确认。

功能（8 条）

PR #68500

为BE非流式窗口函数增加受能力开关控制的溢写路径，支持全分区聚合、ntile、percent_rank/cume_dist等，新增spill_analytic_sink_mem_limit_bytes配置和窗口溢写统计，并补充回归与单元测试；不支持的窗口保持原路径。

PR #69135

为 Iceberg REST 外表新增 tbl$labels 系统表，可查询目录返回的对象级和字段级标签，字段名按当前表结构解析，已删除字段的 field_name 为 NULL；仅 REST catalog 提供该表，并补充单元与回归测试。具体影响待确认。

PR #69298

对外部 Hive 和 Iceberg 扫描引入有界公平任务调度，分离 split 与 metadata worker，支持查询取消和冷 Manifest 并发预取；新增 split_initial_batch_size 控制每个 backend 首次响应大小；修复关闭 enable_external_table_batch_mode 时仍可能走分区批路径的问题。文件格式、固定快照和全扫描结果保持不变，具体性能影响待确认。

PR #69588

新增连接器安全面 SPI：配置 SSRF 检查器时，CREATE/ALTER CATALOG 会探测 HMS 端点并拒绝含 ${...} 占位符的值；JDBC driver_url 门禁改由连接器声明。修复 SSRF net-hook 停止方法绑定错误，插件 API 升至 23.0；未配置检查器时端点门禁不生效，ALTER 需 provider 可用。

PR #69601

移植自 branch-4.2：从 master 移除 Hive ACID 事务读（含 insert-only）与独立 Avro 读取，LakeSoul 保持不支持；保留普通 Hive 扫描、Iceberg/Paimon 删除处理及 Iceberg/Hudi Avro 元数据依赖；退役的 skip_checking_acid_version_file 仍作为兼容空操作接受。

PR #69609

该 PR 属后端重构，将存储值的读取统一改为通过 StorageLayout 抽象进行，标题表明涉及存储读取路径的封装调整，但正文未说明具体动机、行为变化或测试覆盖，是否影响现有读写行为及性能具体影响待确认。

PR #69643

更新 lance-c 依赖至上游新提交，刷新源码归档名与 MD5，引入默认关闭的可选运行时 BTree 段选择器及预解码内存保护；现有 Doris 调用方行为不变，未启用该特性。具体影响待确认。

PR #69651

扩展 Elasticsearch 节点发现解析，显式支持 9.x 主版本及版本比较上限，仍拒绝未验证的更高主版本；新增混合 8.19/9.0 节点 HTTP 单测和可选真实 ES 9 兼容性测试，覆盖节点、映射、分片、分页、滚动及认证失败等场景。

修复（11 条）

PR #66880

修复 SNII 在 NULL 较多的段构建中过早释放 NULL-docid 内存记账的问题：将只可移动的 docid vector 和 Reservation 经 IndexFileWriter、SniiCompoundWriter 传递，增长时预扣几何扩容内存，待 NULL 位图消费完 docid 后再释放，避免交接时重复持有 vector 并保证内存统计准确，并新增单元测试验证。

PR #66926

修复 LIST 分区表短路点查询因分区谓词被剪枝移除而触发 IllegalStateException 的问题：在改写规则和后处理器中，将 isShortCircuitQuery 加入 skipPrunePredicate 豁免，保留分区谓词，使查询及服务端预处理语句返回正确结果，并补充回归测试。

PR #69273

修复语句从 follower 或 observer 转发到 master FE 时会话变量被丢弃的问题：为 disable_join_reorder 等 38 个影响查询计划与执行的变量标注 needForward，使会话级 SET 在转发路径上同样生效；新增单元测试校验这些变量出现在转发列表中并可回填。

PR #69434

修复混合版本升级中后端将 Variant V1 数据块按 V2 解析可能读取非法长度并崩溃的问题：将 variant_is_v2 元数据传入类型工厂，并在 Variant 反序列化入口拒绝 V1、返回明确错误。线格式和 be_exec_version 不变，未增加发送端能力协商。

PR #69444

修复 ALTER TABLE 同时包含轻量索引变更和需重量级 schema change 子句时误走轻量路径的问题：记录 requiresHeavyChange，存在重量级子句时改走 createJob 重量级作业，并同步调整 changelog 路径检查，补充单元测试。

PR #69465

修复 BE 外部表 TopN 延迟物化中 ORC 旧读取器 RowID seekToRow 异常未捕获导致 BE 终止的问题：在惰性和非惰性读取前捕获 seek 异常，携带文件与原因返回错误，保留 Doris 异常传播和错误分类，并补充相关单元与回归测试。

PR #69591

禁用 LOCAL TVF：在属性解析、后端选择与文件发现前无条件拒绝 LOCAL，FILE TVF 的本地存储路径及显式 LOCAL INSERT、已分析的 EXPLAIN INSERT 同样被拒绝，无配置项可启用（含 ADMIN/OPERATOR），底层存储实现保留。测试改为覆盖拒绝路径，13 项 FE 单测通过，回归套件未在本地执行，具体影响待确认。

PR #69606

修复云模式下事务提交重试与惰性发布并发时的竞态：在立即、最终及子事务提交路径中显式处理 COMMITTED，恢复已提交事务的惰性发布，避免重复发布行集或返回不完整分区版本；发布失败时仍保留提交成功并标记惰性提交不完整；回退到惰性提交前清空失败立即提交的响应数据，并补充相关重试测试。

PR #69621

将 Stream Load 现有的不区分大小写敏感请求头脱敏逻辑抽取到 HttpHeaderUtils，并应用于 COPY 上传与查询请求日志及 Stream Load 日志，Authorization 等敏感值统一掩码，fileName、label 等诊断字段保留，原始头仍供认证和转发使用，并补充相关测试。

PR #69636

修复启用分区统计时列统计 numNulls 被重复按选中分区行数比例缩放的问题：分区统计可用时不再二次缩放，仅在回退到表级统计时缩放；调整分区统计辅助函数返回 null 以区分统计范围，并新增单元测试覆盖。

PR #69666

修复 Parquet FLOAT16 转换在旧版 libstdc++ 下因 std::powf 未暴露而导致的 BE 编译失败，改用 std::pow 并显式包含 cmath，仍选用 float 重载，保持原有转换语义，不影响 Parquet 格式或 FLOAT16 编码。

PR #69379

采样分析模板删除了用于收集 hot value 的第三个 CTE，因此线性估计器（单分布列、单唯一键列及全表扫描回退）路径的 hot_value 返回 NULL，仅 DUJ1 模板继续收集热点值，相关参数也只对 DUJ1 填充。规划器因此不再选择倾斜感知聚合等形状，这只会影响计划质量，具体性能影响待确认。

修复（5 条）

PR #69593

该 PR 在 branch-4.1 上无条件禁用 LOCAL TVF 及使用本地存储的 FILE TVF，在属性解析、后端选择和文件发现前拒绝请求；显式 LOCAL INSERT 和分析后的 EXPLAIN INSERT 也被拒绝，且无配置可重新启用，底层存储实现保留。相关测试调整为验证拒绝行为并保留远程 FILE/sink 用例。

PR #69599

PR #69603

PR #69628

修复 Iceberg REST 在启用嵌套命名空间时，子命名空间被其他会话并发删除导致 NoSuchNamespaceException 中断整个 SHOW DATABASES 的问题。仅在子级递归边界捕获该异常并跳过已失效子空间及其后代，根级列举失败及其他授权或服务异常仍向上传播；改动含单元测试，与 master 实现一致。

PR #69629

该改动将 #69501 的修复回合到 branch-4.1，用于刷新外部表元数据缓存中过期的查找状态，避免陈旧的外部表查找信息继续被复用；具体影响范围与触发场景待确认。

性能（2 条）

PR #69637

将 #69600 回合到 branch-4.2：为 LogicalIndexReader::visit_prefix_terms 增加可选 accept_key 谓词，SniiIndexSource::expand_terms 把词项判断作为该谓词传入，使不匹配的词项在解码字典条目正文前即被跳过，词项匹配逻辑保持不变。MATCH_REGEXP、通配符、后缀和包含等无字面前缀模式的 SNII 词项展开因此更快，具体影响待确认。

PR #69638

修复（11 条）

PR #69408

修复直接 Iceberg Catalog 删除源列时仅校验当前分区规范的问题：改为用所有保留及历史分区规范校验目标列及其后代，拒绝不安全删除，保留未被引用的合法删除和 REST 原有行为，并在提交前复核元数据 UUID 以配合 CAS。

PR #69592

该修复在分支4.2于属性解析、后端选择和文件发现前无条件禁用 LOCAL TVF，并拒绝本地存储的 FILE TVF 及显式 LOCAL INSERT 与 EXPLAIN INSERT；无配置可重新启用，底层存储实现保留，相关测试调整以覆盖拒绝逻辑并保留远端行为。

PR #69616

修复 ASOF JOIN 匹配条件在 AdjustNullable 阶段被改用 join 输出槽位、导致输入非空槽位在 FE 表达式中变为可空并与 build-key 求值时列形状不匹配的问题；现改为保留子输入的可空性，其他 join 规则不变，并新增各类 ASOF join 的 FE 测试。

PR #69632

该改动回合到 branch-4.2，修复 metacache 中外部表查找状态未及时刷新、可能保留陈旧状态的问题，使外部表查找状态得到刷新。具体影响待确认。

PR #69634

修复 Iceberg REST 嵌套命名空间列举：当另一会话并发删除子命名空间时，仅在子级递归边界捕获 NoSuchNamespaceException 并跳过失效子级及其后代，避免 SHOW DATABASES 整体失败；根级列举及其他授权或服务异常仍会向上传播。

PR #69640

该改动将 #69506 回合并到 branch-4.2，在 BE 的请求诊断信息中对 HTTP 查询细节进行脱敏，避免诊断输出暴露查询内容；具体影响范围待确认。

PR #69652

BE 修正 MemTable 内存统计：RowInBlock 及其 shared_ptr 控制块改用 allocate_shared 配合 CustomStdAllocator，Tie 缓冲改用 DorisVector 跟踪，MOW 排序额外行引用也计入 memory_usage()，flush 阈值与内存限制更准确；新增内存跟踪单测。

PR #69653

修复自动分桶回退逻辑：当历史记录缺失、为空或不可用，或大小统计未到达时，对自动 Range 和动态分区应用当前 autobucket_min_buckets 最小值，避免新分区桶数低于配置；固定桶数和已有分区保持不变，并补充单元测试。

PR #69656
