# Apache Doris 合并日报｜2026-10-20（北京时间）

## 摘要

本自然日 44 个 PR 中，master 主线 25 个，重点在查询裁剪、可观测性与物化视图：zone map 支持同表列间比较裁剪；AI 函数新增按 fragment 汇总的 profile；\_query\_plan 可转发到 Master；增量刷新 MIN/MAX 物化视图新增 COUNT\_AT\_MIN 与 COUNT\_AT\_MAX；ANALYZE 接受 WITH SAMPLE 与 WITH HOT VALUE；Parquet profile 计数器改为按扫描实例初始化，覆盖 Hive、Iceberg、Hudi、Paimon、Fluss，降低小文件扫描的重复初始化与锁竞争，读取解码行为不变。

主线修复涉及 Iceberg 可空性展示、JSON 嵌套写入丢成员、Paimon 时间戳与 Kerberos、SEARCH BM25、云模式删除位图与事务协调，以及 MySQL 协议预处理语句的长数据上传、跨 FE 转发与空游标问题。

release 回移 19 个（branch-4.1 三个、branch-4.2 十六个）均为既有改动回合，不视为新功能，涉及 S3 无 scheme endpoint 默认 HTTPS、Iceberg/Paimon 纳秒时间戳与嵌套类型、SEARCH 评分与 SNII 压缩、JSON\_SEARCH 转义、Variant 统计与解析配置、map 键校验、SegmentCache 计数、低基数 length() 修复，以及事务过期后删除位图重读、空与级联 CTE 计划裁剪，具体影响待确认；本日未包含 other 其他分支改动。

测试方面多项改动补充了单元或回归用例，但部分回移未完整运行测试、集群回归未执行；摘要未体现专门文档更新。合并不等同于已上线，实际效果需以构建、发布与验证为准。

[PR \#69242](https://github.com/apache/doris/pull/69242)

[PR \#69286](https://github.com/apache/doris/pull/69286)

为增量刷新 MIN/MAX 物化视图新增 COUNT\_AT\_MIN/COUNT\_AT\_MAX 聚合函数，并用隐藏状态列记录极值行数；应用时在极值仍有存活行时保留旧极值，仅删除最后一个极值行才回退全量刷新，同时补充单元测试与回归测试。

[PR \#68084](https://github.com/apache/doris/pull/68084)

[PR \#68161](https://github.com/apache/doris/pull/68161)

[PR \#68640](https://github.com/apache/doris/pull/68640)
