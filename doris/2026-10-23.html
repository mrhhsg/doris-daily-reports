摘要

本日完整自然日覆盖55个PR。master 主线聚焦 Iceberg/Paimon 兼容、查询正确性与稳定性：新增 Iceberg DELETE 整文件元数据删除快速路径，修复 void 分区、保留列名、默认值精度、MODIFY COLUMN 可空性、JDBC V0 视图探测及 Paimon SDK 适配；并处理 VARIANT 内存、Parquet 空值映射越界、array_flatten NULL、嵌套裁剪 CARDINALITY、物化视图常量传播、UTC 折叠、S3 导入、FQDN 心跳和敏感日志等问题。

release 回移集中在 branch-4.1/4.2，按修复或测试处理，不视为新功能：包括 FE 漏洞依赖升级与未用库清理，BM25 并行扫描统计、RBO 常量传播 exprId、云模式 packed slice location 与陈旧路由、TopN batch rowid、JSON 推断大小写、多表例行导入属性和 t-digest 预分配等；另有 LakeSoul/Hudi 日志脱敏、元数据恢复后视图列查找、Iceberg JDBC V0 视图探测与 DROP 分发、同步物化视图改写严格模式、Cloud Broker Load RETRY 竞态及自动分区创建前校验等稳定性调整。

其他分支仅见 paimon-blob-4.1 的 Paimon BLOB descriptor 表选项、paimon_blob_max_size 会话变量和 blob 大负载处理 PR，信息有限，影响待确认，不属于 release 回移。

多项改动补充单测或回归测试，文档更新未普遍提及；部分收益待确认，合并不等于已上线。

master 主线（28 条）

功能（2 条）

PR #69176

为 Iceberg 表 DELETE 增加整文件元数据删除快速路径：仅当谓词可精确提取且候选文件全部匹配时，以元数据操作删除数据文件，不再读写删除文件；部分匹配则回退行级删除，UPDATE、MERGE 和分区范围删除不变。

PR #69343

将 Paimon Java SDK 由 1.4.2 升级至 2.1.0，FE 连接器与 BE JNI 扫描器共用同一版本；适配已移除的基于文件权限 API，保留目录查询授权与元数据缓存治理。修复可空主键下 NULL 安全 MERGE 匹配 UPDATE/DELETE 漏行，显式拒绝 latest-delta 选项，并同步时间戳转日期修正与扫描器测试夹具。

修复（22 条）

PR #68104

修复非等待版本读取在惰性提交未完成时可能缓存旧分区版本的问题：版本响应返回各分区 pending 状态，FE 对存在 pending 的响应不缓存，并且仅恢复 RPC 前捕获的 epoch 的缓存有效性。具体影响待确认。

PR #69007

在启用回收键检查时，commit_rowset 会跳过事务状态检查；现在针对删除谓词 rowset，在写入临时元数据前恢复既有事务状态检查，拒绝事务离开 PREPARED 后的陈旧删除 rowset 重放，避免重建 Recycler 无法安全清理的临时 rowset 键，并新增云单元测试覆盖提交后重放场景。

PR #69292

修复 score() 仅在 ORDER BY score() LIMIT 下可用的问题：单表且 WHERE 含 MATCH 或 SEARCH 的 SELECT 可在选择列、窗口函数和 ORDER BY 中使用 score()，支持 score() > x 或 >= x 的最小分数过滤；其他用法改为报错，不再按 0 求值。

PR #69301

修复向 Iceberg 和 Paimon 的 VARIANT 列写入含大量不同键的 JSON 批次时，因每行复制整批共享字典而导致 Arrow 容量错误或内存耗尽的问题。为表写入引入受限字典策略：当共享字典比该行的值大超过 1 KiB 时，按该行自身的键重新编码；小字典仍保持共享。Paimon 写入端改为按实际写出的行进行校验，并新增回归与单元测试。

PR #69321

修复 array_flatten 在展开嵌套数组时未检查子数组 NULL map、导致 NULL 子数组下隐藏元素被错误输出的问题；现在各嵌套层在组合 offset 前过滤 NULL 子数组范围，保留 NULL 标量元素，并通过 COW 共享最终叶子列以避免克隆。

PR #69323

该 PR 修复 LOCAL TVF 及本地存储 FILE TVF 的权限校验：在属性解析和文件访问前检查 ADMIN 或 OPERATOR 权限，并通过 checkAuth 复查且保留 Resource USAGE 检查，使普通用户在文件列举或模式发现前被拒绝；同时补充单元测试和 SQL 回归测试。

PR #69340

修复启用嵌套列裁剪时 CARDINALITY(ARRAY_MAP(...)) 因 OFFSET 元数据落到结构体元素层而报 E-3110 的问题；改为把 ARRAY_MAP 结果的 NULL/OFFSET 需求路由到输入数组容器，并保留 lambda 实际读取的元素路径，补充回归和单测。

PR #69358

修复 Doris 无法写入 format-v1 Iceberg 表的问题：这类表的分区 spec 含有已删除分区字段遗留的 void 字段。FE 端现在按原样绑定分区 spec，跳过 void 字段的源列校验，并在 INSERT 与 MERGE 路由及 BE 写入中不再解析 void 字段源列，直接写入 NULL。新增单元测试与回归测试，覆盖源列被删除及升级到 v2 后执行 DELETE、UPDATE、MERGE 的场景。

PR #69363

修复 S3 流式导入扫描元数据：LIST/ONE_TIME 保留对象修改时间，NOTIFICATION 使用本地时间作为缓存时间戳；外部文件 TVF 的 schema 推断在候选文件缺失时继续尝试下一文件，BE 跳过缺失文件时输出 INFO 日志，并调整通知回归测试检查顺序。旧通知覆盖后的过期大小问题仍未解决。

PR #69369

修复 BE 的 Iceberg 读取器解析 struct、list、map 字段复杂初始默认值 JSON 时未使用全精度标志的问题，避免其中 DOUBLE 被二次舍入后与 Spark 相差一个 ULP，并补充对应单元测试。具体影响待确认。

PR #69393

在 FE 中为 UTC_DATE() 及 UTC_TIME() 两个重载增加常量折叠，使用语句开始时的 UTC 时间，解决此类函数无法折叠导致 ts >= UTC_DATE() 等谓词不能分区裁剪的问题；具体性能收益待确认。

PR #69419

修复谓词推导在列等值替换时错误复制包含 MATCH、multi_match 或 SEARCH 的谓词的问题：这类谓词依赖所在列的倒排索引而非仅列值，复制会导致漏行与 score 翻倍。现在推导跳过此类输入，其他谓词仍正常推导，并补充单元测试与回归测试。

PR #69448

修复 Parquet 模式转换中可空转换失败产生 NULL 时可能越界写空值映射并导致 BE 崩溃：在逻辑转换前准备目标空值映射，保留源 NULL 与已有前缀；补充转换器单元测试和 S3 TVF V1/V2 混合模式差分回归，移除仅崩溃复现的 Groovy 套件，非空转换错误不变。

PR #69449

修复 Iceberg 分支保留时间映射：将 ALTER TABLE CREATE BRANCH 的 RETAIN 时间改为映射到 max-ref-age-ms，快照保留时间映射到 max-snapshot-age-ms，修正二者此前互换的问题，并新增单元测试覆盖选项转换、DDL 路由及生成的 Iceberg 快照引用元数据。

PR #69450

FQDN模式下，FE通过DNSCache解析BE心跳目标并按解析IP借用连接，同时在TMasterInfo中保留原主机名和ID；地址变更时关闭旧端点空闲连接池，清理已移除BE的连接池，并在心跳响应失败时使连接失效以触发重试，修复BE Pod IP变更后持续心跳失败问题。

PR #69452

修复 Iceberg JDBC V0 目录因不支持视图操作而导致的表发现和访问失败：将不支持的视图探测视为空视图列表或 false，并复用同一探测逻辑过滤表名；新增单元测试和 PostgreSQL V0 回归测试，覆盖列举、扫描、快照与时间旅行。

PR #69464

修复常量传播后物化视图改写丢失过滤条件导致的错误结果：当聚合上方的常量别名复用了下方仍被生成列的 exprId 时，ExpressionLineageReplacer 不再将其视为该 exprId 的血缘，补偿谓词因此保留并下推到物化视图扫描，避免年份等谓词被折叠为恒真而扫描全部数据。

PR #69466

修复 Iceberg 表 MODIFY COLUMN 在未显式写 NULL 时会将必填列变为可空的问题，并确保重述复杂列时其必填嵌套字段、列表元素和 map 值保持必填；仅显式 NULL 才放宽可空性。新增单元与回归测试，其他引擎读取影响待确认。

PR #69471

修复 Iceberg format-version 3 表上 ALTER TABLE 的 ADD COLUMN 和 RENAME COLUMN 未拒绝保留列名 _row_id 与 _last_updated_sequence_number 的问题。现在加载表后按实际格式版本校验，命中则报错，避免提交后隐藏列重名导致表无法读取；v2 表和嵌套字段不受影响，仍允许删除或重命名此类已有列。

PR #69472

移除 binlog、snapshot 和 master-token 相关 RPC 处理器在 DEBUG/TRACE 级别打印完整 Thrift 请求的日志，避免密码、凭据或 token 被写入 FE 日志；其余非敏感快照摘要日志保持不变，具体影响待确认。

PR #69478

Hudi JNI 扫描的 DEBUG 日志不再打印 S3A 访问密钥、密钥和会话令牌等凭证值，仅保留参数名并单独记录查询 ID 以便追踪；读取数据的 Hadoop 配置未变。新增单元测试校验日志不泄露普通凭证、桶级凭证和自定义令牌，并确认 Hadoop 属性值保持原样。

PR #69498

修复云流式作业 FE 回放更新日志时依赖 Meta Service 查询的问题：回放改为本地恢复 offset provider 状态和作业统计，暂停作业重启后保留 ALTER 的 offset 与日志统计；PENDING 调度前仍从 Meta Service 同步权威进度，失败则暂停作业。

PR #69459

修复回归测试 variant_p0/schema_change/test_double_write_when_schema_change 及其 v2 用例的不稳定问题：把插入字面量由 123111.0 改为整数形式的 123111，使 double 转 text 转换和直接写入 text 都得到 123111，并同步更新期望文件；这属于测试稳定性调整，不改变产品行为。

PR #69406

branch-4.2 回合修复 RBO 常量传播问题：为常量传播物化出的常量分配新的 exprId，避免与原有表达式标识复用。具体影响待确认。

PR #69413

PR #69415

回合移植 #69325：云模式复用 tablet vacuum 回收孤儿且已完成的 rowset 预热记录，覆盖无 stale 或 unused rowset 的 tablet，并释放过大哈希桶；保留运行中尝试与本地查询版本路径，新增宽限期配置，默认 3600 秒。

PR #69429

将批量 rowid 读取回移到 4.2 分支，修复 TopN 延迟物化在连接产生重复或乱序 rowid 时卡住的问题；按 segment 分组、排序去重后批量读取再回填，保持输出顺序和重复行。仅做静态检查，构建与回归测试未运行，具体影响待确认。

PR #69433

修复云模式 CloudReplica 陈旧路由累积：清理合并为每 replay 批次一次，rebalancer 每轮及 checkpoint 保存前按自身 Env 后端集合清理，支持每日时间窗口；回放主路由前校验后端是否仍注册，避免晚到 journal 误清同计算组有效 secondary 路由。

PR #69440
