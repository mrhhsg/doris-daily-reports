摘要

本日 master 主线共 5 个 PR，覆盖功能、性能与稳定性修复。功能方面，为纯追加、无聚合和外连接的 IVM 查询新增 DUP 明细模型，刷新由 upsert 改为追加，并在基表不再满足条件时明确报错并标记需重建。

性能方面，倒排索引优化非打分稠密合取查询，跳过全覆盖词项并流式位集求交，打分路径与结果不变，实际收益仍待确认；线性采样估计移除热点值收集聚合，降低采样开销，但相关列不再向倾斜聚合、shuffle key 裁剪和倾斜 join 提供热点值，主要影响计划质量。

修复方面，避免 BE 返回非法 UTF-8 时被替换字符解码导致 unhex 等过滤和投影错误，并修复 PipelineTask 停止流程中 _sink 的数据竞争。摘要显示新增了单测和回归测试，未见文档更新；当日仅涉及 master 主线，未提供 release 回移或其他分支内容。

master 主线（5 条）

功能（1 条）

PR #69168

该 PR 为纯追加、无聚合和外连接的 IVM 查询新增 DUP 明细模型：创建时依据基表与查询确定模型，刷新改为追加而非 upsert，省去 row-id、序列列、删除标记和计划签名；基表不再满足追加条件时刷新报 AnalysisException 并标记需重建。

性能（2 条）

PR #69172

优化倒排索引中非打分稠密合取查询：跳过覆盖全部行的词项，单词项直接写入结果位图，按位集无分支求交，并在按需读取源上分批流式求交；打分查询路径和结果不变，具体收益待确认。

PR #69209

该 PR 移除线性采样估计模板中为收集热点值而额外执行的聚合 CTE，使热点值返回 NULL，以减少采样分析开销；DUJ1 估计和显式 WITH HOT VALUE 的全量分析仍会收集。线性估计列不再向倾斜聚合、shuffle key 裁剪和倾斜 join 提供热点值，只影响计划质量，相关回归测试和报错文案同步更新。

修复（2 条）

PR #69143

Nereids 常量折叠在 enable_fold_constant_by_be=true 时，会把 BE 返回的非法 UTF-8 字节按替换字符解码成 U+FFFD，导致 unhex('FF') 等过滤条件和投影结果出错；现改为这类字符串常量不折叠、交由 BE 按原始字节求值，合法 UTF-8 仍照常折叠，并新增单测与回归测试。

PR #69208

修复 PipelineTask::stop_if_finished 在取消线程无锁复制 _sink、与 finalize 重置 _sink 产生数据竞争的问题；改为持生命周期锁复制 _sink，已 finalize 则返回，锁外调用 is_finished 和 unblock_all_dependencies，并新增单元测试验证。
