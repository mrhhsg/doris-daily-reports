摘要

本日日报覆盖完整自然日，共19个已校验PR：master主线1个，release/branch-4.2回移18个，无other分支改动。master侧仅见一项性能优化，针对轻量DROP INDEX预检查改为单次快照扫描索引变更历史，减少持表写锁期间开销，并统一冲突匹配与报错提示。

release回移以修复和稳定性为主，不视作新功能：包括prepared statement协议兼容与资源清理、FQDN下BE地址变化后的心跳连接重建、云模式删除rowset重放与schema change可见性修复、S3流式元数据刷新、物化视图IF NOT EXISTS判断及改写谓词保留、flatten对NULL子数组处理，以及Nereids中score()/MATCH相关绑定、谓词推断和虚拟列深拷贝问题。另有回移将内部/外部扫描默认调度器切换及安全日志脱敏，后者减少凭据和敏感RPC信息落日志。

测试方面，多项回移附带回归或单元测试，覆盖prepared statement、FQDN心跳、日志脱敏、Nereids查询正确性及双写schema change稳定性；本次输入未见文档类PR。上述改动需经合入后验证，尚不能视为已发布或已上线。

性能（1 条）

PR #69441

该 PR 优化轻量 DROP INDEX 预检查：对索引变更任务历史只取一次快照并单次扫描，匹配表内任一分区的冲突任务，替代原先逐分区复制扫描全部历史的任务，降低持表写锁时的开销；同时把匹配条件抽取为共用方法，并将拒绝时的报错改为提示存在未完成的索引变更任务。

功能（1 条）

PR #69508

branch-4.2 回移植：内部与外部扫描默认改用线程池调度器，可通过 enable_task_executor_in_internal_table 或 enable_task_executor_in_external_table 配置重新启用任务执行器；同时将 row-ID V2 拉取 RPC 在线程池工作线程中抛出的 Doris 异常转换为错误状态返回。具体影响待确认。

修复（15 条）

PR #69463

回迁 prepared statement 协议修复到 branch-4.2：长数据上传不再返回响应并延迟错误到执行阶段，执行后清理数据；非 master FE 转发完整参数类型和值以支持缓存语句复用；空结果游标返回空游标并以 LAST_ROW_SENT 完成 FETCH；响应完成或转发结束后释放命令缓冲区。含回归和单元测试。

PR #69484

在 branch-4.2 回合云模式修复：防止陈旧的删除 rowset 重放重新创建临时元数据，避免已清理的临时元数据被重放操作恢复；具体影响待确认。

PR #69497

回填云端 schema change 场景修复：压缩在 TABLET_RUNNING 前预填充聚合删除位图缓存，可能导致切换到 RUNNING 后仍暴露被覆盖行。改为在持有 tablet 头读锁且状态为 RUNNING 时才执行两种压缩后预填充，并适配 4.2 的分段 ID 与 BitmapKey API 调整参数化单测。具体影响待确认。

PR #69518

在 FQDN 模式下，BE Pod IP 变更后，FE 可能继续复用指向旧进程的心跳连接。此改动通过 DNSCache 解析目标地址，并按解析出的 IP 区分心跳连接，同时保留原始主机名和后端 ID；地址变化时清理旧端点的空闲连接，移除后端时清理相关连接，失败时废弃连接后重试，从而避免心跳持续失败。

PR #69520

在 branch-4.2 上回合合入 Nereids 相关改动，使 UTC_DATE 与 UTC_TIME 能在 FE 侧进行常量折叠，属于查询优化器表达式折叠的缺陷修复；具体影响待确认。

PR #69521

在 branch-4.2 回合修复前端 S3 流式数据源文件元数据刷新问题，改动来自 #69363；具体影响待确认。

PR #69531

在 branch-4.2 上挑选并合入修复：使用 CREATE MATERIALIZED VIEW IF NOT EXISTS 创建物化视图时，此前会跳过已存在的同步物化视图，该改动修正了这一判断行为，使同名同步物化视图能被正确识别。具体影响待确认。

PR #69534

在 branch-4.2 回合修复 flatten 函数：处理 NULL 子数组时跳过其中的隐藏元素，避免将隐藏元素纳入展开结果。具体触发场景与影响范围待确认。

PR #69535

将 LakeSoul 诊断日志修复移植到 branch-4.2：扫描器启动时仅记录查询 ID 和批大小，不再输出完整参数及对象存储凭据，FE 扫描节点也不再输出完整 catalog 属性；补充相关单元回归测试和 Maven profile。认证选项仍传给读取器，默认构建仍排除弃用扫描器，且 LakeSoul catalog 创建仍禁用。

PR #69539

将物化视图改写中常量传播后的谓词保留下来，避免改写时丢失该谓词而影响结果正确性；本次为回合到 branch-4.2 的修复，具体影响待确认。

PR #69543

修复 FragmentMgr 在执行日志中打印完整执行参数和外部查询计划的问题，改为仅记录查询与 Fragment 标识及实例数量，避免日志泄露凭据；执行与协议参数不变，并新增5项针对性日志测试。具体影响待确认。

PR #69546

该改动在 branch-4.2 回合合入安全修复，停止记录敏感的 FE RPC 请求日志，以降低敏感信息通过日志泄露的风险；具体影响待确认。

PR #69560

回移植修复 Nereids 逻辑计划深拷贝虚拟列：先为每个虚拟列分配新 ID，复制表达式并重映射排序键，withVirtualColumns 替换输出中的旧 slot，解决按 score() 或 ANN 距离带 LIMIT、含 MATCH 的 CTE 内联后报错。

PR #69561

将 #69419 回合到 branch-4.2：谓词推断不再把含 MATCH、multi_match 或 SEARCH 的谓词复制到相等列，避免倒排索引差异导致错误结果及 score 重复；并补充回归和单元测试。

PR #69562

将该修复回合到 branch-4.2：新增 BindScoreToOlapScan，把 score() 绑定到对应 OlapScan，支持无 ORDER BY score() LIMIT 的最小分数过滤，并拒绝无法绑定的用法；BE 侧表达式改为读取 score 列，最小分数仍与 TopN 一起下推。

PR #69548
