摘要

本日报覆盖完整自然日的13项PR。master主线新增统计收集扫描并发的动态配置，仅对新建统计查询上下文生效，不影响普通查询；修复ADMIN COMPACT TABLE缺少分区子句时的空指针异常，并让Cloud模式在可选版本字段读取失败时保留已获取的tablet统计，减少整批统计丢失。

release回移方面，branch-4.1纳入谓词合并、字符集查询筛选及协调器取消状态修复，并修正VARIANT路径缺失引发的score()报错和可空索引列取反查询漏行。Brotli安全修复需重建依赖并重新链接BE，完整BE构建及镜像复扫尚未验证。

branch-4.2回移Hive分区与Iceberg清单处理优化，具体性能收益未披露；同时回移取消状态、物化视图与ANN改写、时区显示及VARIANT检索正确性修复。MongoDB依赖归档不代表启用目录或扫描器。测试覆盖包括主线分区参数异常、Cloud混合批次及4.2索引求值场景；未提供文档更新信息。上述回移不作为新增功能，合并也不代表已上线。

功能（1 条）

PR #70938

新增两个可动态调整的 FE 配置，分别控制手动及自动统计收集 SQL 的普通扫描与文件扫描并发，范围为 0 至 256。默认每个扫描实例使用一个扫描器，设为 0 可恢复继承全局会话配置；变更对新建统计查询上下文生效，不影响普通查询。

修复（2 条）

PR #70288

修复 Nereids 中 ADMIN COMPACT TABLE 缺少 PARTITION 子句时触发空指针异常的问题，通过检查分区信息对象是否为空，恢复返回“未选择待压实分区”的预期错误，覆盖分区表和非分区表，并补充分区缺失、多分区及参数异常等单元测试。

PR #70895

修复 Cloud 模式下可选的 changelog 行数版本读取或解析失败导致整批 tablet 统计被丢弃的问题。现保留已读取的统计，仅省略受影响的版本字段并记录错误，覆盖传统与版本化元数据读取路径；统计本身读取失败仍使 RPC 失败，并新增混合批次测试。
