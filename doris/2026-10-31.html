摘要

本日 master 主线共涉及5项改动，以稳定性修复和测试、文档完善为主，未涉及新增功能或性能优化。Arrow 反序列化补齐不兼容数组类型及 STRUCT 字段数校验，遇到异常输入时返回错误而非导致 BE 崩溃；Stream Load 转换错误增加列名及源、目标类型，便于定位导入问题。ADBC Catalog 修复删除或修改时提前释放资源引发的 FE 崩溃风险，在不阻塞 DROP、ALTER 操作的同时，等待进行中的调用结束再释放资源。

测试方面，补充上述修复的回归或单元测试，稳定强制删表场景下的文件缓存清理测试，并验证 s3()、hdfs() 对 Avro 格式的既有拒绝行为及报错顺序。文档将 Iceberg 写入 P0 测试覆盖矩阵译为英文，方便非中文贡献者维护，未改变覆盖内容或产品行为。本日无 release 回移及 other 其他分支改动；上述合并不代表已上线。

2026-10-31（北京时间）｜合并 PR：5。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（5 条）

修复（2 条）

PR #69872

修复 Arrow 反序列化对不兼容数组类型及 STRUCT 字段数缺少校验的问题，使其返回错误而非导致 BE 崩溃，且不受输入校验配置影响。为 V1/V2 Stream Load 转换错误补充列名和源、目标类型，保留 V2 已支持的安全类型转换，并新增回归与单元测试。

PR #69874

修复删除或修改 ADBC Catalog 时，提前释放原生资源导致并发查询或统计信息加载触发 FE 崩溃的问题。客户端关闭后拒绝新调用，待最后一个进行中的调用结束再释放数据库和 Arrow 分配器，DROP、ALTER CATALOG 仍无需等待，并新增相关单元测试。

测试（2 条）

PR #69846

修复强制删表回归测试中文件缓存清理偶发超时的问题：在版本3数据加载后增加查询，确保各BE在删表前同步该版本，并断言行数为160000，验证数据可见，避免版本3缓存因未纳入回收范围而残留。

PR #69849

新增 FE 回归测试及表函数构造器单元测试，覆盖 s3()、hdfs() 使用 avro 和 AVRO 格式时在分析阶段报错，验证格式检查先于存储属性校验或文件访问，并校验不再支持 Avro 读取的错误信息。本次仅补充测试，不改变现有行为。

文档（1 条）

PR #69514

将 Iceberg 写入 P0 测试覆盖矩阵由中文翻译为英文，并与相邻矩阵的风险、编号、来源、影响和优先级等术语保持一致，方便非中文贡献者检查和扩展覆盖。原有风险项、覆盖行、用例、状态及测试套件名称均不变，不涉及行为变更。
