摘要

master 主线新增默认关闭的 HMS Iceberg v3 加密 Parquet 原生读取，需启用认证加密私有 RPC，暂不支持加密写入；优化前导通配符检索、常量数组重叠判断及 ARM64 MD5，并降低索引合并映射内存占用，但存在解码开销。重要修复覆盖 HLL 与嵌套空值序列化、ORC 含 NaN 聚合、Iceberg 缓存漏行及 Group Commit 表变更写入阻塞，提升结果正确性与写入可靠性。

release 回移方面，branch-4.1 涉及 MTMV、ORC 正负零裁剪、非分区表覆盖写及测试修正；branch-4.2 还涉及缓存失效、运行时过滤器、溢写配置和 Iceberg Google 认证安全修复。相关云端集成需先升级匹配的 BE 并重启，再升级 FE；这些属于回移，不是新增主线功能。

主线还调整 CI 构建与评审路由、报告展示和令牌目标地址校验。多项数据正确性修复补充单元及 SQL 回归，报告工具测试通过；部分原生构建、加密 SQL、云端集成和线上 CI 验证仍未完成，不能视为已上线。所提供摘要未见独立文档改动，部分回移影响仍待确认。

简化存储层容器凭证提供器构造，直接使用 SDK 常量读取四个容器环境变量，移除重复常量、端点选择日志及冗长注释，并复用测试配置。凭证链顺序、URI 优先级、令牌加载和刷新行为保持不变；因缺少 JDK 17，相关测试未编译运行。

PR #70697

新增 HMS Iceberg v3 标准加密 Parquet 数据及删除文件的原生读取支持，默认关闭，需验证后端能力并启用认证加密的私有 RPC；密钥发送前复核接收端，密钥仅限查询内使用。加密写入和加密表 SQL 结果缓存仍不支持，完整原生构建及加密 SQL 验证尚未完成。

PR #70949

新增独立 Python 命令，将已完成的 CI 构建生成可分享的静态报告，保留失败信息和用例计数，并支持日志、核心转储下载链接及调试回溯展示。支持本地预览和显式上传，23 项单元测试通过；生产流水线接入另行推进，真实代理上传与匿名访问仍待验证。

PR #70972

PR #70973

新增通过独立评论 run debugreview 触发云端代码审查的 CI 流程，提交当前 PR 快照并轮询结果，经验证后更新现有 code-review 合并门禁；预览或过期结果无法放行。支持关联并撤销阻断审查，部署前需更新服务并配置发布 App，等待期间会占用 Actions 运行器。

PR #70984

将 PR 评论触发的常规 TeamCity 构建改为经 FC 队列提交，使用 OIDC 认证，移除直连客户端及试点命令别名。保留原有命令语法和权限检查，提交失败或回执不完整时报告失败；运行器不再需要 TeamCity 凭据或直连服务器，FC 端仍需维护有效凭据。

PR #71030

支持通过仓库变量将 /review 评论路由至函数计算 FC，默认路由及手动触发行为不变。授权校验绑定 PR 信息和可选关注点；正式评审须发布结果并取得持久化回执后才完成门禁，预览或缺少回执时保持待定。上线依赖回执修复及工作端配置，可切回原执行器。

PR #71036

同步仓库与已部署的 CI 报告渲染器，按构建结果着色标题，分组展示失败与静默测试，提供日志链接及缺失提示；新增可选 Doris 运行日志筛选、脱敏和下载归档能力，兼容原有输入。流水线切换需另行操作，24 项独立测试通过。

性能（4 条）

PR #70373

优化倒排索引中以 * 或 ? 开头的通配符查询：提取模式中最长的连续字面量片段，让 CLucene 和 SNII 在转换或匹配前跳过不含该片段的词项，并原地比较单字节字符，减少匹配开销，查询语义不变。

PR #70645

优化 arrays_overlap：当恰有一个数组参数为常量时，每个执行片段仅构建一次只读查找集合并复用，避免逐行重复分配和插入；全常量表达式继续使用现有的整表达式结果缓存。

PR #70754

为 ARM64 的批量单参数 MD5 引入 NEON，每批并行处理八条消息；不足四条或长度严重不均衡时回退串行，保持摘要结果及 AVX2 路径不变。微基准显示吞吐提升，非端到端 SQL 测量；完整 BE 构建及 SQL 回归仍待验证。

PR #70890

CLucene 索引合并接入压缩行号映射，符合现有阈值的合并不再强制使用稠密映射，并通过借用映射避免写入器复制。默认配置和索引结果保持不变；可降低映射内存占用，但解码会增加耗时，实际开销取决于工作负载。

修复（8 条）

PR #67030

修复嵌套可空值的 Protobuf 序列化在分段追加数据时，遗漏无 NULL 区间空值映射的问题。现在每个区间均追加空值映射，避免映射短于数据列及反序列化时 NULL 位置错位，并新增嵌套数组往返测试。

PR #70446

移除数据导入（load）中已弃用的 auth_code 处理逻辑。标题和正文未说明兼容性变化及对导入行为的影响，具体影响待确认。

PR #70743

修复 Group Commit 在从节点接收 INSERT 时未遵守主节点表结构变更写入阻塞的问题。主节点在选择 BE 或返回缓存 BE ID 前检查阻塞列表，若表被阻塞则向从节点返回表结构变更错误，防止新写入加入现有批次并延迟 WAL 排空。

PR #70908

修复 HLL 在 MySQL 二进制输出、ORC 导出、Arrow 和 Protobuf 中使用序列化长度上限的问题，改为写入实际字节数，避免稀疏 HLL 携带尾部填充或未初始化数据而导致反序列化失败；Protobuf 读取新增畸形数据及 null_map 长度校验，不再静默插入空 HLL，并补充测试。

PR #70930

修复原生 ORC 元数据聚合在浮点列含 NaN 时 MIN/MAX 结果与逐行扫描不一致的问题。仅在统计信息的 sum 存在且有限时使用浮点边界，否则回退逐行扫描；补充相关单元及 SQL 回归测试，COUNT、整数边界和普通谓词裁剪保持不变。

PR #70936

修复 Iceberg 嵌套字段删除后以同名新字段和初始默认值重建时，旧条件缓存位图可能导致查询漏行的问题。将文件本地化谓词摘要纳入外部条件缓存键，避免谓词下推范围变化后错误复用缓存，并补充单元测试与回归测试，保留现有缓存排除规则。

PR #70983

修复云端评审在 GitHub Actions 轮询退出后无法更新合并门禁的问题：发布端验证评审后直接记录提交状态回执并触发聚合，使迟到的 P0/P1 结果仍可阻断合并，同时校验回执来源并保留后续结论顺序。相关回归测试已通过，线上交付与状态聚合仍需部署验证。

PR #71037

修复 TeamCity 提交脚本的目标地址校验：请求 OIDC 令牌前，必须确认完整 URL 与固定的香港 FC 端点一致；地址为空或不匹配时停止提交，避免令牌被发往其他服务。补充相关测试，迁移端点需同步修改固定地址、测试及仓库变量。
