# Apache Doris 合并日报｜2026-10-18（北京时间）

## 摘要

当日为完整自然日覆盖，共 16 个 PR。master 主线 7 个：FE 升级 Spring Boot 4.1.1、Framework 7.0.9 与 Jetty 12.1.14（保持 Java 17），并修复升级引发的编译失败（S3 事件通知改用私有 DTO、更新 Servlet 上下文导入）；连接器 SPI 新增 setTableProperties，使 Iceberg/Paimon 外部表 ALTER TABLE SET 可设置原生属性且单语句原子提交。查询与存储侧修复 search() 正则在打分时恒返回 1、SNII 流式 compaction 按序号查找写入器引发 BE 崩溃，并调整倒排索引短语位置默认值；另有无作用域枚举改作用域枚举的重构，宣称无行为变化但未本地编译测试。

release 回移共 9 个，均为既有改动向分支对齐，不视为新功能：branch-4.1 回合 CDC offset journal 去重持久化、短语位置默认行为对齐；branch-4.2 回合 Parquet V2 诊断信息增强、自适应随机分桶路由修复、默认日期值类型错误修复，以及分区倒排索引存储格式、MATCH/SEARCH 统一逻辑查询引擎等既有改动，并将版本号改为 4.2.0。

验证方面，多个回移 PR 标注 FE 单测因缺 protoc 未完成、回归未运行或待 CI 验证，仅少数有 BE 单测通过；master 侧补充了 BM25 打分、连接器属性与诊断的单测和回归。合并不等同于已发布，实际影响以各分支验证结果为准。

## 合并概览

2026-10-18（北京时间）｜合并 PR：16。按实际 merged\_at 筛选，主线与 release 回移分别统计。

## master 主线（7 条）

### 功能（3 条）

[PR \#68862](https://github.com/apache/doris/pull/68862)

FE 升级 Spring Boot 4.1.1、Framework 7.0.9 与 Jetty 12.1.14（Servlet 6.1/EE11），保留 Java 17；适配 API 并以请求包装处理尾斜杠；移除未用 AWS SDK v1、cglib，排除带入 Jetty 9 的 Hadoop YARN 客户端。

[PR \#69086](https://github.com/apache/doris/pull/69086)

新增连接器 SPI 方法 setTableProperties，使 Iceberg 与 Paimon 外部表的 ALTER TABLE SET (...) 可设置表原生属性，一条语句中的多个属性一起提交或全部不提交，auto\_analyze\_policy 不能与其他属性混用；另补充单元测试与回归测试。

[PR \#69174](https://github.com/apache/doris/pull/69174)

用作用域枚举替换平板路由、函数状态作用域、几何类型及其状态的无作用域枚举，把 Hash Join 模板参数和运行时过滤、WKB 接口的整型参数改为实际枚举类型；改用 constexpr 常量表示标量组索引，并移除未使用的 JSON 枚举。编码值与 DateTime 值类型不变，属重构、宣称无行为变化；未在本地运行编译和测试，具体影响待确认。

### 修复（4 条）

[PR \#69052](https://github.com/apache/doris/pull/69052)

修复 search() 中正则与通配符词项扩展在启用打分时固定返回 1 的问题：将打分标志传入 ExpandQuery，对每个匹配词项基于索引统计构建 BM25 scorer 并累加同一文档上的贡献；不打分的查询仍走批量位图路径。新增单元测试校验 BM25 分数，未新增 SQL 回归，具体影响待确认。

[PR \#69192](https://github.com/apache/doris/pull/69192)

修复倒排索引 SNII 流式 compaction：对兼容的 docs-only（T1）postings 直接合并，混合或不兼容来源及 gram 来源仍从原始列重建；同时改为按物理段 ID 查找目标写入器，修复按序号查找导致的 BE 崩溃。具体影响待确认。

[PR \#69199](https://github.com/apache/doris/pull/69199)

修复倒排索引短语位置默认值：新建精确索引及内置 lowercase 归一化索引默认仅存文档级 posting，自定义归一化器仍保留位置；BE 将缺省属性视为 false。保留 lowercase 索引的短语匹配与相关性评分，未涉及 CIR-22263 的合并热点。

[PR \#69232](https://github.com/apache/doris/pull/69232)

修复依赖升级后 FE 生产与测试代码的编译失败：将仍引用 AWS SDK v1 的 S3 事件通知改为用现有 Jackson 解析的私有 DTO，并保留原有时间解析、标量转换、UTF-8 URL 解码、尾随 JSON 拒绝及 SQS 确认边界；同时更新 Spring Boot 4 下 ServletWebServerApplicationContext 的导入包。未使用的异常元数据将被忽略，行为有变化，具体影响待确认。
