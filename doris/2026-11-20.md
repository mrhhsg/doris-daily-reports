# Apache Doris 合并日报｜2026-11-20（北京时间）

## 摘要

主线重点优化无评分 SEARCH 的候选行处理，减少无关扫描；运行时镜像默认基底升级至 Ubuntu 26.04，新增 UBI 9 构建入口并保留 Ubuntu 22.04 回退。修复 Routine Load 中止锁未释放、客户端停读时查询取消迟滞、lambda 规划及凭据脱敏问题，完善 Flight SQL 元数据排序与权限检查。lambda 体内子查询将统一报不支持，原先偶然可用的写法需调整。

release 回移方面，branch-4.2 纳入外表自适应缓存读取、CSV 解析、Hudi 扫描及 MATCH 扫描器拆分优化，并修复内存压力下查询等待与取消、聚合重复键、数值转换和运行时过滤器共享状态等问题；branch-4.1 与 branch-4.2 均修复 Variant 外部元数据内存受限后的重试。这些属于分支回移，不作为主线新增功能。

多项改动补充单测与回归用例，部分单测已通过，但若干回移未完成本地构建或 SQL 回归，镜像 amd64 执行及完整端到端验证也未完成。摘要未提供文档更新信息，部分修复影响范围仍待确认；合并不代表已上线。

## 合并概览

2026-11-20（北京时间）｜合并 PR：22。按实际 merged\_at 筛选，主线与 release 回移分别统计。

## master 主线（8 条）

### 功能（1 条）

[PR \#70770](https://github.com/apache/doris/pull/70770)

运行时镜像默认基底升级为 Ubuntu 26.04，新增独立 UBI 9 构建入口，为 FE、BE、MS 生成带 -ubi9 后缀的镜像。共享发行包校验与组件打包，分离系统依赖安装，保留显式回退 Ubuntu 22.04 的支持。UBI 在 amd64 上要求 x86-64-v2，amd64 执行及完整端到端验证尚未完成。

### 性能（1 条）

[PR \#70678](https://github.com/apache/doris/pull/70678)

优化作为独立过滤合取项的无评分 SEARCH，使其仅在扫描阶段其他过滤条件保留的候选行内收集结果，减少无关行处理。局部结果不写入 DSL 查询缓存，避免污染完整查询；返回行与评分保持一致，有评分 SEARCH、虚拟列及复合谓词内的 SEARCH 不受影响。

### 修复（6 条）

[PR \#70178](https://github.com/apache/doris/pull/70178)

修复普通及两阶段提交事务中止失败时 Routine Load 作业锁未释放的问题，确保中止回调成对执行并保留原始异常，避免作业命令、调度和事务发布挂起；同时按部署模式处理删除作业回调的保留与清理，补充锁释放、异常处理及回调清理测试。

[PR \#70607](https://github.com/apache/doris/pull/70607)

修复 FE 在 MySQL 客户端停止读取结果时，取消查询仍需等待网络写超时的问题。改用非阻塞写入和有界等待，最长每100毫秒检查取消状态；阻塞写入被取消或超时后关闭连接并阻止后续写入，普通查询取消仍支持连接复用，同时修正多语句响应处理并补充测试。

[PR \#70627](https://github.com/apache/doris/pull/70627)

修复外连接上方含 lambda 的投影在连接重排序时可能规划失败的问题：调整输入槽位可空性时保留 lambda 局部槽位，普通子节点槽位仍按原逻辑替换。新增用例及相关 FE 单测共14项通过，尚未运行端到端 SQL 回归。

[PR \#70634](https://github.com/apache/doris/pull/70634)

Nereids 在绑定 lambda 表达式体前统一拒绝其中的子查询，返回明确的不支持错误，避免规划阶段空指针、空白报错或误导性的未知列错误。此前偶然可用的非关联标量子查询也将被拒绝；普通 IN 列表及 lambda 体外用于数组参数的子查询不受影响，并补充相关测试。

[PR \#70705](https://github.com/apache/doris/pull/70705)

修复外部 Catalog 属性及 URL 中凭据脱敏不完整的问题，统一展示、审计与血缘的按值脱敏规则，补齐连接器凭据标注，并增加 FE 本地敏感名称正则配置。保留合法诊断路径和流式审计文件名，修正跨 FE 配置转发转义；不改变存储属性及实际连接。

[PR \#70735](https://github.com/apache/doris/pull/70735)

修复 Flight SQL 目录、Schema 和表元数据返回顺序不符合协议的问题，按协议键排序并保持目录与 Schema 的关联。GetCatalogs 复用 SHOW CATALOGS 可见性检查，保留会话角色，仅返回当前用户可见目录；新增顺序、权限与角色传递回归测试，MySQL 元数据行为不变。
