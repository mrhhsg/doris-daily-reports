# Apache Doris 合并日报｜2026-10-28（北京时间）

## 摘要

本完整自然日共汇总38个PR：master主线27个，release回移11个（branch-4.1 3个、branch-4.2 8个），未涉及其他分支。

master主线以查询与存储读取优化为主，包括MATCH查询复用ANN扫描路径、Rowset回收跳过非MoW delete bitmap读取、Parquet V2 TopN按ZoneMap裁剪行组、SNII小批次内联执行、CAST执行器重构及位置索引zstd选用阈值；功能侧新增DataSketches HLL降采样函数和Arrow IPC原生读取，并将Arrow Stream Load及多种格式的schema推断切到V2。重要修复覆盖SEARCH DSL解析、SHOW QUERY STATS空指针、ASOF连接空值推导、Hive表注释读取、加密表空rowset误报、Iceberg快照过期文件分类及运行时过滤器剪枝等，部分性能收益仍待确认。

release回移不视为新功能：branch-4.1回移涉及Paimon BLOB读取、CTE列顺序保持和MATCH\_PHRASE\_PREFIX打分异常修复；branch-4.2回移覆盖列间ZoneMap裁剪、表达式返回列校验、短路点查询分区谓词保留、Iceberg扫描schema字段对齐、合并块复杂类型及带默认值列惰性读取等修复。测试方面，多项改动补充了单元或回归用例，另有若干测试稳定性修复；摘要中未见明确的文档更新说明。

## master 主线（27 条）

### 功能（2 条）

[PR \#69257](https://github.com/apache/doris/pull/69257)

新增标量函数 datasketches\_hll\_downsample，可将序列化的 DataSketches HLL sketch 转为不超过目标 lgK 且可指定 HLL\_4/HLL\_6/HLL\_8 表示的 sketch，支持 STRING、VARCHAR、VARBINARY 输入，空值原样返回，无需转换时返回原始字节；可用于重写历史分区以降低存储，但降低 lgK 不可逆且会损失精度。

[PR \#69668](https://github.com/apache/doris/pull/69668)

为 FileScannerV2 增加原生 Arrow IPC 读取，并将 Arrow Stream Load 及 CSV、TEXT、JSON 的 schema 推断切换到 V2 读取器和共享入口；Stream Load 计划显式启用 enable\_file\_scanner\_v2，同时保留原有加载表达式、过滤、默认值及 schema 诊断等行为。

### 性能（7 条）

[PR \#67915](https://github.com/apache/doris/pull/67915)

云模式下，含 MATCH 的查询复用 ann topn 的按 segment 划分扫描器路径，使每个 segment 只构建一个 scanner，避免倒排索引先在整个 segment 上执行再与扫描器行范围求交、导致共享 segment 的 posting list 被遍历两次。不含 MATCH 或 ann topn 的查询不变，具体性能收益待确认。

[PR \#68256](https://github.com/apache/doris/pull/68256)

云模式回收 rowset 时，单条、批量和 tablet 回收路径先判断是否需要清理 delete bitmap，非 MoW rowset 跳过其存储元数据读取，避免不必要的空范围读；同步更新 recycler benchmark 并新增单测覆盖非 MoW 跳过与 MoW 保留路径。具体性能影响待确认。

[PR \#69639](https://github.com/apache/doris/pull/69639)

该 PR 在表达式准备阶段为 CAST 绑定列执行器，用 CastOptions 保存转换配置并在执行时传入 RuntimeState，将标量、复杂类型和 Variant 转换迁移到新接口，同时保留 FunctionCast 兼容适配器。属于 CAST 执行重构，行为不变，可减少临时 Block 和通用函数框架开销；具体性能影响待确认，回归测试未运行。

[PR \#69646](https://github.com/apache/doris/pull/69646)

该 PR 为 Parquet V2 TopN 扫描增加 VTopNPred 的 ZoneMap 判断，按前导排序键的页脚最小/最大值优先读取更可能命中的行组，并在每个行组边界复查最新运行时上界以跳过无关行组；最终 TopN 结果与排序语义不变，但被排除行组中的表达式或转换可能不再执行。

[PR \#69648](https://github.com/apache/doris/pull/69648)

将 SNII 小批次读取改为在调用线程内联执行：仅当索引位于本地文件系统、批次段数不超过配置默认 4、数据量不超过 256 KiB 且近期小读平均低于 20 微秒时生效；大批次、远程和慢读仍提交线程池。减少线程池提交与等待开销，从而加速本地短语查询。

[PR \#69649](https://github.com/apache/doris/pull/69649)

新增可变配置 snii\_prx\_zstd\_min\_saving\_percent，位置窗口仅在 zstd 相对 PFOR 至少节省指定百分比时才选用 zstd，默认30；可减少短语查询解压开销、提升查询速度，但新写段索引约增大2%，设为0恢复原行为。

[PR \#69665](https://github.com/apache/doris/pull/69665)

将 ALTER、DROP、重命名外部 catalog 时旧连接器等资源的关闭从 journal replay 同步路径改为由 FE resource reclaimer 异步执行，元数据应用和缓存失效仍同步；并处理 drop/rename 并发、资源租约与清理指标，新增回放并发单测。可减少慢关闭阻塞后续 journal 条目，具体性能影响待确认。
