摘要

本日覆盖49项PR，其中master主线31项。主线新增历史优化器统计、MySQL VECTOR同步和内部RPC双向TLS，并优化Lance下推与缓存、CDC快照内存、短字符串哈希连接、JSONB转换及Iceberg规划，旨在减少读取开销、改善查询性能。TLS默认关闭且不支持混合版本滚动升级；Lance同URI数据集删除重建后需刷新目录。

主线修复BM25评分、共享列改写引发的查询错误、ORC正负零过滤漏行、物化视图刷新与回退、参数转换溢出、日志凭据泄露及Iceberg分区和文件重写问题。测试覆盖单元、回归及集成场景，并推进70个BE单测文件的临时目录隔离；部分测试通过，但Changelog仍有四项云端测试失败，Lance相关失败也阻碍全量通过。摘要未提供明确的文档更新信息。

release回移包括branch-4.1的3项、branch-4.2的14项及branch-deltalake的1项，涉及查询正确性、崩溃防护、凭据脱敏、Iceberg视图、对象存储适配和Delta Lake只读支持，不作为主线新增功能。部分回移未构建或测试；未提供other分支改动，合并不代表已上线。

合并概览

2026-11-23（北京时间）｜合并 PR：49。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（31 条）

功能（7 条）

PR #69322

为 Nereids 新增历史优化器统计，使用结构化计划指纹匹配历史执行数据，并校验表统计与数据状态，避免复用过期或不匹配的统计。支持手动管理固定统计、持久化及 EXPLAIN 展示；当前指纹对表别名敏感，重命名后无法复用原条目。

PR #69896

在存算一体和存算分离模式下，成功提交可即时补充 Changelog 物理记录行数估计，周期统计继续校准保留行数；新增云端统计聚合、版本去重及恢复副本统计拉取。无需新配置，现有 SQL 和数据可见性不变；计数仍为估计值，四项云端行内容测试失败尚未解决。

PR #69948

流式作业新增 MySQL VECTOR 列同步支持，涵盖普通列及 VIRTUAL、STORED 生成列，映射为 Doris 浮点数组，支持快照、增量读取、自动建表和运行时加列。新增生成列不回填目标表历史行；补充 MySQL 9.7.4 冒烟及 VECTOR 集成测试，不代表完整兼容性认证。

PR #70271

重构后端 SNII 的 ANN 数据读写，直接实现存储接口并移除 CLucene 目录适配层，磁盘字节与读取次数不变。启用 inverted_index_snii_read_no_write_file_cache 时，SNII 文件中的 ANN 读取不再填充文件缓存。

PR #70693

为 OSS 内置私有 gRPC、BRPC 和阻塞式 Thrift RPC 增加双向 TLS，支持流量加密和可信对端证书认证，认证失败不回退明文。默认仍关闭，启用需协调节点配置；内部连接与外部服务策略隔离，本次不支持混合版本 FE/BE 滚动升级。

PR #70793

Iceberg 插件新增 worker_thread_pool_size 配置，可统一设置 FE 上所有 Iceberg Catalog 共享线程池的大小，用于清单规划和写入，需重启 FE 生效。显式配置优先于 SDK 设置，未配置时保留原有行为；非法值或已初始化线程池大小冲突会导致连接器初始化失败。

PR #70827

Lance 连接器新增精确匹配的谓词下推、无残留过滤时的 LIMIT 下推，以及无过滤 COUNT(*) 的清单行数读取，支持按标量索引分段规划扫描，减少不必要的数据读取。无法精确转换的条件仍由 Doris 执行，并新增扫描分片分组调试变量。

性能（6 条）

PR #70255

将 MySQL CDC 初始快照和仅快照读取默认改为 JDBC 逐行流式读取，替代整分快照分片缓存，减少读写路径中大分片、宽行的驱动端内存占用，使下游背压在读取期间生效。不新增配置，binlog 消费、偏移量和检查点格式不变；不保证进程整体内存上限，OceanBase 兼容性待验证。

PR #70404

让 JsonBinaryValue 持有并复用 simdjson 解析器，将转换对象移至严格及非严格 CAST 批量循环外，减少 JSON 转 JSONB 时的重复分配，JSON 函数、JNI 和 SerDe 批量转换亦受益。存储格式及错误、NULL 语义不变；尚未验证 Doris 端到端性能。

PR #70410

将 Iceberg 有界 Manifest 加载与解析缓存解耦，未启用缓存的受支持扫描也可复用按完成顺序预取，减少 SDK 轮询等待；精简查询元数据保留，保持共享缓存完整，并修复分区投影及删除关联等问题。单个、超大或数量未知的 Manifest 仍使用 SDK 流式规划，最终版本端到端性能收益待验证。

PR #70748

优化哈希连接的单个短字符串等值键：扫描构建侧键后，按需打包为4、8或16字节整数，复用数值哈希与桶链，减少字符串读取开销。超长或尾随零字节的构建键保留原路径，不可匹配的探测键转入独立空桶，保持NULL处理及JOIN结果不变。

PR #70795

优化 BE 扫描条件排序：将残余条件的首次成本排序移至扫描器初始化前，延迟运行时过滤器仅在追加新表达式后重新排序，避免无新增表达式时反复在共享锁内排序。禁用过滤器仍推进已应用计数，并新增扫描排序测试；收益取决于空检查次数。

PR #70830

Lance 目录通过共享 Session 和默认60秒的表访问缓存跨查询复用元数据，减少重复描述及存储请求；查询 Profile 新增各扫描表的 FE 元数据耗时、调用及失败次数。支持刷新失效，同 URI 删除重建数据集后需执行 REFRESH CATALOG。

修复（16 条）

PR #69313

修复 CLucene 倒排索引压实在删除或重分布文档后持久化词元总数错误的问题，纠正 BM25 平均文档长度及评分排名。对带范数但未存储词频的索引改用原始列数据重建，并检查同列所有索引以避免误选原生合并；此类重建会增加压实开销。

PR #69467

修复 FE 执行日志 SQL 脱敏丢失格式及部分日志泄露原始 SQL 的问题，复用审计脱敏规则，仅替换敏感值并保留换行、缩进和注释。统一 UTF-16 替换范围，避免补充 Unicode 字符导致凭据漏脱敏；脱敏失败使用固定占位符，异常日志不再携带原始输入，审计日志格式与分发行为保持不变。

PR #69732

加强云模式下 Meta Service RPC 的实例身份校验，拒绝未注册的 cloud_unique_id 及 instance_id 不匹配的请求，同时保持现有管理 API 兼容；补充有效请求和无效实例身份拒绝场景的单元测试。

PR #69817

修复过滤谓词降低估算行数后，其他列空值计数仅被截断、未按选择率缩放的问题，避免后续空值相关谓词行数估算失真，影响连接规划及运行时过滤器估算。同时拆分统计有效性校验与空值缩放接口，移除 OR 分支的重复归一化，并补充单元测试。

PR #69850

修复表流扫描行数被误估为一行或将保留日志存量当作增量范围的问题，按所选分区、扫描类型和消费基线估算行数，并将消费偏移与基表、变更日志计数一同持久化，支持本地回放与云端读取。补充统计缺失回退及估算溢出保护；云端新协议尚未在真实集群验证。

PR #70613

修复 Iceberg 写入有限 FLOAT/DOUBLE 恒等分区值时的精度丢失，改用最短往返格式，统一保留写入器分组、分区路径及提交元数据中的精度，避免分区误合并及过滤漏行。NaN 和无穷值处理不变，历史错误元数据需另行恢复；新增单元测试，完整 BE 与端到端验证尚未完成。

PR #70616

修复 Iceberg rewrite_data_files 将单个超大候选文件静默过滤的问题：分组内容判断改用最大文件大小阈值，分组大小上限仍用于装箱，确保超大文件进入重写执行器；补充规划器与过程测试，覆盖默认设置、大小边界及分组场景。

PR #70772

修复云端 MetaChecker 连接 FE 的 MySQL 失败时在警告日志中泄露数据库密码的问题。日志改为记录数字错误码、主机、端口、用户及实例 ID，不再输出密码和自由格式错误文本；密码仅用于连接尝试，避免通过该日志泄露凭据。

PR #70777

修复 BE 处理 NULL 时未遵循写时复制、意外改写共享列而导致查询结果错误的问题。哈希连接探测键先获取可写列，定长复合键直接在打包缓冲区填零，可空列过滤前检查独占性，避免破坏其他键或输出列的原始值；相关单元测试及 P0 回归测试通过。

PR #70799

修复异步物化视图默认 REFRESH AUTO 在 Stream 开关关闭或写时合并基表缺少历史变更日志值时创建失败的问题。将前置条件检查提前至 IVM 创建分析阶段，不满足条件时回退为普通异步物化视图并恢复原始属性；显式 INCREMENTAL 则在分析阶段报错，并补充相关测试。

PR #70804

修复增量聚合物化视图刷新遇到负计数时未能回退的问题。将相关断言错误识别为 NEGATIVE_AGGREGATE_COUNT，使 INCREMENTAL FALLBACK 和 AUTO 模式尝试全量刷新，同步重建视图状态并重置流基线；严格增量模式仍报错，并提供分类原因与断言详情。

PR #70824

修复 SUB_BITMAP 对单元素位图使用偏移量 -1 且截取数量为正时错误返回 NULL 的问题，使其正确返回唯一元素，与负偏移从末尾计数的语义一致。补充单元测试，覆盖有效偏移及越界偏移场景。

PR #70839

修复写时合并增量物化视图分区刷新未校验布局签名的问题，避免不同分区混用布局。每次分区写入前检查签名，严格模式遇到不匹配即失败，允许回退的请求则执行全视图 COMPLETE 刷新，成功后更新签名；同时覆盖增量刷新前的脏分区重建。

PR #70844

修复函数参数在校验前发生整数截断、符号变化或溢出的问题，覆盖 STRUCT 访问、子串计数、数组切片、位图、漏斗窗口及 ngram 大小。通过转换前校验、扩大计算位宽及提前限制长度，确保合法边界输入返回正确结果，非法参数报错，并补充 FE、BE 及回归测试。

PR #70862

修复 ORC 扫描中浮点 Bloom 过滤对正负零处理不一致导致匹配行遗漏的问题。在共享 SARG 适配层将两种零位模式加入同一 IN 叶节点，覆盖 FLOAT、DOUBLE 的等值、空值安全相等及 IN 谓词；补充真实文件单测与 SQL 回归测试，适用于 TVF 和 Catalog 的原生 ORC 路径。

PR #70881

修复本地审查凭证因模型白名单被拒的问题，新增接受 GPT-6.2 Astra/Sol 和 Gemini 4 Carbon/Neon 及指定推理等级，保留原有校验规则并补充单元测试。配套发送端更新后，符合权限要求的维护者可用这些凭证通过 code-review 检查，现有 PR 和 CI 审查不受影响。

PR #70840
