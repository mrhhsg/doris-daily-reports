摘要

本完整自然日覆盖32个PR，主线改动集中在VARIANT、Iceberg/Paimon与查询执行。新增H3经纬度与单元格互转函数，支持在Iceberg format v3 Parquet表写入顶层和嵌套VARIANT，并统一VARIANT解析错误语义、拒绝非法点号列名与复杂Map键；内外表扫描默认改用线程池调度，任务执行器配置默认关闭但可显式开启。

主线修复覆盖JSON_SEARCH路径转义、Paimon CHAR补空格、查询profile完成状态、Iceberg分区源列删除后的写入保护、IVM增量刷新与标记连接准入，以及row binlog tablet压缩策略误改等，并清理死代码、放宽ORC TIMESTAMPTZ年份下界。测试覆盖较广，涉及H3、Iceberg/Paimon VARIANT、IVM、外部目录和回归夹具；H3文档仍待补充。

回移方面，branch-4.1回合Boolean SEARCH分数隔离修复；branch-4.2回合外部类型映射、云端元数据key校验、BM25正则与通配符评分修复、倒排索引查询优化，以及条件缓存和COUNT_ON_INDEX谓词修复，并调整相关回归夹具。回移不视为新功能，部分修复的具体影响仍待确认。

合并概览

2026-10-19（北京时间）｜合并 PR：32。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（25 条）

功能（4 条）

PR #68447

该 PR 移除两个 VARIANT BE 配置，使解析错误仅由函数决定：非法 JSON、空字符串、重复键、超长键或嵌套过深时 PARSE_TO_VARIANT 报错，TRY_PARSE_TO_VARIANT 和导入返回 NULL；点号键与嵌套路径冲突时写入失败。JSON 格式导入中的普通字符串值改为 NULL，NOT NULL 列相关行按过滤统计。

PR #68610

将 BE 配置 enable_task_executor_in_internal_table 和 enable_task_executor_in_external_table 默认值改为 false，内外表扫描默认改用线程池调度；同时修复共享 LIMIT 计数、投影 padding 行丢失、row-ID RPC 回调异常及负计数下指针获取等问题，任务执行器仍可在 be.conf 显式开启。

PR #69018

新增三个H3 SQL函数，用于经纬度与H3单元格互转以及获取单元格边界，非法输入返回NULL；同时以静态库方式集成H3 4.5.0，并补充单元测试和回归测试，文档尚待补充。

PR #69194

该 PR 将 Iceberg VARIANT 写入能力移植到 master：支持在 format-version 3 且 Parquet 表上通过 INSERT、UPDATE、MERGE 等写入顶层和嵌套 VARIANT，并支持相关 DDL；新增计划校验器，拒绝把 VARIANT 隐式转换为标量的有损写入，且 VARIANT 默认值须为 NULL。

修复（17 条）

PR #65989

修复 information_schema.tables 扫描外部 Iceberg 表时，即使未查询 TABLE_COMMENT 也会逐表远程加载元数据的问题；现用 requiredColumns 判断，未投影该列时跳过注释填充，显式查询仍保留原行为，旧 BE 无 required_columns 时行为不变。

PR #68444

修复 information_schema.column_data_sizes 中 VARIANT 列字节数恒为 0 的问题：Variant 各写入器汇总内部写入器的数据页字节数，扫描端将无唯一 ID 及嵌入根元数据的子列元数据归入父 VARIANT 列，并更新相关黄金 Segment 文件。旧数据需压缩重写后才显示新大小。

PR #69044

修复查询 profile 完成状态在 spill 失败、并发渲染及 BE 上报合并时的错误：释放上报后状态改为 INCOMPLETE，序列化前冻结终态并在写失败时重置，pipeline 节点在写锁内挂载后再标记 BE 完成，避免丢失报告后误报 COMPLETE 或长期停留在 COLLECTING。

PR #69083

修复 Doris 写 Paimon 时 CHAR(n) 未补齐空格、与 Spark/Flink 写入产生重复主键和分区桶不一致的问题：写入行、嵌套值与静态分区值按码点补空格，UPDATE/DELETE、rowkind.field 及 ORC 表键不补齐；新增默认开启的会话变量可关闭补齐。

PR #69087

修复 BE 端两处问题：Segment TopN 达到本地读取限制时不再写入不完整的条件缓存，避免后续查询复用后跳过有效行范围；COUNT_ON_INDEX 改为仅拒绝引用列的残余谓词，无槽位谓词交由扫描器执行，使相关 count 查询不再报错。具体性能影响待确认。

PR #69088

该修复将 VARIANT 顶层列名含点号的限制移入共享列定义校验，使 CREATE TABLE、单条或批量 ADD COLUMN 及 MODIFY COLUMN 一致拒绝无效模式，并在 RENAME 修改元数据前拦截；同时更新回归测试和 FE SQL 单测。影响是 ALTER TABLE 不再接受此前可写入的点号 VARIANT 列名，其他类型的点号列名仍支持。

PR #69101

该 PR 在 FE 侧拒绝将复杂类型用作 Map 键，使 select map(named_struct(...), 'v') 报错 MAP key type must be a primitive type，避免构造键类型非法的 Map；测试与行为变更细节待确认。

PR #69121

修复 JDBC 扫描中 Oracle 会话时区设置误用于 OceanBase Oracle 模式目录的问题：OracleTypeHandler 接收表类型，仅对 ORACLE 目录通过 Oracle 驱动设置会话时区，OCEANBASE_ORACLE 保持原行为；新增单元测试覆盖，端到端因环境限制未验证。

PR #69170

修复 JSON_SEARCH 返回路径未转义成员键的问题：当键含点、方括号、以星号开头或为空时，用双引号包裹，使其可被 JSON_EXTRACT 等重新解析；新增 is_wildcard 区分通配符与字面星号键，接受显式空键 $.""，并调整 JSON_SET/JSON_INSERT 对数组的非索引末段处理及 [*] 输出。

PR #69210

修复 IVM 中基表带 sequence 列时，INCREMENTAL 刷新后更新行被删除标记吞掉而消失的问题：归一化时从基表扫描输出中屏蔽隐藏的 DORIS_SEQUENCE_COL，避免其与增量侧的序列列冲突导致 merge-on-write 选错值。已补充回归与单元测试，行为无变化。

PR #69211

修复增量物化视图缺陷：仅追加明细模型在检查内连接或交叉连接前先拒绝标记连接，并将两条规范化路径与明细增量重写器的准入条件合并到 IvmNormalizeCommonChecker。此前 EXISTS 或 NOT IN 被重写为标记连接时会被错误接受，但刷新无法由追加维护。

PR #69228

Iceberg 连接器的 CREATE DATABASE 现按 catalog 类型区分：JDBC 与 Glue 接受数据库 properties，仅 Glue 额外接受 location，JDBC 拒绝 location；Paimon 的 ALTER TABLE SET 在提交前拒绝 path 键（任意大小写），避免写入错误元数据。两者均新增单测与回归测试。

PR #69229

修复 Iceberg 分区字段源列被删除后 DELETE、UPDATE、MERGE 写入 NULL 分区删除文件并导致 Doris 后续无法读表的问题；现在在写入前返回明确错误，普通读取不受影响，同时补充 TIME 分区值解析和隐藏 row-id 列处理，并增加回归与单元测试。

PR #69238

清理 row binlog 多次重构遗留的死代码：删除 FE Replica 的 binlogSize 与 binlogFileNum、BE 未使用的常量方法及两个错误码；并在 protobuf 用 reserved、thrift 用注释退役已删除的字段 id，避免后续复用与旧版本持久化的 tablet meta 冲突。行为无变化。

PR #69240

修复本地模式下含 binlog.format = 'ROW' 的表修改压缩配置时误改隐藏 row binlog tablet 策略的问题：FE 不再向其下发 compaction policy 或 time series 设置，BE 拒绝更改 row binlog tablet 策略及将 binlog 作为新策略。影响：row binlog tablet 保持 binlog 策略，time_series 压缩属性修改不再中途失败。

PR #69243

将 V1 ORC 读取 TIMESTAMPTZ 的 UTC 时间下界从 0001-01-01 放宽到 0000-01-01，使年份 0 的值可正常解码而不再报越界错误，上界与越界报错逻辑不变，错误信息改为 0000-9999，并同步更新 BE 单元测试。

PR #69261

修复 #68447 导致的 Variant 测试夹具失效：回归测试中改用等价 JSON 字符串文档替代 parse_to_variant('abc')；移除 BE 单测中已删除的 check_duplicate_json_path 字段以恢复编译；更新 paimon 写入测试中 try_parse_to_variant('not-json') 返回 NULL 的预期行。具体影响待确认。

测试（4 条）

PR #69042

该 PR 仅调整回归测试：用 ALTER COLUMN SET STATS 固定基表与物化视图的行数统计，创建前临时关闭自动分析并在成功或失败后恢复原全局设置，同时将该套件标记为非并发执行，以稳定 chosen-MV 断言；生产优化器与聚合代码不变。

PR #69224

将 Iceberg docker 测试环境中的 Spark Paimon 从 1.3.1 升级到 1.4.2，更新 fixture 包和挂载脚本，调整 Variant 属性设置，恢复 weight-robin 外部路径用例，并重新生成分区表输出。具体影响待确认。

PR #69227

该 PR 为 test_paimon_catalog_variant 增加 Paimon 去重主键 Variant 读取回归测试：在 run13.sql 新建含两次快照的 variant_primary_key_smoke 表，并增加整列、路径投影和谓词三组 JNI 读取块，校验合并读取返回 id 1、2 的最新值，填补现有仅覆盖追加表的空白。

PR #69230

修正 Hive 与 Paimon 回归测试断言：Hive 用语句级 SET_VAR 关闭外部表批模式以核对精确分片数，并保留同步及强制流式结果检查；Paimon 改为按 doris-paimon- 线程名检查十个写入阶段后 30 秒内线程消失，保留进程线程总数诊断。无生产行为变化。
