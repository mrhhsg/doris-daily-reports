摘要

本日57项PR中，master主线新增建表级行TTL和批量AI结构化输出开关，支持过期行过滤与输出格式控制，TTL暂不支持通过ALTER动态启用。性能改动覆盖SNII编码与解码、扫描调度、Parquet裁剪、运行时过滤器及S3异步预取，旨在降低查询、内存和远程读取开销，具体收益仍需验证。

主线重点修复Iceberg等值删除、Arrow Flight重复端点和扫描失败后静默缺行、IVM偏移异常处理及TIMESTAMPTZ比较导致的DELETE错误，提升结果完整性；另修复旧Lance元数据升级导致的FE启动失败，升级后使用仍需安装连接器插件。

release回移不作为新功能：branch-4.1涵盖BM25、SEARCH DSL、HTTP TVF SSRF防护、事务重试及敏感日志修复；branch-4.2另涵盖SNII、Parquet、distinct聚合、缓存锁内远程IO及压缩类型保留等优化和修复。

测试覆盖TTL、Iceberg、IVM、索引、时间与时区、资源清理等场景，已有macOS相关364项测试及32项FE测试通过记录；部分改动仍待CI或受构建问题阻碍，ARM性能尚未实测。资料未提供文档更新信息，合并不代表已上线。

合并概览

2026-10-29（北京时间）｜合并 PR：57。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（33 条）

功能（2 条）

PR #65858

新增建表时配置行级 TTL，通过隐藏列支持基于源时间或直接指定过期时间的表。TTL 在行合并后与删除标记共同决定可见性，读取及自然重写时过滤过期行，保留普通压实策略；不支持通过 ALTER 动态启用，并补充属性校验、部分更新及可见性等测试。

PR #69302

为批量 AI 函数新增资源属性 ai.enable_structured_output，默认启用结构化输出约束并校验返回结果；关闭后省略服务商格式字段，保留批处理、提示词及结果校验。同时复用静态格式定义，解析响应时保留内嵌 NUL 字符，提高输出可靠性。

性能（11 条）

PR #66742

优化 SegmentIterator，在延迟初始化完成所有位图过滤后缓存行位图基数，并复用于列空间预留和批次读取，避免每个输出批次重复遍历 Roaring 位图容器计算基数，减少大数据段的扫描开销。

PR #69620

优化 BE 的 Peer/S3 竞速读取：跳过排队期间 Peer 已胜出的 S3 任务，减少无效请求和资源占用，并新增跳过计数。普通 Peer 缓存读取改用只读查询，不再创建空缓存单元；范围未完全下载时立即返回 NOT_FOUND，并支持碎片化缓存布局、补齐异步 LRU 更新。

PR #69655

优化 Parquet V2 浮点列裁剪：读取并校验可选 nan_count 元数据，将可信的零 NaN 计数传递给行组和页级 ZoneMap，使比较及 NOT IN 条件可跳过不匹配的数据，减少解码与读取。缺失或无效统计仍保守处理，保持原有查询语义和旧文件兼容性。

PR #69683

外表扫描默认从一个分区或文件启用批模式，生产批次调整为8个分片，每个后端队列按1024个分片限流，Hive分区处理批量独立配置，降低缓冲内存与批大小的耦合及小LIMIT等待。补充分片未就绪时的重试和扫描停止退出逻辑，连接器插件API升级至25。

PR #69685

将 BE 运行时过滤器的掩码合并与输入、输出有效行计数由三次扫描融合为共享 SSE 处理，适用于普通和可空过滤器，保留位运算、空值语义及统计更新，降低合并与计数的 CPU 开销；通过 sse2neon 适配 AArch64，ARM 性能尚未实测，标准 BE 单测因本地编译错误未执行。

PR #69686

优化非溢出窗口计算中 NTILE 的参数存储：从首个非空输入块为每个函数保存一个桶数值，裁剪旧输入行时仍保留，避免按行重复物化和缓存。其他窗口函数仍使用逐行参数列，SQL 结果不变，并新增多输入块、多分区裁剪测试。

PR #69715

优化 positive() 对非 Decimal 参数的处理，直接复用不可变输入列，避免分配和复制结果列，降低 CPU 与内存分配开销，保持输入值、类型及原有行为不变。

PR #69716

恢复 FileScannerV2 CSV/Text 读取的 S3 异步顺序预取，使远程 I/O 与解析重叠；隔离并安全汇总缓存统计，修正环形缓冲容量与关闭时指标发布。清理会等待未完成读取，可能超过读取超时。所测 TPC-H 导入耗时降低35.2%；完整运行测试待 CI 验证。

PR #69727

SNII 的 NULL 位图在计算序列化大小前执行游程优化，finish 复用该流程，确保预留大小与写入字节一致。减少连续 NULL 行索引的存储占用及读取开销，兼容现有读取器；随机位图大小不变，但增加容器扫描成本。新增单元测试覆盖游程序列化与回读。

PR #69769

SNII 新写入段的 .prx 窗口改为按索引预算选择编码，优先将 zstd 压缩收益较低的窗口存为解码更快的 PFOR 或原始格式，额外空间不超过参与预算窗口最小帧总大小的 8%。默认启用预算模式，仍支持固定阈值；普通构建与合并构建共用预算，已有段读取不变。

PR #69770

优化 BE 端 SNII 索引的原始及 zstd 压缩 .prx 窗口解码：将常见变长整数处理内联，减少逐文档调用开销；按索引源复用 zstd 上下文和缓冲区，并纳入内存追踪。减少部分短语查询的解码与分配开销，异常检查及查询结果保持不变。

修复（20 条）

PR #68795

修复 FE 中行策略谓词引用用户或系统变量时 SHOW ROW POLICY 报错的问题。为未绑定变量补充 SQL 渲染，正确转义用户变量名并保留系统变量作用域，使策略可正常展示，不改变行策略的实际过滤行为。

PR #69457

修复分叉仓库 PR 合并后，检出保护拦截诊断加载、导致评审状态无法同步的问题。pull_request_target 事件改用可信默认检出，其他调用仍固定工作流 SHA，保留安全限制及关闭事件的状态重算逻辑，并补充事件回归测试。

PR #69575

修复含 Lance Catalog 的旧版 FE 镜像升级至 master 后解析失败、FE 无法启动的问题，将旧类型映射为插件驱动类型并保留元数据；Catalog 需安装 Lance 连接器插件后才能使用。同时修复 BDBJE 调试视图读取无载荷日志时的空指针异常，并补充兼容性测试。

PR #69679

统一常量表达式缓存结果，以持有所有权的单行数据列存储，并零拷贝解包 ColumnConst。适配扫描、标量函数及 ANN 消费端，广播时重建常量列，避免扫描谓词依赖物理列类型；非法多行输入在构造时拒绝，保留原有函数初始化与 NULL 处理。

PR #69691

修复 Iceberg V1 文件扫描器在等值删除键列类型提升后查询失败或误删、漏删的问题。删除键及旧数据文件中的嵌套键统一转换为扫描模式中的类型进行比较，支持提升前后删除文件混用，避免窄化转换导致越界值误匹配 NULL 删除键，并新增 Parquet、ORC 单元测试。

PR #69695

移除 BE 测试工具 load_data_from_csv 中解引用 std::set 尾后迭代器的冗余断言，修复 macOS 下 ASAN 检测到栈越界并中止测试进程的问题。修复后相关 24 个测试套件共 364 项测试通过，Linux 行为不变，不涉及生产代码。

PR #69711

修复 FileScannerV2 在 Iceberg 键类型变更后，因统一比较类型导致等值删除误删、漏删或扫描失败的问题。改为按删除文件与数据文件的较宽键类型比较，启用严格转换，并修复缺失键默认值处理及相关 BE 崩溃；V1 读取器不受影响。

PR #69718

修复 FE 语句结束后连接器作用域资源泄漏：已关闭作用域拒绝加载资源，并释放与关闭操作并发加载的值；为 EXPLAIN REFRESH MATERIALIZED VIEW 的独立上下文分配查询标识并执行结束清理，避免表租约、元数据及清理注册项持续滞留，新增回归测试覆盖相关场景。

PR #69726

修复 BE 解码 SNII 索引时的长度与索引溢出问题：为 FRQ 长度计算增加检查，拒绝 varint64 第十字节超范围编码，并将 PFOR 异常索引累加值改为64位。损坏或构造的文件将返回损坏状态，避免错误解码和越界读取；不改变磁盘格式及正常文件兼容性，并补充单元测试。

PR #69728

补齐 SNII 数值、日期和 IP 索引 BKD 写入器的内存统计，将点缓冲区和 NULL 行文档 ID 纳入构建内存跟踪及指标，并在写入完成后释放相关向量及统计占用。仅完善内存记账，不新增内存上限，不改变磁盘格式、读取逻辑或混合版本兼容性；新增单元测试验证统计与归还。

PR #69730

修复 FE 为 VARIANT 子路径选择倒排索引时采用最后匹配字段的问题，改为与 BE 一致的首个匹配字段，避免重叠字段模式导致查询索引与写入索引不一致及回退扫描。无需重建索引，不影响字段模式无重叠的表，并新增单元测试覆盖。

PR #69757

修复通过旧版 Iceberg REST 目录删除最高字段 ID 列时提交失败的问题。调整 REST 请求编解码，使模式提交中的 last-column-id 保留历史已分配 ID 上限，并按表独立跟踪连续更新，兼容 REST 1.6.0；字段及模式 ID、提交约束和非模式提交行为保持不变。

PR #69758

清理 BE 中未使用的列接口，移除 IColumnDummy::addSize()、ColumnDictI32::Dictionary::avg_str_len() 及 _total_str_len 计数和插入时的更新逻辑，不改变现有行为。已确认无残留引用，未运行编译和运行时测试。

PR #69771

为 Arrow Flight 结果增加逐批校验，拒绝非法 UTF-8 字符串及超出 0001 至 9999 年范围的时间戳，覆盖嵌套值并返回服务端错误，避免客户端解码失败。同时修复 Spark、Flink 连接器扫描失败却正常结束的问题，防止静默缺行；普通 Arrow 转换器行为不变。

PR #69774

修复关闭新类型转换行为时，不同小数秒精度的 TIMESTAMPTZ 比较退化为 DATETIME、导致 DELETE 报类型转换错误的问题。旧比较逻辑复用公共类型规则，保留较高精度和 UTC 表示，并补充精度组合、时区及微秒敏感的 DELETE、IN 谓词测试。

PR #69778

修复 IVM 物化视图刷新时，新增或原为空的基表分区因缺少流消费偏移且数据超过变更日志保留期而永久漏行的问题。此类分区改为从基表读取全部行并作为追加数据处理，已有偏移的分区仍读取变更日志，用户流行为不变。

PR #69780

修复 Arrow Flight SQL 在启用并行结果接收时按实例发布重复端点的问题，改为按后端 ID 去重，每个结果后端仅发布一个端点，避免客户端凭相同票据重复建立读取流。关闭并行结果接收时仍保留每实例一个端点，并新增单元与回归测试验证端点唯一性及结果完整性。

PR #69785

修复重复键表的 IVM 物化视图在流偏移过期后刷新成功却静默漏行的问题。所有 IVM 刷新读取均拒绝过期偏移：严格增量刷新以 CHANGELOG_BROKEN 失败，允许回退时执行 COMPLETE 全量重建，避免漏行影响透明改写查询；用户流读取行为不变，并补充回归及单元测试。

PR #69799

修复 HLL 降采样读取常量参数时的两处遗漏，改用 ConstantExprResult::column_ptr() 获取列，解决常量表达式 API 迁移导致的 BE 构建失败。本地 ASAN BE 构建已通过，不改变运行行为。

PR #69809

删除 ExplainTableStreamPlanTest 中重复定义的 normalizeStreamRead 私有辅助方法，修复测试源码编译报错导致整个 FE 构建失败的问题。保留的实现与删除副本完全相同，不改变测试行为，相关 32 个测试用例全部通过。
