# Apache Doris 合并日报｜2026-11-16（北京时间）

## 摘要

master 主线新增 VARIANT 点号键转义、Iceberg V3 unknown 列只读支持及 MongoDB 会话级读取策略；优化节点间异步缓存读取、外表慢缓存自适应绕过和空间函数，改善外表扫描及复杂多边形查询。点号键转义须全量升级 FE、BE 后启用，Iceberg 支持仍有配套与验证限制。

主线重点修复缓存并发崩溃风险、Catalog SSRF 检查遗漏、补充字符引发的凭据脱敏问题，以及空值过滤、夏令时分区裁剪、HAVING 与 LIMIT 组合导致的结果错误。连接器 UDF 改为本地执行，旧插件需重构建；已有损坏物化视图需重建。

release 回移方面，branch-4.1 承接空值语义、ANN 线程预算、空间函数优化及 Kuromoji 等改动；branch-4.2 承接 Kuromoji、Variant 安全修复和无根 Docker 环境适配；branch-4.1.2-recycler 调整打包文件筛选与切片回收。多项改动补充单元、回归测试，MongoDB 配套文档；部分测试未运行、真实无根环境未验证，若干回移影响仍待确认，合并不代表已上线。

### 性能（3 条）

[PR \#69071](https://github.com/apache/doris/pull/69071)

[PR \#69779](https://github.com/apache/doris/pull/69779)

外表扫描按缓存路径和请求大小采样本地与远端延迟，可自适应绕过较慢的磁盘缓存，并限制探测频率与并发。远端失败或短读时回退本地，保持缓存与LRU行为；默认启用，不适用于HDFS，并补充Profile指标及回归测试。

[PR \#70302](https://github.com/apache/doris/pull/70302)

优化 st\_contains 等空间关系函数：每个扫描线程缓存常量形状的解码结果，避免逐行重复解码与校验；缓存多边形顶点经纬度，并通过边界框预筛减少边缘判断开销。主要改善含多顶点常量多边形的查询，结果保持不变，新增跨数据块缓存及边界容差测试。
