摘要

本日日报覆盖50项PR。master主线聚焦查询与资源效率：活跃Tablet快照降低FE内存占用，SQL缓存按依赖分区校验，SNII及倒排索引优化减少读取、解码与过滤开销，部分路径短时内存增加。文件读取统一至FileScannerV2，原开关不再生效；云模式例行导入和异步物化视图支持显式绑定计算组，并补充刷新与清理监控。

主线修复Iceberg默认值、时间语义及外部视图绑定、历史时间数据读取、删除位图检查死锁和并发UPDATE规划等问题。Brotli升级修复解码器越界写入漏洞，需重建第三方库并重新链接BE。测试补充分区缓存、指标转义及执行器配置覆盖；部分单测通过，完整构建和真实外部集成仍待验证。文档仅见协作者名单更新。

release回移中，branch-4.2接收Lance DDL、向量检索和部分AI函数改进，以及TIME兼容、Arrow导入崩溃和模式评分修复；branch-4.1回移导入鉴权与Join投影修复，两分支均修复行策略展示。回移不代表新增功能发布，合并不代表已上线；未提供other其他分支改动。

合并概览

2026-11-02（北京时间）｜合并 PR：50。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（37 条）

功能（5 条）

PR #69723

文件扫描统一使用 FileScannerV2，迁移查询、导入及删除文件等读取入口，移除旧扫描器和读取器；enable_file_scanner_v2 废弃且不再生效。恢复 ORC 尾部缓存，在字符串展开前过滤字典项，并限制位置删除读取批次大小，保留空值语义与嵌套类型读取行为。

PR #69749

云模式下，例行导入和异步物化视图支持通过 compute_group 显式绑定计算组，并在任务执行前校验组是否存在及使用权限；未声明时保留原有行为。同时修复带 workload_group 的例行导入任务在 FE 从镜像重启后被取消，以及并发停止被暂停状态覆盖的问题。

PR #69781

重构 BE 溢写文件读写，将 S3 上传、预取、相邻块合并及远端统计等策略拆分至专用读写类，由工厂为远端文件选择。公共类保留分片生命周期与序列化等职责，维持原有本地及 S3 行为，公开接口和文件格式不变；补充工厂选择、查询缓冲上限及本地统计隔离测试。

PR #69856

为 IVM 物化视图刷新任务新增 IvmRefreshMethod 列，区分增量、分区重建、全量及混合刷新，并记录失败与回退原因；持久化刷新摘要，在 Master 端新增任务数、耗时、回退、失败和调度拒绝五类计数指标，便于监控刷新行为与异常。

PR #69868

新增 BE changelog TTL 清理指标，记录清理成功与失败次数、成功清理移除的过期数据字节数及最近成功时间，覆盖存算一体和云模式，便于监控告警。字节数在行集移出 tablet 时统计，不代表文件已物理删除；原有清理行为不变。

性能（10 条）

PR #67621

改用 BE 上报的活跃 Tablet 快照替代 FE 滑动窗口及异步记录，降低 FE 内存占用；云端均衡分别按查询和导入活跃度排名，未进入上报前 N 的 Tablet 活跃度为零。同时修复云端 Tablet 上报重试导致的数量虚增。

PR #69879

为搜索器缓存保留的 SNII 读取器增加跨查询词项 LRU 缓存，最多保存32个精确查找结果及不存在的词项，减少重复读取、解压和校验字典块的开销，加速热点查询。缓存仅用于按需读取的字典，内存计入搜索器缓存；不覆盖前缀和模式遍历。

PR #69882

将 SNII 调用线程内读取的默认批次段数上限从 4 提至 16，覆盖本地缓存索引的短语前缀查询批次；遇到慢读时将剩余多段移交线程池，并在耗时判定中扣除缓存数据复制开销，减少缓存命中时的线程池调度与等待。

PR #69883

SQL 缓存改为记录扫描依赖的分区版本，包含规划时移除的空分区；无关分区写入后，依赖、表结构及分区拓扑不变即可复用缓存。元数据聚合、变量相关键和物化视图改写仍按全表校验。改动仅涉及 FE，保持 BE 缓存协议不变，并补充分区写入及物化视图等回归测试。

PR #69887

优化 BE 端 SNII 字典遍历与块打开：直接读取前缀压缩键，遍历复用缓冲区并跳过未命中条目的正文，块打开仅读取锚点键，减少解码开销，加速无字面前缀的正则查询。异常读取回退至校验解码，锚点正文损坏延迟至解码时报告；磁盘格式、写入路径及查询结果不变。

PR #69891

优化 BE 端 SNII 短语查询的选择性解码，按段累加位置计数，减少逐文档分支并便于编译器向量化，降低 CPU 开销。累加使用64位整数并保留上限校验，超限仍报相同错误；磁盘格式、写入路径及返回位置和窗口形态不变。

PR #69895

优化倒排索引过滤时有序文档编号写入 Roaring 位图的路径：按容器边界分段，直接批量填充位集或数组容器，其他情况沿用原逻辑。减少逐文档处理的 CPU 开销，加速匹配大量行的过滤，适用于各倒排索引格式，包括 V3，结果保持一致。

PR #69897

优化 next_day 和 previous_day 的星期解析，使用编译期校验的专用查找表替代逐行字符串复制、大写转换和哈希查找，常量星期参数每个数据块仅解析一次。完整校验输入以拒绝碰撞值，保持支持的别名、NULL 传播、SQL 结果及错误行为不变，减少重复解析开销。

PR #69908

优化数值列 SNII 范围过滤：批量读取连续整叶命中，宽范围使用平面位图收集文档编号以避免排序，并复用解码缓冲。稀疏命中或超出位图上限时沿用排序路径，限制分配规模。可加速大量行命中的查询，但短时内存占用增加；磁盘格式与写入路径不变。

PR #69909

优化 SNII 文档编号解码：复用窗口向量，减少重复清零；按窗口校验增量，消除逐文档检查分支；为 PFOR 解码和跳过操作加入单字节变长整数快速路径。降低匹配大量行时的过滤查询开销，磁盘格式及写入路径不变；多项校验同时失败时优先报告零增量错误。

修复（17 条）

PR #68979

修复 FE 常量折叠与 BE 运行时 CAST、CONVERT_TZ 的时区偏移校验不一致问题，统一解析并保留会话与字面量的独立策略，拒绝缓存中的越界会话偏移，修正显式时区后缀识别。TIMESTAMPTZ 数值偏移限定在 -18:00 至 +18:00；最终 FE 清理代码仍待 CI 验证。

PR #69447

修复 CI 审查内联意见批量提交被 GitHub 拒绝的问题，改为创建单个草稿、逐条添加并核验完整意见后统一发布，依据本地差异转换行号定位。保留提交前校验，失败时尽力清理自有草稿，不重试结果不确定的写入；仅摘要审查路径不变，正式发布与 Actions 身份仍待上线验证。

PR #69469

修复 CI 早期审核失败通知：显式指定仓库，使通知不再依赖代码检出；准确报告待处理状态设置及检出步骤的失败或取消，避免将跳过或未启动的上下文准备误判为故障。保留认证、用量限制恢复提示及失败退出状态，并新增七项回归测试。

PR #69488

修复 Iceberg 表 DEFAULT(column) 错读读取模式默认值的问题，改为使用语句固定的写入模式，避免 INSERT 报错或写入 NULL，以及 UPDATE、MERGE 条件无法匹配。SELECT 和 DELETE 中不合法的用法改为报错；Hive 托管 Iceberg 表的部分快照路径仍待后续修复。

PR #69510

修复 CI 审查流程遇 GitHub 临时读取错误即中断的问题：对符合条件的 REST GET 502/503/504 最多尝试三次，受单次及总超时预算约束，遵循 Retry-After 并丢弃失败分页输出；输入解析失败时回退使用已授权触发来源的 PR 编号发送通知，不放宽状态发布限制。

PR #69611

修复新增默认值为 CURRENT_TIMESTAMP 的 TIMESTAMPTZ 列后历史数据不可读的问题。回填默认值改用 UTC 字面量，调整批量加列转换，并在 Protobuf 和 Thrift 中保留默认表达式，确保部分更新新增行动态计算时间，而非复用固定回填时间。

PR #69829

修复 FE 加载 Iceberg 视图时对 engine-name 元数据的处理，支持该字段缺失或为空的视图；字段有值时仍按现有引擎规则选择 SQL，仅在无值时采用 Doris/SDK 回退逻辑，保留原有选择行为。

PR #69837

修复 FE 的 Prometheus 指标输出未转义标签值的问题，统一处理反斜杠、双引号和换行符，避免云模式下特殊表名导致整次指标抓取解析失败。保持普通标签及空值原有输出行为，并新增转义与空值处理单元测试。

PR #69845

修复 Iceberg 的 Parquet INT96 格式 timestamptz 列在非 UTC 会话中读取出现时区偏移、等值删除漏删或误删的问题。FE 标记字段时间语义，BE 据表类型将数据文件及删除文件中的对应列解码为时间瞬间，覆盖嵌套字段与隐藏删除键；保留纳秒类型和旧 FE 计划行为，ORC 不受影响。

PR #69851

修复 IVM 物化视图完整刷新 EXPLAIN 与实际执行计划不一致的问题，按刷新起始阶段的 RESET 模式展示流扫描，包含物化视图分区所依赖的基表；缺少可用流时直接报错。仅增加流元数据读取，不执行刷新、不创建流或推进流偏移。

PR #69880

FE 在 UPDATE 逻辑计划补全过程中持有目标表读锁，并在进入 INSERT 规划或执行前通过 finally 释放，防止并发轻量级表结构变更导致元数据读取抛出 ConcurrentModificationException；同样覆盖 EXPLAIN UPDATE，相关单元测试通过。

PR #69892

修复云模式后台删除位图检查与 Compaction 锁顺序相反导致的 BE 死锁。检查前读取序列列标志，并复用 tablet 快照在映射互斥锁外执行检查，避免阻塞其他 tablet 操作及引发写入、元数据停滞，同时保留序列与非序列表的活跃及过期 rowset 版本检查。

PR #69901

修复同一列的多个 MATCH 子句通过 USING ANALYZER 使用不同倒排索引时，score() 查询报错的问题。BM25 统计改为按字段和索引 ID 分别保存，各子句使用自身索引统计评分，组合得分为各子句得分之和；SEARCH 行为保持不变，并补充多索引回归及单元测试。

PR #69906

将内置 Brotli 升级至 1.0.10，修复 CVE-2026-111497 涉及的解码器越界写入漏洞；同步更新归档校验和及 Arrow 24 依赖元数据，避免校验失败，并确保已打补丁的源码树也能应用更新。需重建相关第三方库并重新链接 BE；完整 Doris 和 Arrow 构建仍待 CI 验证。

PR #69946

修复外部 Iceberg REST 视图查询在绑定阶段因请求表元数据被拒而失败的问题。解析时先识别视图，跳过表句柄请求，并保留实时存在性检查，使 Doris 外删除的视图仍可使缓存失效；基表快照和普通表加载行为不变。相关单元测试通过，未进行真实 Databricks 集成测试。

PR #69953

修复 CI 审查因模型容量不足耗尽重试的问题：可通过可选参数启用回退，累计五次容量失败后，在同一会话中切换至 gpt-6-astra 完成剩余两次尝试，保留已完成发现、累计轮次、五分钟退避及共享时限。已补充测试，真实 CI 访问与跨模型子代理恢复尚未验证。

PR #69988

修复 CI 审查容量恢复配置：主模型连续五次容量失败后，回退目标由 GPT-6 Astra 改为 GPT-6 Sol，并更新测试用例与断言。主模型、重试与退避策略、会话和预算保留机制不变；实际模型容量及端到端跨模型恢复未重新验证，具体影响待确认。

PR #69384

为 4.2 分支的 Lance 外部目录新增基于 Namespace API 的 DDL 支持，覆盖文件系统和 REST 目录的命名空间创建删除、表创建删除及重命名、顶层列变更，并在成功后刷新元数据与缓存；保护根命名空间，明确拒绝 SDK 不支持的操作。

PR #69843

将部分 ai_function 改进代码合入 branch-4.2 分支，涉及 BE 端 AI 函数。正文仅列出来源 PR，未说明具体改动内容，具体影响待确认。

PR #69852

Lance vector_search 新增 approx_mode，支持 fast、normal、accurate，省略时保留默认行为。单、多向量扫描均支持，EXPLAIN 展示显式模式；平滑升级期间，候选后端含旧升级源节点时拒绝 fast、accurate，防止合并不同策略生成的候选结果。

修复（5 条）

PR #69654

修复 branch-4.2 分支 BE 端 topn_array 对 TIMEV2 类型的支持问题，使其能够处理该类型数据。本次为回合并改动，具体影响待确认。

PR #69878

向 branch-4.2 回移旧版 TIME 元数据兼容修复，将其反序列化为 TIMEV2，新元数据仍写为 TIMEV2，修复升级后视图从镜像或日志恢复时类型无效、导致 information_schema.columns 查询失败的问题，并补充相关兼容性与恢复测试。

PR #69900

修复 4.2 分支中行策略 USING 子句引用用户变量时，SHOW ROW POLICY 因未绑定对象无法转换为 SQL 而失败的问题。通过实现 UnboundVariable 的 computeToSql 方法，恢复此类行策略的正常列出，便于管理。

PR #69905

修复 BE 在 Stream Load 中处理不兼容 Arrow 数组时崩溃的问题，改为拒绝此类数组，避免因此导致导入崩溃；该修复回移至 4.2 分支。

PR #69922

修复 BE 中正则表达式和通配符模式的评分逻辑，参照 Elasticsearch 使用常量评分；该改动已回移至 4.2 分支，具体影响待确认。
