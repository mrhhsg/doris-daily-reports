# Apache Doris 合并日报｜2026-10-23（北京时间）

## 摘要

本日完整自然日覆盖55个PR。master 主线聚焦 Iceberg/Paimon 兼容、查询正确性与稳定性：新增 Iceberg DELETE 整文件元数据删除快速路径，修复 void 分区、保留列名、默认值精度、MODIFY COLUMN 可空性、JDBC V0 视图探测及 Paimon SDK 适配；并处理 VARIANT 内存、Parquet 空值映射越界、array\_flatten NULL、嵌套裁剪 CARDINALITY、物化视图常量传播、UTC 折叠、S3 导入、FQDN 心跳和敏感日志等问题。

release 回移集中在 branch-4.1/4.2，按修复或测试处理，不视为新功能：包括 FE 漏洞依赖升级与未用库清理，BM25 并行扫描统计、RBO 常量传播 exprId、云模式 packed slice location 与陈旧路由、TopN batch rowid、JSON 推断大小写、多表例行导入属性和 t-digest 预分配等；另有 LakeSoul/Hudi 日志脱敏、元数据恢复后视图列查找、Iceberg JDBC V0 视图探测与 DROP 分发、同步物化视图改写严格模式、Cloud Broker Load RETRY 竞态及自动分区创建前校验等稳定性调整。

其他分支仅见 paimon-blob-4.1 的 Paimon BLOB descriptor 表选项、paimon\_blob\_max\_size 会话变量和 blob 大负载处理 PR，信息有限，影响待确认，不属于 release 回移。

多项改动补充单测或回归测试，文档更新未普遍提及；部分收益待确认，合并不等于已上线。

[PR \#69301](https://github.com/apache/doris/pull/69301)

[PR \#69321](https://github.com/apache/doris/pull/69321)
