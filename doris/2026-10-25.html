摘要

本自然日日报覆盖 22 个已校验 PR，其中 master 主线 19 个、release 回移 3 个，无其他分支条目。主线改动集中在写入路径、元数据缓存与外部表兼容：写入路径重构改为通过 IColumn 与行范围直接写 Segment，Iceberg 数据文件写入改由阻塞调度器上的 Pipeline 任务同步执行；元数据缓存新增权重统计列并采用逐元素估算，使宽表、长名称和长分区列表更易被缓存接纳，同时 CREATE/ALTER CATALOG 增加 meta.cache 属性校验。上述写入重构对用户的具体影响尚待确认。

修复覆盖 Paimon ORC CHAR 补齐、二进制分区与 schema 恢复，Iceberg 分支写入使用当前 schema、二进制等值删除键及 Parquet 结构体删除键读取，索引变更任务冲突判定、EXECUTE 失败清理和带引号表名美元后缀解析等，主要降低写入失败、读取报错、BE 崩溃和静默扫描基表的风险。测试方面补充 Iceberg、Paimon 及 ANN 编译相关用例，部分 SQL 套件未执行或仅调整断言，生产行为影响有限或待确认；未提及专门文档改动。

release 回移 3 项包括云模式 ALTER TABLE 后同步 tablet 元数据的 RPC、滚动升级回归测试调整及日期运算别名下推溢出修复，均按回移处理，不作为新功能；相关改动是否已上线未在资料中说明。

合并概览

2026-10-25（北京时间）｜合并 PR：22。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（19 条）

功能（4 条）

PR #69070

重构写入路径：移除 OlapBlockDataConvertor，改为通过 IColumn 与行范围直接写 Segment；扩展 StorageLayout 以支持列到存储转换和对象序列化，更新列写入器，直接从 Block 列编码 key，并迁移 partial-update、variant 与 BUILD INDEX 路径。CHAR 补齐、key 编码及磁盘页格式保持不变，具体影响待确认。

PR #69556

CREATE/ALTER CATALOG 校验语句提交的 meta.cache 引擎属性：选项限 enable、ttl-second、capacity、max-weight 且值类型正确，否则报错；并拒绝超过 FE 全局配额 external_meta_cache_max_weight 的配额。

PR #69557

为 information_schema.catalog_meta_cache_statistics 增加 WEIGHT_BOUNDED、EVICTION_WEIGHT 以及 catalog 与全局预算的最大值和已占用字节等六个权重列，使按 4.x 写法监控该视图的查询可用；无权重上限条目的各权重列由 0 改为 -1；当 FE 不认识新列时，BE 扫描器回退为请求前 28 列。查询结果列顺序与 4.x 仍有差异，具体影响待确认。

PR #69558

元数据缓存设有权重上限时，宽表（数千列）、长名称列表与长分区列表因整体大小估算超出遍历预算而无法被缓存，导致每条语句重复加载。此 PR 新增逐元素估算，使这些值可被缓存接纳并按元素计费，单个元素仍受遍历预算约束，其他条目的估算方式不变。

性能（1 条）

PR #69355

Iceberg 数据文件写入改由阻塞调度器上的 Pipeline 任务同步执行，本地状态改为可阻塞 sink，由任务自行打开、写入和关闭 writer；移除异步队列的等待逻辑，最终 spill 合并的输出块限制为不超过一个 spill 批次；保留原有内存预留与撤销机制，并新增单元测试和回归测试。

修复（10 条）

PR #69295

Paimon ORC 表写入时对含 UPDATE、DELETE、MERGE 在内的所有行 CHAR 值补齐空格，与 Spark/Flink 一致，使 DML 命中其写入的行；跨分区表全局索引键同步补齐；MERGE 拒绝插入以空格结尾或长度不足的 CHAR 主键；FE 端 ORC 表 CHAR 桶键改为单写入。

PR #69350

改进 Variant 写入校验器：按目标列类型逐字段追踪写入需求，仅在值确实写入 Variant 叶子且发生有损转换时拒绝；跳过仅用于比较或选择的参数，如比较、IN、LIKE、NULLIF 第二参数和 element_at 的索引或键。新增单元测试与 Paimon 写入用例，错误信息补充显式 CAST 提示。

PR #69443

本地模式下未完成的索引变更任务此前只与同方向的新任务冲突，导致同一索引的 BUILD INDEX 与 DROP INDEX 可能乱序执行。本次改为：同一索引的建索引或删索引任务，只要在分区上未完成，无论方向如何都判定为冲突；DROP INDEX、DROP INDEX PARTITION 和 BUILD INDEX 均返回原有错误信息，待任务结束后可重试，并补充了单元测试。

PR #69499

修复 Iceberg 分支写入绑定分支 head 快照 schema 的问题：分支写入现在改用表的当前 schema，包括列名、写入默认值和分区规范；同时移除 validateBranchWriterSchema，改为在提交前校验当前 schema id 是否已变化。INSERT OVERWRITE 会记录规划所依据的写入 schema 和元数据标识，若两次规划之间表发生变化，则报错并提示重试。相关单元测试和回归测试已同步调整。

PR #69503

修复文件扫描V1下Iceberg等值删除键为BINARY或FIXED时读取失败甚至BE崩溃的问题；字符串和VARBINARY键改为按字节匹配，复合键按字节哈希比较，并支持常量NULL键；新增6个BE单测，无回归测试。

PR #69541

解析器现在会拒绝紧贴带引号表名的未加引号美元后缀，例如表名后直接跟 $snapshots，从而避免该后缀被当作隐式别名并静默扫描基表；此时改为报错，并提示引用完整表名。完整引用、显式别名及空白分隔别名仍有效，并补充了解析器与回归测试。

PR #69545

修复 Paimon 在重命名 sequence 或聚合字段后，当前读取和历史读取出现缺字段报错的问题；读取时同时恢复所选 schema 及物理选项，保留读状态键、分支策略和 catalog 覆盖，并补充真实表与端到端回归测试。

PR #69547

修复 V1 Parquet 读取器处理 Iceberg 等值删除键位于结构体字段时的错误：当查询同时投影该结构体，或删除在同一结构体含多个键时，避免共享文件列只被读取一次而导致结构体为空或行缺失，并补充单元测试。具体性能影响待确认。

PR #69566

修复预处理语句 EXECUTE 执行失败后清理不彻底的问题：在 handleExecute 的 finally 中注销查询 ID 并关闭语句上下文，使查询结束回调、连接器作用域及待停止扫描节点按正常结束流程释放；新增单元测试覆盖失败与成功场景。

PR #69567

修复 Paimon 二进制分区写入：对使用 legacy 分区名的表改为在规划阶段报错并提示设置 partition.legacy-name=false，避免提交失败残留文件；二进制静态分区覆盖写支持 UTF-8 文本字节，VARBINARY(n) 超长值在规划阶段被拒，fe-core 按列类型转换静态分区字面量。

测试（4 条）

PR #69551

新增45个Iceberg连接器单元测试、两个外部回归套件及覆盖清单，覆盖快照、schema、ref隔离，原子写入与失败路径，嵌套类型元数据、谓词语义、分区序列化、ref保留及删除历史中的文件位置；另设9个禁用复现对应5类已确认缺陷，生产行为不变。SQL套件未执行，具体影响待确认。

PR #69552

从 branch-4.1 移植 Iceberg schema 矩阵测试断言到 master：为双关系矩阵补充历史与最新表连接校验，时间旅行矩阵新增分支读取当前 schema 用例，元数据矩阵启用 show_column_comment_in_describe 断言 DESC 注释，并恢复已存在 CTAS 目标用例；无生产代码变更。

PR #69569

该 PR 仅新增测试，在 PaimonBackendBoundTableTest 中补充两个 FE 单元测试，覆盖 Paimon 系统表来源的 catalog 快照固定：回退分支分别固定到各自快照，且关系级 scan.snapshot-id 优先于固定值；不改变运行行为，未新增回归测试。

PR #69584

将三个 ANN 单元测试中 17 处 offsets 向量由 size_t 元素类型改为 uint64_t，以匹配索引 writer 的 const uint64_t 指针参数，修复 macOS 下因 size_t 与 uint64_t 类型不同导致的 BE 单元测试编译失败，生产代码未改动。
