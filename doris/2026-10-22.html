摘要

本完整自然日日报覆盖51个PR：master主线33个、release回移branch-4.1 5个、branch-4.2 13个，other其他分支无记录。主线重点是云模式查询溢写可写S3，并补充容量限制、SHOW DATA和审计统计；同时优化字符串函数与percentile缓冲区。

主线还集中修复查询正确性：外部Catalog刷新锁竞争、云MOW schema change取消、DROP INDEX元数据误删、聚合视图改写丢聚合节点、嵌套集合列映射、行策略、KVCache持锁、Iceberg/Hive写NULL及残留文件、STRUCT重命名、SEARCH/BM25等；并处理Nereids虚拟列/CTE、BACKUP timeout、Azure插件Netty隔离，引入扫描级SupportChangelog接口。

release回移不作为新功能：branch-4.1含轮询间隔、TopN惰性物化、rowset裁剪、云路由清理及测试清理；branch-4.2含布尔搜索评分隔离、GZIP写入、index_disk_usage、decimal溢出、Hudi别名、GROUP BY误报、时间类型归一化，以及统计优化回滚、HBO用例删除、Clang AArch64兼容、云Tablet加密处理和RBO列映射等。

测试上，主线扩展Iceberg JDBC catalog在PostgreSQL/MySQL的DML、分区更新、MERGE、CTAS、表结构变更、快照与元数据隔离回归并加校验，修正Iceberg/Paimon期望；Azure插件和BACKUP timeout补测。文档覆盖有限，部分性能收益与单测执行未确认；合并不等于上线，实际发布影响待版本确认。

合并概览

2026-10-22（北京时间）｜合并 PR：51。按实际 merged_at 筛选，主线与 release 回移分别统计。

master 主线（33 条）

功能（2 条）

PR #68032

云模式下查询溢写可写入 S3 存储库，由 be.conf 的 spill_storage_type 与 spill_s3_storage_vault_id 选择，新增 spill_storage_limit_bytes 限制各溢写存储；SHOW DATA 新增 remote_spill 行并计入总量，审计日志记录查询读写的远端溢写字节，另补充溢写文件生命周期日志与创建/删除计数。

PR #69435

引入扫描级能力接口 SupportChangelog，统一判断 changelog 是否启用、是否仅追加及构建快照 withSnapshot；LogicalOlapScan 实现该接口，流扫描拒绝，IVM 相关判断改为经接口调用，快照入口合并为单一 withSnapshot，现有 OLAP 表行为不变。

性能（1 条）

PR #69223

优化 BE 字符串函数：混合列中的 ASCII 行改用大小写转换快速路径，常量 ASCII 映射的 translate 改用表路径，concat_ws 直接追加输入，repeat 复用 fast_repeat 并预留输出空间，缓存 parse_url 常量部件查找；新增 AArch64 NEON 的 contain_one/contain_zero 及边界测试。基准加速未测量，单元测试尚未执行，具体影响待确认。

修复（25 条）

PR #68042

修复外部 Doris Catalog 表在并发查询时元数据刷新锁竞争导致的 FE 规划阻塞：刷新协调仅在创建或选择 FutureTask 时持有表监视器，实际刷新在监视器外执行，刷新期间到达的请求等待并共享后继任务，只有一次执行；刷新失败可由后继任务重试，中断的等待者恢复中断状态且不取消共享任务。元数据 RPC、分区同步和缓存更新逻辑未变，具体性能影响待确认。

PR #68398

修复 BE 重启导致云 MOW 表 schema change 被取消：start_compaction_job 允许新 STOP_TOKEN 替换陈旧 initiator 的 token，并同事务释放其 delete bitmap 锁；存活 token 仍阻塞 compaction，load 不再被陈旧锁阻塞。

PR #68674

修复 DROP INDEX 因同分区未完成的索引变更任务（云模式下还包括计算组缺失）报错后，索引元数据仍被删除的问题：把冲突检查提前到处理 ALTER 子句之前，并提取 isLightDropIndexSupported 共用；同时拒绝同一语句中同时走轻量路径的 ADD INDEX 与 DROP INDEX。新增单元测试。

PR #68861

修复标量聚合查询被分组聚合物化视图改写时丢失聚合节点的问题：当查询为标量聚合而视图分组时，改走 roll up 路径并保留聚合节点，使空输入返回 0 而非空结果；同时修正 roll up 输出映射的可空性判断与补偿谓词裁剪，使自身带 HAVING 的视图不再改写此类查询。

PR #69131

修复RBO合并嵌套集合操作时丢失父输入列映射、可能从错误列取值的问题；在展平子节点前组合父映射与嵌套输出序号，并统一处理UNION常量行及INTERSECT、EXCEPT的相关映射。

PR #69150

修复 FE 元数据恢复后，在视图上创建行策略误报列不存在的问题；原因是 View.gsonPostProcess() 未调用父类方法，导致未持久化的列名映射为空。改为调用 super.gsonPostProcess()，从恢复的 schema 重建列查找，覆盖镜像加载和建表日志回放场景，已加单元测试。

PR #69183

将 Hive 和 Iceberg 写入超过单 writer 打开分区上限时的错误由 INTERNAL_ERROR 改为 INVALID_ARGUMENT，并在信息中说明写入类型、当前与尝试分区数、上限、BE 配置项及拆分写入或调大配置的建议；限制检查逻辑未变，并补充 BE 单测和 SQL 测试。

PR #69252

修复FE外部catalog初始化与数据库发现异常被吞并误报Unknown database的问题，保留认证、连接和发现错误；成功确认不存在时仍返回空。调整调用方在元数据失败及USE/SWITCH失败后保留会话状态，HTTP命名空间按默认解析，缺失的隐式Hadoop根视为空。重定基后受Thrift编译器版本限制未完成单测，具体影响待确认。

PR #69284

修复 percentile_approx 和 quantile_union 为每个 GROUP BY 分组预分配与 compression 成正比缓冲区的问题，改为构造函数按需增长并移除合并时的整块 reserve，避免分组数量极多时后端内存耗尽中止；压缩阈值、算法与序列化格式不变，并新增单元测试校验容量与分配行为。

PR #69287

该 PR 在存储代码中将无作用域枚举和整型字段改为作用域枚举，并在序列化、索引和日志边界显式转换，同时用 constexpr 常量替代匿名大小枚举、将 IK 字典二叉节点状态改为 bool。持久化数值和存储格式不变，属类型安全重构，具体影响待确认。

PR #69324

修复 KVCache 在持有分片互斥锁时执行 value factory 的问题：改为按键加锁执行，保证每个键只有一次在途加载，并按值类型隔离缓存条目，同时将 Fluss tail 加载简化为同一单飞路径，避免远程 IO 阻塞无关缓存键。具体影响待确认。

PR #69327

修复 Iceberg ORC/Parquet 写入可将必填字段写成 NULL 及失败后残留数据文件的问题：新增 BE 校验器检查必填嵌套字段和 MAP 键，在创建 writer/文件前校验并清理失败文件且不发布快照，FE 回滚也会删除已完成 BE 片段上报的文件。

PR #69328

修复 FE 将仅重命名字段的 STRUCT 转 STRUCT cast 当作 no-op 折叠的问题：Type.matchExactType 现在同时比较字段名，此类 cast 会正常序列化并由 BE 按目标字段名重标注，从而解决 element_at 按字段名访问时报 Element not found 或返回错误结果，ARRAY/MAP 内嵌重命名同样覆盖，字段名相同的 cast 仍保持 no-op。

PR #69341

修复 FE 依赖安全问题：升级存在 CVE 的库，移除未使用的 Avro RPC、YARN 客户端和 Hive UDF 依赖；因 master 授权插件需要相关类，未沿用 Ranger Hadoop 排除项。验证显示 FE 构建 87 个模块且 7 个 Hive UDF 测试通过。

PR #69347

将 SEARCH 谓词后端执行统一为二值匹配：普通词不匹配 NULL 或已证实缺失字段，AND/OR 组合匹配集，NOT 对其取补；过滤物理 NULL posting，缺失且必需的 Variant 索引报错，普通 SQL 与 MATCH 仍保持三值语义。补充相关测试，未声明性能提升。

PR #69352

该 PR 修复倒排索引 BM25 统计在平板并行扫描时按分片采集的问题：改为每个平板由首个扫描器采集全量统计并复制给其他扫描器，使相同文本行的得分不再受扫描器划分影响；非并行路径不变，跨平板与 BE 的一致性未涉及。

PR #69370

修复同步物化视图的 CREATE MATERIALIZED VIEW IF NOT EXISTS 标志未传递给命令、被静默忽略的问题：现在持基表写锁检查索引，已存在时直接返回不创建，避免重复列名或已存在报错；普通 CREATE 行为不变，并补充回归测试和单元测试。

PR #69375

严格校验 binlog 属性：未知 binlog.* 键报错，仅允许四个 CCR 键；binlog.enable 仅接受 true/false（大小写不限），其他值报非法。CREATE/ALTER TABLE 与 DATABASE 均受影响，已持久化元数据不重新校验。

PR #69378

修复 ClickHouse JDBC 驱动版本识别：FE 客户端和连接器客户端在比较主次版本前先移除 clickhouse-jdbc 工件前缀，避免带前缀的旧版本（如 0.3.2-patch11）解析失败或被误判为新驱动；低于 0.5 的版本继续使用旧元数据模式，其他未知或无效字符串的行为保持不变。

PR #69382

修复 Iceberg 扫描载体名称不一致问题：统一基于权威扫描 schema 构建载体，并按 Iceberg field id 解析分区列，避免大小写混用及时间旅行读取异常。

PR #69386

为代码审查流水线的 gh api 调用新增共享诊断辅助脚本，失败时记录 HTTP 状态码、允许列表响应头、截断且脱敏的响应片段、退出码或超时及运行上下文，失败产物在 PR 检出前或调用方处理错误时仍会上传。辅助脚本从不可变工作流提交加载，聚合产物按 head SHA 区分，原有输出、请求参数、权限与评审结论保持不变。

PR #69399

修复 Nereids 深度复制含虚拟列扫描时的槽位映射：先为虚拟列分配新 ID 再复制表达式，并同步 score/ANN 排序键；withVirtualColumns 同时替换输出槽位，解决 CTE 内联报 A expression contains slot not from children。

PR #69416

修正外部回归测试：更新 Iceberg 必填 digest 字段的非空期望及六处 NULL 写入错误断言，以适配新校验报错；Paimon HMS 测试改用可识别的 fs.gcs.support 选择 GCS。仅修改回归脚本，不改变产品行为，具体影响待确认。

PR #69420

该修复在 FE Azure 插件中打包 netty io_uring 传输类与 Linux 原生库，避免插件与宿主机的 Netty 类加载器冲突，并新增隔离加载测试。可修复选用 io_uring 时 Azure 文件访问和仓库创建失败，其他影响待确认。

PR #69424

修复 BACKUP SNAPSHOT 指定有效 timeout 时，因 BackupCommand 从解析器返回的不可变属性映射中移除 timeout 而导致 Nereids 分析失败并抛出 UnsupportedOperationException 的问题；改为先复制属性再分析，并从可变副本消费全部属性，同时新增单测校验 timeout 转换与内容解析。

测试（5 条）

PR #67138

修复回归测试 test_materialized_view_load_open 不稳定问题：原 createMV 会等共享库最新物化视图任务，并行时可能误判其他任务完成后对仍处于 ROLLUP 的表执行 ADD COLUMN；改为四处使用 create_sync_mv，使每个视图等待其基表对应任务。仅改测试同步逻辑。

PR #67723

修复回归测试 test_fix_tablet_stat_fault_injection：为 compaction 等待函数增加可选 tablet_ids 参数，首轮后仅对仍多于 2 个 rowset 的 tablet 重试，最多 5 轮，恢复 rowsetCount 断言，并在失败时报告 tablet id 与 last full status，以规避云模式下 delete bitmap 锁冲突造成的偶发失败。

PR #69310

移除外部分回归测试中六个 Paimon Variant 写入套件和 Iceberg initial-default 套件的 nonConcurrent 标签，使其可在现有并行机制下与其他隔离套件并发调度，同时需独占集群状态的套件仍串行执行。仅调整测试调度，未运行完整外部分回归。

PR #69374

该 PR 将仅在云模式运行的两个 changelog 测试套件中残留的九个 binlog 结果标签重命名为 changelog，并同步修改 groovy 文件与 .out 文件的标签行；查询和预期结果行均未变，.out 为手工改标签而非重新生成，具体测试执行影响待确认。

PR #69417

扩展 Iceberg JDBC catalog 回归测试，在 PostgreSQL 与 MySQL 上覆盖行级 DML、分区更新、MERGE、CTAS、表结构变更、分支标签与快照、重写及元数据隔离等场景，并新增 98 项有序结果校验，保留原有检查；该 PR 仅改测试，不改变产品行为。

PR #67601

将 #65470 回移到 branch-4.1，修复最大分数尾部裁剪可能留下单个不重叠 cumulative rowset、导致无法单独压缩并反复找不到合适版本的问题。云与本地策略会记住最后裁剪的 rowset，在裁剪将造成非重叠单例时恢复其直接后继，并接受一次最大分数超调以保持输入可合并；同时补充云和本地回归用例。具体线上影响待确认。

PR #69164

修复云模式下 CloudReplica 陈旧路由清理：不再逐条回放日志扫描，改为每个回放批次及均衡器每轮合并清理一次，checkpoint 保存前也清理，并支持每日时间窗；延迟 journal 不再发布已删除 backend 的路由，避免误删有效 secondary 路由，并补充相关单测。

PR #69331

将 #63436 的批量 rowid 读取回移到 4.1 分支，修复 TopN 惰性物化在 join 产生重复或乱序 rowid 时可能挂起的问题；按 segment 分组、排序去重后批量读取，再散射结果以保留请求顺序和重复行，具体影响待确认。
